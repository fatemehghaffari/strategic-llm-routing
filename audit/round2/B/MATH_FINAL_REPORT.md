### 1.2 Adjudication of the three points raised by the main agent

1. Nesting and Levy's theorem are not needed (ACCEPTED, verified independently by the lead). Both provers proved the convergence `sum_C nu(C) eta_{i,C} -> 0` by making the level-k dyadic cells a filtration and invoking Levy's upward theorem, which forces the nested dyadic grid of the task. The adversary observed that only the integral is needed, and the lead verified the following complete replacement, which holds for ANY sequence of finite Borel partitions with mesh tending to zero:

   Lemma (cell-average convergence, L1 form). Let `nu` be a Borel probability measure on the compact metric space `[0,1]^D` and let `P_n` be finite Borel partitions with `mesh(P_n) := max_{C in P_n} diam(C) -> 0`. For bounded Borel `f` write `f^{(n)}(X) := E[f | C]` on each `C in P_n` with `nu(C) > 0`, and `f^{(n)} := 0` on null cells. Then `||f^{(n)} - f||_{L^1(nu)} -> 0`.
   Proof. Fix `eps > 0`. Continuous functions are dense in `L^1(nu)` for a finite Borel measure on a compact metric space, so pick `g` continuous with `||f - g||_{L^1(nu)} <= eps`. Conditional expectation is an `L^1` contraction, so `||f^{(n)} - g^{(n)}||_1 = ||(f-g)^{(n)}||_1 <= ||f - g||_1 <= eps`. For `X` in a positive-mass cell `C`, `|g^{(n)}(X) - g(X)| = |E[g | C] - g(X)| <= sup_{Y in C} |g(Y) - g(X)| <= omega_g(mesh(P_n))`, where `omega_g` is the modulus of continuity of `g`, which is uniform because `g` is continuous on a compact set; hence `||g^{(n)} - g||_1 <= omega_g(mesh(P_n))`. By the triangle inequality `limsup_n ||f^{(n)} - f||_1 <= 2 eps`, and `eps` was arbitrary. QED.

   Consequences. The maps `(u_1,...,u_K) -> (u_i - max_{j != i} u_j)_+` and `(v, u_1,...,u_K) -> v - max_j u_j` satisfy `|Phi(u) - Phi(u')| <= sum_l |u_l - u'_l|`, so `||eta_i^{(n)} - (M_i - r_i)_+||_1 <= sum_j ||M_j^{(n)} - M_j||_1 -> 0` and `||beta^{(n)}||_1 <= ||M_*^{(n)} - M_*||_1 + sum_j ||M_j^{(n)} - M_j||_1 -> 0`. Since `sum_C nu(C) eta_{i,C} = int eta_i^{(n)} dnu` and `(M_i - r_i)_+ = 0` `nu`-a.e. under two-top a.e., both sums tend to zero. ### 1.4 Exact theorem statements for the paper

Setting. `X = [0,1]^D`, `D = Kd`; profiles `X_t` i.i.d. `nu`, an arbitrary Borel probability measure, exogenous and independent of all reward seeds, platform coins, and ex ante randomization; capacities `M_j : [0,1]^d -> [0,1]` and intrinsic means `mu_j <= M_j` Borel. `M_*(X) := max_j M_j(x_j)`, `T(X) := {j : M_j(x_j) = M_*(X)}`, `r_i(X) := max_{j != i} M_j(x_j)`, `U_i := {X : M_i(x_i) > r_i(X)}` (agent `i` is the unique top). Static Grid-ETC with `h_n` a dyadic width within a constant factor of `n^{-1/(D+3)}`, `J_n = h_n^{-D}`, `q_n = ceil(n^{2/(D+3)})`, one uniform priority permutation per cell, exploitation rewards ignored. For a positive-mass cell `C`, `bar M_{j,C} := E[M_j | C]`, `eta_{i,C} := (bar M_{i,C} - max_{j != i} bar M_{j,C})_+`, `beta_C := E[M_* | C] - max_j bar M_{j,C}`, `c_1 := 2 e^{-1/2}`.

Theorem C3.1 (public restricted equilibrium under two tops almost everywhere). Assume `nu(|T(X)| >= 2) = 1` and `M_*` public. Then for every `n >= 1`, every agent `i`, and every unilateral deviation `m'` in `S_HDS` (deterministic feasible map or independent ex ante mixture),
`u_i(n; m', S^max_{-i}) - u_i(n; S^max) <= q_n J_n + c_1 n q_n^{-1/2} + n sum_C nu(C) eta_{i,C}`,
and `sum_C nu(C) eta_{i,C} -> 0`; hence the supremum over deviations is `o(n)` and `S^max` is an `S_HDS`-asymptotic equilibrium. No continuity, no closed null separator, no component structure, and no constant top set are assumed.

Theorem C3.2 (explicit rate). If in addition every `M_j` is `L`-Lipschitz on `[0,1]^d`, then `eta_{i,C} <= L sqrt(d) h_n` for every positive-mass cell and every `i`, hence for every `n`, `i`, and deviation,
`u_i(n; m', S^max_{-i}) - u_i(n; S^max) <= q_n J_n + c_1 n q_n^{-1/2} + L sqrt(d) n h_n <= (2^{D+1} + c_1 + L sqrt(d)) n^{(D+2)/(D+3)}`,
with a constant depending only on `D` and `L`, with no top versus non-top case split and no dependence on `K` beyond `D = Kd`.

Theorem C3.3 (revenue at all-maximum play; no top-set condition). For every `n >= 1`,
`P(n; S^max) >= E sum_{t <= n} M_*(X_t) - [K q_n J_n + (K-1) c_1 n q_n^{-1/2} + n sum_C nu(C) beta_C]`,
and `sum_C nu(C) beta_C -> 0` for Borel capacities, so the deficit is `o(n)`. If every `M_j` is `L`-Lipschitz, `beta_C <= L sqrt(d) h_n` and the deficit is at most `(K 2^{D+1} + (K-1) c_1 + L sqrt(d)) n^{(D+2)/(D+3)}`.

Proposition C3.4 (sharpness of the two-top condition). For agent `i` put `s_i := M_i` if `i` is strategic and `s_i := M_i - mu_i` if `i` is honest, and `W_i := U_i cap {s_i > 0}`. (a) If `nu(W_i) > 0`, choose `g_0 > 0` and Borel `A subset W_i` with `nu(A) > 0` on which `M_i(x_i) - r_i(X) >= g_0` and `s_i >= g_0`; then there are deviations `m'_n in S_HDS` (honest-feasible if `i` is honest) and an instance-dependent `n_0` with `u_i(n; m'_n, S^max_{-i}) - u_i(n; S^max) >= (g_0 nu(A)/32) n` for all `n >= n_0`. (b) If `nu(W_i) = 0` for every `i`, then `S^max` is an `S_HDS`-asymptotic equilibrium, by the bound of Theorem C3.1 with `eta_{i,C}` replaced by `min{eta_{i,C}, E[s_i 1_{U_i^c} | C]}`. Hence `S^max` is an `S_HDS`-asymptotic equilibrium if and only if `nu(W_i) = 0` for every `i`; an honest unique top with no downward slack is a knife-edge case that remains an equilibrium.

### 1.5 Complete proof text (adopted version)

Lemma A (cell law and factorization). Fix a positive-mass cell `C`. Let `E_C := (1{X_t in C})_{t <= n}`, `V_C` the visit count, `t_{C,1} < ... < t_{C,V_C}` the visit rounds, `N_C := (V_C - K q_n)_+`.
(i) Conditionally on `E_C`, the pairs `(X_{t_{C,k}}, U_{t_{C,k}})`, `k <= V_C`, are i.i.d. with law `nu(. | C)` tensor Uniform`[0,1]`, independent of the cell's permutations and priority and of the data of the other cells.
Proof: for every indicator sequence `e` of positive probability and Borel `A_t`, `B_t`, independence across rounds gives `P(X_t in A_t, U_t in B_t for all t, E_C = e) = prod_t nu(A_t cap C^{e_t}) Leb(B_t)` with `P(E_C = e) = prod_t nu(C^{e_t}) > 0`, and the quotient is a product law whose factor at a visit round is `nu(. | C)` tensor Uniform.
(ii) The exploration schedule (which rounds of `C` are exploration rounds and which agent each one serves) is a function of the contexts and the cell's permutations only, never of rewards; each agent occupies exactly one position per block, hence at most `q_n` exploration pulls per cell, and exactly `q_n` once `V_C >= K q_n`.
(iii) On `{V_C >= K q_n}`, conditionally on `E_C` and the cell's coins, each agent `j`'s `q_n` exploration observations are i.i.d. Bernoulli(`bar m_{j,C}`) with `bar m_{j,C} = E[m_j | C]` (by (i), they are functions of distinct coordinates of an i.i.d. sequence, and `P(U <= m_j(X)) = E[m_j(X)] = bar m_{j,C}` by Fubini). This is the step that uses a map fixed before play.
(iv) The commitment `hat I_C` is a function of the exploration data and the cell's coins, hence conditionally independent of the profiles at the exploitation visits, and its conditional law given `E_C` is the same for every indicator sequence with `V_C >= K q_n`; writing `p_{j,C}` for that probability, for every bounded Borel `w`,
`E[ sum_{k > K q_n}^{V_C} 1{hat I_C = j} w(X_{t_{C,k}}) ] = E[N_C] p_{j,C} E[w | C]`, and `E[N_C] <= E[V_C] = n nu(C)`.
(v) A zero-mass cell is visited with probability zero (`P(V_C >= 1) <= n nu(C) = 0`), so all cell sums are finite sums over positive-mass cells.

Lemma B (ETC tail, with the exact constant). Let `hat a`, `hat b` be averages of `q` i.i.d. `[0,1]`-valued observations with means `a < b` (no independence between the two samples needed), `Delta := b - a`. Then `P(hat a >= hat b) <= 2 exp(-q Delta^2/2)` and `Delta P(hat a >= hat b) <= c_1 q^{-1/2}` with `c_1 = 2 e^{-1/2}`.
Proof: if `hat a >= hat b` then `hat a - a >= Delta/2` or `b - hat b >= Delta/2`, since otherwise `hat a < a + Delta/2 = b - Delta/2 < hat b`; Hoeffding's inequality bounds each by `exp(-2 q (Delta/2)^2) = exp(-q Delta^2/2)`, and a union bound gives the first claim. For the second, `Delta P(hat a >= hat b) <= min{Delta, 2 Delta exp(-q Delta^2/2)} <= sup_{x >= 0} 2 x exp(-q x^2/2)`, and `x exp(-q x^2/2)` has derivative `exp(-q x^2/2)(1 - q x^2)`, so the supremum is at `x = q^{-1/2}` with value `q^{-1/2} e^{-1/2}`. QED.

Lemma C (pathwise commitment coupling). Fix agent `i` and feasible maps `m' <= m''` pointwise, all other maps equal; run both executions on the same contexts, reward uniforms, permutations, and priorities. Then in every cell the exploration rounds and their assigned agents coincide; `hat m'_{i,C} <= hat m''_{i,C}` because `1{U_t <= m'(X_t)} <= 1{U_t <= m''(X_t)}` at the same round and the same profile; the rivals' empirical means are identical; and `{hat I'_C = i} subset {hat I''_C = i}` pathwise, including ties, because if `i` is a maximizer under `m'` and wins its ties by priority, then under `m''` its score is no smaller, the rivals' scores are unchanged, so `i` is still a maximizer and any rival tying with it under `m''` also tied under `m'` and lost the same priority comparison. Hence `p'_{i,C} <= p''_{i,C}`. The coupling is legitimate because, by Lemma A(ii), the round of agent `i`'s `r`-th exploration pull in a cell is the same in both executions.

Proposition D (per-cell inequality). Fix agent `i`, a deterministic feasible deviation `m'`, rivals at `S^max`, and a positive-mass cell `C`. With `a_C := E[1 + mu_i - M_i | C] in [0,1]`, `delta_C := E[M_i - m' | C] in [0,1]`, and `p'_C <= p_C` from Lemma C, the exploitation gain in `C` satisfies
`G_C = E[N_C] [p'_C (a_C + delta_C) - p_C a_C] <= E[N_C] p'_C delta_C <= E[N_C] min{delta_C, c_1 q_n^{-1/2} + eta_{i,C}} <= n nu(C) (c_1 q_n^{-1/2} + eta_{i,C})`.
Proof: `a_C >= 0` since `M_i <= 1 <= 1 + mu_i`, and `p'_C <= p_C`, giving the first inequality. Let `j^*` attain `max_{j != i} bar M_{j,C}` and `Delta' := bar M_{j^*,C} - (bar M_{i,C} - delta_C) = delta_C - (bar M_{i,C} - max_{j != i} bar M_{j,C})`. If `Delta' > 0`, then `{hat I'_C = i} subset {hat m'_{i,C} >= hat m_{j^*,C}}`, and by Lemma A(iii) the two empirical means are averages of `q_n` i.i.d. Bernoulli samples with means differing by `Delta'`, so Lemma B gives `p'_C Delta' <= c_1 q_n^{-1/2}` and therefore `p'_C delta_C = p'_C Delta' + p'_C (bar M_{i,C} - max_{j != i} bar M_{j,C}) <= c_1 q_n^{-1/2} + eta_{i,C}`. If `Delta' <= 0`, then `delta_C <= bar M_{i,C} - max_{j != i} bar M_{j,C} = eta_{i,C}` and the same bound holds. The trivial bound `p'_C delta_C <= delta_C` gives the minimum, and `E[N_C] <= n nu(C)`. QED.

Lemma E (exploration accounting). By Lemma C the exploration rounds of agent `i` coincide in the two executions, so their utility difference is the sum of `M_i(x_{i,t}) - m'(X_t) in [0,1]` over those rounds; by Lemma A(ii) there are at most `q_n` per cell and at most `J_n` cells, so the total lies in `[0, q_n J_n]`, for every `n`, including truncated blocks and cells never fully explored.

Proof of Theorem C3.1. `N_C` is a function of the contexts alone, hence has the same law under both profiles. Summing Lemma E and Proposition D over the positive-mass cells, and using `sum_C E[N_C] <= n` for the `c_1 q_n^{-1/2}` term and `E[N_C] <= n nu(C)` for the `eta` term, gives the displayed bound for every deterministic deviation, with a right-hand side independent of the deviation. For an independent ex ante mixture, condition on the realized map: the conditional law of the execution is that of the corresponding deterministic map, the bound is uniform over maps, and integrating preserves it. Convergence of `sum_C nu(C) eta_{i,C} = int eta_i^{(n)} dnu` to zero follows from the L1 lemma of Section 1.2 item 1 together with `(M_i - r_i)_+ = 0` `nu`-a.e.: indeed `nu(|T| >= 2) = 1` means `nu(U_i) = 0` for every `i`, because `T(X)` is never empty and `{|T| = 1} = union_i U_i` disjointly, and on `{|T| >= 2}` any `i` has some `j != i` with `M_j(x_j) = M_*(X) >= M_i(x_i)`, so `M_i(x_i) <= r_i(X)`. Finally `q_n J_n <= 2^{D+1} n^{(D+2)/(D+3)}` and `c_1 n q_n^{-1/2} <= c_1 n^{(D+2)/(D+3)}`, so the whole bound is `o(n)` uniformly over deviations, which is Definition 1. QED.

Proof of Theorem C3.2. For `X, X' in C` and any `j`, `|x_j - x'_j| <= sqrt(d) h_n` (the block `x_j` has `d` coordinates, each differing by at most `h_n`), so `M_j(x_j) <= M_j(x'_j) + L sqrt(d) h_n`; integrating in `X'` over `nu(. | C)` gives `M_j(x_j) <= bar M_{j,C} + L sqrt(d) h_n` for every `X in C`. Under `nu(U_i) = 0` we have `M_i(x_i) <= r_i(X) = max_{j != i} M_j(x_j) <= max_{j != i} bar M_{j,C} + L sqrt(d) h_n` for `nu`-a.e. `X in C`; integrating over `nu(. | C)` gives `bar M_{i,C} <= max_{j != i} bar M_{j,C} + L sqrt(d) h_n`, that is `eta_{i,C} <= L sqrt(d) h_n`. Insert into Theorem C3.1 and use `sum_C nu(C) = 1` and `n h_n <= n^{(D+2)/(D+3)}`. QED.

Proof of Theorem C3.3. Under `S^max` the deficit is `E sum_t [M_*(X_t) - M_{I_t}(x_{I_t,t})]`, each term in `[0,1]`. Exploration contributes at most `K q_n` per cell and at most `K q_n J_n` in total. For the exploitation part of a positive-mass cell, apply Lemma A(iv) with `w := M_* - M_j` and sum over `j`, using `sum_j p_{j,C} = 1`: the deficit is `E[N_C] (beta_C + sum_j p_{j,C} (max_l bar M_{l,C} - bar M_{j,C}))`. For each `j` with a positive gap to a best agent `j^*`, `{hat I_C = j} subset {hat m_{j,C} >= hat m_{j^*,C}}`, so Lemma B bounds its contribution by `c_1 q_n^{-1/2}`, and at most `K - 1` agents contribute. Summing with `E[N_C] <= n nu(C)` gives the display. Convergence of `sum_C nu(C) beta_C` to zero is the L1 lemma applied to `M_*` and to each `M_j`, since `M_*(X) - max_j M_j(x_j) = 0` pointwise. Under `L`-Lipschitz capacities, `M_*(X) = max_j M_j(x_j) <= max_j bar M_{j,C} + L sqrt(d) h_n` for every `X in C` by the one-step bound of the previous proof, and integrating gives `beta_C <= L sqrt(d) h_n`. No top-set condition is used anywhere. QED.

Proof of Proposition C3.4. (a) Choose `g_0` and `A` by continuity from below applied to `A_m := {M_i - r_i >= 1/m} cap {s_i >= 1/m}`, whose union is `W_i`. Call a cell `C` good if `nu(C) > 0`, `nu(A | C) >= 1/2`, and `gamma_C := bar M_{i,C} - max_{j != i} bar M_{j,C} >= 3 g_0/4`; let `Good_n` be the union of the good cells at scale `h_n`, and set `m'_n := M_i - (g_0/2) 1_A 1_{Good_n}`, which is Borel, feasible, and honest-feasible when `i` is honest because `s_i >= g_0` on `A`. On a cell that is not good the two maps agree `nu`-a.e., so the executions coincide almost surely and the gain there is zero. On a good cell, `delta_C = (g_0/2) nu(A | C) in [g_0/4, g_0/2]` and for every rival `j`, `bar m'_C - bar M_{j,C} >= gamma_C - g_0/2 >= g_0/4`, so `{hat I'_C != i} subset union_{j != i} {hat m_{j,C} >= hat m'_{i,C}}` has probability at most `rho_n := 2 (K-1) exp(-q_n g_0^2/32)` by Lemma B, whence the per-exploitation-visit gain is at least `p'_C delta_C - (p_C - p'_C) a_C >= (1 - rho_n) g_0/4 - rho_n`, which is at least `g_0/8` once `rho_n <= g_0/(8 + 2 g_0)`. The exploration change is nonnegative by Lemma E. The good cells carry mass at least `nu(A)/2` for all large `n`: on `A` one has `1_A = 1` and `gap_i >= g_0`, so by Markov's inequality and the L1 lemma, `nu(A cap {nu(A | C_n(.)) < 1/2}) <= 2 ||1_A^{(n)} - 1_A||_1 -> 0` and `nu(A cap {gamma_{C_n(.)} < 3 g_0/4}) <= (4/g_0) ||gamma^{(n)} - gap_i||_1 -> 0`. Finally `N_C >= V_C - K q_n` and `K q_n J_n <= K 2^{D+1} n^{(D+2)/(D+3)} <= n nu(A)/4` for large `n`, so the gain is at least `(g_0/8)(n nu(A)/2 - n nu(A)/4) = (g_0 nu(A)/32) n`. (b) If `i` is strategic, `W_i = U_i`, so `nu(U_i) = 0` and Theorem C3.1's bound applies. If `i` is honest, then `mu_i = M_i` `nu`-a.e. on `U_i`, so honesty and feasibility force `m' = M_i` `nu`-a.e. on `U_i` and therefore `M_i - m' <= (M_i - mu_i) 1_{U_i^c}` `nu`-a.e.; hence `delta_C <= E[(M_i - mu_i) 1_{U_i^c} | C]`, and Proposition D with `min{s, c + e} <= c + min{s, e}` gives the refined bound. Its remainder tends to zero because `E[(M_i - mu_i) 1_{U_i^c} | C_n(.)] -> (M_i - mu_i) 1_{U_i^c}` and `eta_i^{(n)} -> (M_i - r_i) 1_{U_i}` in `L^1`, and at every point one of the two limits vanishes, so the minimum tends to zero in `L^1`. QED.

### 2.2 The P1 finding: C1 is not the algorithm in the experiments

The manuscript describes cell-local "local-time UCB1" and the experiment code (`scratch/experiments/final/contextual_performance/run.py`, class `CellUCB`) computes the index with `np.log(max(2, n.sum()))`, where `n.sum()` is the number of visits the cell has already received. The adversary reported that this index is not pathwise monotone. My first reconstruction failed to reproduce it because I used the log of the current visit index rather than of the visits already made. With the code's own convention my exhaustive search over all 0/1 tapes reproduces the adversary's instance exactly:

K = 3, six cell visits, fixed priority (0,1,2), index `hat m_a + sqrt(2 log(max(2, v-1)) / T_a)`; agent 0's tape `(0,0,0,0,0,0)` raised pointwise to `(1,0,0,0,0,0)`, agent 1 `(0,0,0,0,0,0)`, agent 2 `(1,0,0,0,0,0)`. Base pulls `0,1,2,2,2,0` giving counts `(2,1,3)`; raised pulls `0,1,2,0,2,1` giving counts `(2,2,2)`. Agent 1's count RISES from 1 to 2. Three such instances exist at six visits. Control: the known-horizon index shows 0 violations at five, six and seven visits, and the log-of-current-visit variant shows its first failure at eight visits, which is exactly the scalar anytime tape of Claim L3 (in a one-cell instance local time equals the global round).

Structural reason: the race lemma requires each arm's index to be a fixed function of its own count and own reward prefix. `sqrt(c log n / T_a)` qualifies because `n` is a constant of the instance; any local-time or anytime bonus does not.

Consequence: adopting C1 changes the rule that was simulated. Either the contextual experiments are re-run with the known-horizon index, or the paper states plainly that the simulated variant is a different rule for which only robustness is proved. This is a P1 item for the experiments lead and the main agent, not a defect in the mathematics.

### 2.3 The one apparent conflict between the provers, resolved

Prover 1 proves (its Proposition 2.6) that exact expected monotonicity survives fresh per-round uniform tie coins; prover 2 lists the same statement as open and does not use it. This is not a contradiction: prover 2's counterexample is for the NATURAL coupling that gives both runs the same coin at the same round, and prover 1 agrees that the pathwise statement fails there (its Fact 2.6.1, with its own tape). Prover 1's proposition constructs a DIFFERENT coupling with correct marginals, so the expectation conclusion is legitimate.

I verified prover 1's proof myself, step by step, because a majority is not evidence and prover 2 declined to assert it. Step 1 represents the per-round uniform tie rule with two independent coin families, one indexed by the number of non-arm-1 pulls and one by the round, and the conditional probability of each maximizer is exactly `1/|S_t|` in all three cases, including the case where arm 1 is in the tie set and the arm-1 branch consumes no coin of the first family. Step 2 shows the sequence of non-arm-1 pulls is a deterministic function of the first coin family and of the other arms' sequences, because at any such pull the tie set minus arm 1 is exactly the argmax among the other arms. Step 3 is a first-violation argument in which both runs are in the same state and see the same coin, so a raise cannot cost arm 1 that pull. Step 4 converts arm 1's gain into the other arms' loss through the common non-arm-1 sequence. The argument is correct.

Consequence, and it reduces the cost of adopting C1: the manuscript already specifies independent uniform tie-breaking per round and a uniform random initialization order, and the SAMF definition is an expectation statement. So the tie rule does NOT have to change. The only change the paper must make is the index, from `sqrt(2 log t / T)` to the known-horizon `sqrt(4 log n / T)`. A fixed uniform priority is needed only if one wants the pathwise scalar statement, which is a bonus, not a requirement.

### 2.6 What the paper should state

Theorem (Static Grid KH-UCB is contextual SAMF at exponent (D+1)/(D+2)). Let `X = [0,1]^D`, `D = Kd`, profiles i.i.d. `nu` and exogenous, agents in `S_HDS`. Run cell-local UCB on a fixed grid of side `h_n = (log(en)/n)^{1/(D+2)}` with `J_n = O(h_n^{-D})` cells, index `hat m_a + sqrt(4 log n / T_a)` with the GLOBAL horizon `n` and the agent's LOCAL count in the cell, cell-blind decisions, coins drawn independently of the contexts. Then for every `n >= 2`:
(i) sharp adaptivity for every agent and EVERY measurable `R`, with remainder `L sqrt(d) n h_n + 4 sqrt(J_n n log n) + 3 min{J_n, n} + n nu((partial R)^{sqrt(D) h_n})`, under `L`-Lipschitz intrinsic means;
(ii) robustness `P(n) >= E sum_t b(X_t) - [L sqrt(d) n h_n + 8 sqrt(K J_n n log n) + 3 K min{J_n, n}]`;
(iii) exact expected contextual monotonicity, zero remainder, for EVERY measurable `R` and every `n`, with no regularity and no boundary condition, and for any pointwise raise of one agent's map, not only the raise to capacity;
(iv) expected FATA on `G_{ij}(R)` with remainder `n nu((partial G)^{sqrt(D) h_n})`;
(v) revenue `P(n; S^max) >= E sum_t M_*(X_t) - [L sqrt(d) n h_n + 8 sqrt(K J_n n log n) + 3 K min{J_n, n}]` under `L`-Lipschitz capacities;
(vi) if capacities are `L`-Lipschitz and `nu(|T(X)| >= 2) = 1`, every unilateral `S_HDS` deviation gains at most `L sqrt(d) n h_n + 4 sqrt(J_n n log n) + 3 min{J_n, n} = O(n^{(D+1)/(D+2)} (log n)^{1/(D+2)})`, uniformly over deviations and over independent ex ante mixtures.
The first three terms in each display are `O(n^{(D+1)/(D+2)} (log n)^{1/(D+2)})`. No minimax optimality in `D` is claimed.

Scalar and finite-context corollaries (C0): with the same index and the manuscript's per-round uniform tie-breaking, scalar UCB is stochastic SAMF with sharp-adaptivity error `4 sqrt(n log n) + 3` and EXACT monotonicity (zero remainder, replacing the current `o(n)` that is only pointwise in fixed profiles); with one uniform priority fixed before play the monotonicity is in addition pathwise, on every sample point, and also against blind own-history behavioural strategies of the other agents. Finite-context UCB inherits both, with monotonicity exact for every region and pathwise given the arrivals.

Remark to include (five lines): the anytime index is not pathwise monotone, with the explicit three-agent, eight-round tape; this is what motivates the known-horizon index. Both the ledger's tape and prover 2's independently found tape are the same counts, `(2,1,5)` against `(2,2,4)`.

The blind behavioural extension is scalar only and fails as soon as an agent observes the profile, so no contextual behavioural class is claimed. No optimality in `D`.
