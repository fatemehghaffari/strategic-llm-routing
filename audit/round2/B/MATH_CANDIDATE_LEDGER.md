## 1. Candidate C1: known-horizon Static Grid-UCB as a full contextual SAMF mechanism at the sharper rate

Exact theorem (target statement for the pipeline). Let X = [0,1]^D with profiles i.i.d. nu, intrinsic means L-Lipschitz, capacities Borel. Static Grid-UCB(n): deterministic partition into half-open cubes of side h_n = (log(en)/n)^{1/(D+2)} (J_n = ceil(1/h_n)^D cells), one lazily initialized cell-local instance per cell with index `hat m_a + sqrt(4 log n / T_a)` (the global horizon n in the logarithm, local count T_a), initialization and all ties by one uniformly random priority permutation drawn per cell before play, cell-blind decisions. Then uniformly over S_HDS (and independent mixtures), with constants depending only on K, D, L:
(i) contextual sharp adaptivity for every agent i and every R: remainder `2 L sqrt(D) n h_n + C sqrt(K J_n n log n) + C K J_n + n nu((partial R)^{sqrt(D) h_n})`, the first three terms being O(n^{(D+1)/(D+2)} (log n)^{1/(D+2)});
(ii) global robustness `P(n) >= E sum_t b(X_t) - O(n^{(D+1)/(D+2)} (log n)^{1/(D+2)})` (this is thm:grid-ucb-robust, already in the manuscript with the anytime index; unchanged);
(iii) exact expected contextual monotonicity: for every allowed map profile, every i != j, and EVERY measurable R (no boundary condition), replacing m_i pointwise by M_i gives `E T_j(R; n)` no increase, with zero remainder, for every n;
(iv) expected FATA on G_{ij}(R) with remainder `n nu((partial G_{ij}(R))^{sqrt(D) h_n})`;
(v) revenue at all-maximum play `P(n; S^max) >= E sum_t M_*(X_t) - O(n^{(D+1)/(D+2)} (log n)^{1/(D+2)})` if capacities are L-Lipschitz;
(vi) public restricted equilibrium: if capacities are L-Lipschitz and `nu(|T(X)| >= 2) = 1`, every unilateral S_HDS deviation by any agent gains at most `C sqrt(K J_n n log n) + C K J_n + 2 L sqrt(D) n h_n = O(n^{(D+1)/(D+2)} (log n)^{1/(D+2)})`.

Assumptions: i.i.d. exogenous profiles; fixed ex ante maps (S_HDS); Lipschitz intrinsic means for (i), (ii); Lipschitz capacities for (v), (vi); two-top a.e. for (vi); known horizon.

## 3. Candidate C3: continuous public equilibrium without finite components, closed null boundaries, or continuity

Exact theorem (Grid-ETC version, scout B3 Theorem C.1 as stated in its summary, reconstructed and checked by the lead). Static Grid-ETC on nested dyadic grids (h_n = 2^{-k_n} with k_n = ceil(log_2(n)/(D+3)), so n^{-1/(D+3)}/2 < h_n <= n^{-1/(D+3)}, J_n = h_n^{-D}, q_n = ceil(n^{2/(D+3)})). Let nu be any Borel law on [0,1]^D and the capacities Borel with `nu(|T(X)| >= 2) = 1`. (a) All-maximum play is an S_HDS-asymptotic equilibrium (including independent mixtures): every unilateral deviation by any agent i gains at most `q_n J_n + c_1 n q_n^{-1/2} + n sum_C nu(C) eta_{i,C}` with `c_1 = 2 e^{-1/2}` and `eta_{i,C} := (bar M_{i,C} - max_{j != i} bar M_{j,C})_+`, and `sum_C nu(C) eta_{i,C} -> 0` by Levy's upward theorem along the dyadic filtration (cell averages of the bounded Borel functions M_j converge nu-a.s. to M_j(X), and `(M_i - max_{j != i} M_j)_+ = 0` nu-a.s.). (b) If in addition capacities are L-Lipschitz, `eta_{i,C} <= 2 L sqrt(D) h_n` in every positive-mass cell and the gain is at most `(2^{D+1} + c_1 + 2 L sqrt(D)) n^{(D+2)/(D+3)}`, with no top/non-top case split and no K-dependence beyond D. (c) Revenue: `P(n; S^max) >= E sum_t M_*(X_t) - (K 2^{D+1} + (K-1) c_1 + 2 L sqrt(D)) n^{(D+2)/(D+3)}` under Lipschitz capacities with NO top-set condition, and `o(n)` under mere measurability.

Lead's check of the per-cell inequality (the only nonroutine step). In a cell C with expected exploitation visits N_C, deviating cell mean `bar M_{i,C} - delta_C`, baseline per-pull utility `a_C = E[1 + mu_i - M_i | C] >= 0`: by the coupling of appendix A.4 the commitment indicator of i under the deviation is at most that under S^max, so `p'_C <= p_C` and `gain_C = N_C [p'_C (a_C + delta_C) - p_C a_C] <= N_C p'_C delta_C`. Let `Delta' := max_{j != i} bar M_{j,C} - (bar M_{i,C} - delta_C) >= delta_C - eta_{i,C}`. If `Delta' > 0`, Lemma lem:etc-tail gives `p'_C Delta' <= c_1 q_n^{-1/2}`, hence `p'_C delta_C <= p'_C (Delta' + eta_{i,C}) <= c_1 q_n^{-1/2} + eta_{i,C}`; if `Delta' <= 0` then `delta_C <= eta_{i,C}`. Exploration utility differs by at most q_n per cell. Summing over cells gives (a). Under L-Lipschitz capacities, any positive-mass cell contains X_0 with |T(X_0)| >= 2, hence some j != i with `M_j(x_j) >= M_*(X_0) - L|x - X_0| >= M_i(x_i) - 2 L sqrt(D) h_n` for all x in C, so `eta_{i,C} <= 2 L sqrt(D) h_n`, giving (b). For (c), `max_j bar M_{j,C} >= bar M_C - 2 L sqrt(D) h_n` by the same argument applied to any top agent at any point, and each non-best agent contributes at most `c_1 q_n^{-1/2}` per exploitation visit. This corrects the lead's Claim L5, which used `bar M_C` where `bar M_{i,C}` is needed (the two agree only when i is top on the whole cell).

Necessity (scout B3 Theorem F.1, statement checked by the lead, proof not on disk): agent i has a unilateral S_HDS deviation with linear gain iff `nu(W_i) > 0`, where W_i is the set where i is the unique top (intersected with `mu_i < M_i` for an honest agent). The "if" direction is elementary: shade by half the gap on W_i; the "only if" direction is (a). Knife-edge honest unique tops without slack remain equilibria, as in the scalar remark.

Strongest counterexamples: to the CURRENT assumptions, not to the new theorem: Example A.1 (fat Cantor shared-top set: no closed null B exists, yet the new theorem applies; the rate degrades to O(n h_n^{1/2}) for discontinuous capacities, computed exactly); Example A.2 (countably many components: the current proof works verbatim, "finitely" is redundant); Example A.3 and Attack 4 (changing top-pair identity, and a nowhere-top agent that is cell-best in mixed cells: the manuscript's step (S2) and its non-top argument are false cell by cell, but the eta term controls the gain); Attack 9 (the lazy deviation of an agent with a_C = 0 attains `q_n J_n (1 - o(1))`, so the exponent (D+2)/(D+3) is tight for Grid-ETC).

Novelty: relative to the manuscript, removes three structural assumptions (finite components, closed nu-null separator, constant top set per piece) and continuity, replaces them with the sharp condition two-top a.e., and gives an explicit rate plus a necessity characterization; relative to the literature, the two-top condition is from Esmaeili et al. (scalar, deterministic), the contextual version and the dyadic-martingale argument appear new (no primary source found claiming them).

Rate: O(n^{(D+2)/(D+3)}) explicit under Lipschitz capacities; o(n) without rate under measurability; the UCB analogue is O(n^{(D+1)/(D+2)} (log n)^{1/(D+2)}) (C1 (vi)).

Dependencies: Lemma lem:cell-law; Lemma lem:etc-tail; the pathwise ETC coupling of appendix A.4; Levy's upward theorem (standard; cite a textbook, e.g. Williams, Probability with Martingales, Theorem 14.2, to be verified by the provers); nested dyadic grids (the manuscript's "dyadic width within a constant factor" must be fixed to k_n = ceil(log_2(n)/(D+3))).

Page cost: negative. The new theorem statement is shorter than thm:contextual-public and the proof (per-cell inequality, one sum, one martingale convergence sentence) is about half the length of the current appendix A.5.

Recommendation: SELECT for the two-prover pipeline (second priority; the ETC version is independent of C1, the UCB version shares C1's deficit lemma). Provers must write the Levy argument with the exact filtration, treat cells of zero mass, prove the necessity direction with an explicit constant, and confirm the lem:etc-tail constant c_1.

## 4. Candidate C2: finite-context private incentives (Local-MESP), lead's assessment in place of scout B4

Mechanism (Local-MESP). Finite profile set X_F = {z_1, ..., z_Q}. Parameters from the GLOBAL horizon: `L := ceil(n^{2/3} (log(en))^{1/3})`, `s := sqrt(log(2 K n^4)/(2 L))`, `b(r) := sqrt(r log(2 n^4)/2)`. For each profile z, an independent local instance driven by the visits to z: local Stage 1 (the first K L visits to z, agents in a fixed reward-independent order, L pulls each, local bids beta_i(z)); local winner W_z by an independent uniform priority; local price `tau_z := (beta_(2)(z) - s)_+` announced to the selected agent at every later z-visit; local Stage 2 (pull W_z at each z-visit, monitor `Z_r < r tau_z - b(r)` on its r-th local primary pull); local Stage 3 (fresh explicit-exploration EXP3 over all agents restarted in doubling epochs of planned local lengths 2^0, 2^1, ..., each epoch with `gamma_k = min{1/2, sqrt(K log K / 2^k)}`, `eta_k = gamma_k / K`, fresh weights; no knowledge of the remaining local horizon is needed). If a profile receives fewer than K L visits, all its visits are bidding pulls. Messages revealed: the profile z (the agent observes X_t anyway), the local phase, tau_z in the primary phase. Proposed profile S^*: capacity M_i(z_i) in local bidding and local fallback; local primary winner delivers `min{tau_z, M_i(z_i)}` (honest: `max{mu_i(z_i), min{tau_z, M_i(z_i)}}`).

Exact theorem (target statement). Fix K >= 2, a finite X_F, an instance with nonempty honest set, and an exogenous arrival process (X_t) independent of all reward seeds, priorities, EXP3 coins, and private coins (i.i.d. is NOT required; the platform need not know the masses). Targets are chosen before fresh conditionally independent Bernoulli seeds. Then, with `R^dbl_K(H) := C_0 (sqrt(K H log K) + K log K log_2(2H))` for an absolute C_0 (to be fixed by the provers; the doubling sum of R_K(2^k) over epochs gives C_0 <= 11):
(i) additive behavioral equilibrium in the class B^ctx_{i,n} of the contract (deviations may depend on the deviator's entire cross-profile history and the current profile): for every i,
`sup [u_i(n; S'_{i,n}, S^*_{-i,n}) - u_i(n; S^*_n)] <= Q L + sum_z [2 b(V_z) + R^dbl_K(V_z)] + O(1) + sum_{z : i non-top at z} O(1 + log n / delta_i(z)^2 + R^dbl_K(n) / delta_i(z))`, in expectation over arrivals, which is `O(Q n^{2/3} (log n)^{1/3} + sqrt(Q K n log(Kn)) + Q K log K log n)` plus instance constants, and o(n) iff `Q = o(n^{1/3} (log n)^{-1/3})`;
(ii) revenue `P(n; S^*) >= E sum_t M_(2)(X_t) - O(Q K L + n s + sqrt(Q K n log K) + Q K log K log n)`, where M_(2)(z) is the second-largest capacity at z counting ties;
(iii) honest-benchmark robustness `P(n; S) >= E sum_t b(X_t) - O(Q K L + n s + sqrt(Q n log n) + sqrt(Q K n log K) + Q K log K log n)` for every feasible behavioral profile S (all agents may deviate, cross-profile adaptively).

Proof plan (lead's; every step is a local instantiation of the scalar proof, with the changes listed).
1. Condition on the arrival sequence. By exogeneity, conditional on (X_t)_t all uniforms, priorities, coins remain independent with their original laws, every local visit count V_z and every local round schedule is deterministic, and the deviation class conditional on arrivals contains the original class. All bounds below are then integrated over arrivals.
2. Per-profile coupling. Index reward uniforms by (profile, agent, local pull index). Other agents follow S^*, which is local-Markov (targets depend only on the local phase and tau_z), so their Stage-1 rewards at z, hence tau_z, are identical in the deviating and baseline executions. The deviator's Stage-1 rewards at z satisfy `1{U <= m'} <= 1{U <= M_i(z_i)}` pathwise for any predictable m' (cross-profile dependence allowed), so `{deviation wins at z} subseteq {maximum bidding wins at z}` with the same price.
3. Local monitor. Lemma lem:private-monitor holds for targets predictable with respect to the GLOBAL filtration (the martingale differences Y - m on the deviator's primary pulls at z have conditional mean zero given everything before the pull); the union over r <= n covers every local length since V_z <= n. Failure probability n^{-3} per profile.
4. Local fallback. Per epoch, conditional on the epoch start, the selected-reactive EXP3 lemma holds for any realized epoch length H' <= 2^k (the potential inequality telescopes over any prefix; H' is deterministic given arrivals), giving loss at most R_K(2^k) with gamma tuned to 2^k; summing over the at most log_2(2 H_z) epochs gives R^dbl_K(H_z). The comparator is a nondeviating agent of capacity V_i(z) (for incentives) or the honest agent attaining b(z) (for robustness).
5. Accounting per profile, exactly the scalar case with n replaced by V_z in phase lengths and with the tightened top-agent bound of `PRIVATE_BOUND_NOTES.md` (no 2 n s term): top-at-z: gain at most `L + 1 + 2 b(V_z) + R^dbl_K(V_z) + O(n^{-2})`; non-top-at-z (delta_i(z) := V_i(z) - M_i(z_i) > 0): for n with `2 s <= delta_i(z)/2`, gain at most `L + O(1 + log n / delta_i(z)^2 + R^dbl_K(V_z)/delta_i(z))`, and at most V_z otherwise (absorbed into instance constants); profiles with V_z < K L: gain at most L. Bad events: Q (n^{-4} + n^{-3}) each costing at most 2n.
6. Sum over z with `sum_z sqrt(V_z) <= sqrt(Q n)`.
7. Revenue and robustness: per profile as in the scalar proof (price within 2s of M_(2)(z) on the local good event; honest bid at least b(z) - s; monitor charges the primary at rate tau_z; fallback comparator), plus Stage-1 charge K L per profile.

Proof status: INCOMPLETE (complete plan, no independently checked write-up; the scout produced no text). Delicate points the provers must settle: (a) legitimacy of conditioning on arrivals when agents may know future arrivals (fine: the class only grows); (b) the per-epoch EXP3 lemma with the fixed-gamma potential argument over a prefix, and the constant C_0; (c) a deviator that uses one profile's history to time deviations at another (harmless because every local bound is uniform over globally predictable strategies, but this must be written with the global filtration explicit); (d) whether triggering fallback at z can change prices elsewhere (it cannot: tau_{z'} depends only on Stage-1 rewards at z'); (e) K = 2 and capacity ties per profile (covered by the scalar proof's tie handling); (f) profiles with tiny mass where bidding never completes and the deviator harvests bidding utility (bounded by L per profile, already in Q L).

## 6. Secondary directions (lead's assessment in place of scout B5)

6.1 Minimax lower bounds. Rigollet and Zeevi Theorem 4.1 embeds in the honest special case of our model: K = 2, both agents honest with mu_i = M_i, agent 2 constant 1/2, agent 1's mean a (1, L)-smooth function of ITS OWN context x_1 in [0,1]^d with margin alpha (alpha < 1), x_1 uniform; honest agents deliver exactly their intrinsic means, and the platform's robustness loss equals the regret. Hence every mechanism has robustness loss at least `C n^{1 - (1+alpha)/(2+d)}` on some such instance, for every alpha in (0,1), so no exponent below (d+1)/(d+2) is attainable in the PER-AGENT dimension d. This does not show that the manuscript's exponent (D+1)/(D+2) in D = Kd is optimal; the D-dimensional grid is forced only by the strategy class: with per-agent cells (a grid on [0,1]^d per agent, statistics pooled over the other agents' contexts) a fixed full-profile map can correlate its delivered mean with the other agents' cells; the lead's sketch: one honest agent h with mu_h = 0.2 on cell A and 0.9 on cell B (equal masses), one strategic agent with constant own context delivering 1 when h is in A and 0 when h is in B; per-agent UCB drives the strategic agent's pooled estimate to about 0.9, which is attained when it is selected in about 11 percent of the B rounds, each losing 0.9, a linear robustness loss. Classification: PROVED that the (d+1)/(d+2) exponent is a lower bound for the honest case in the per-agent dimension (by citation of Theorem 4.1 with the embedding above, which the provers should write out); OPEN whether Omega(n^{(D+1)/(D+2)}) holds for any mechanism against S_HDS; PROVED (Attack 9 of B3) that Grid-ETC's own exponent (D+2)/(D+3) is attained by the lazy deviation, so its rate cannot be improved by analysis alone, and C1 is the way to (D+1)/(D+2). A per-agent grid under a product law nu and own-context-only strategy maps would satisfy a per-agent cell law and plausibly achieve n^{(d+1)/(d+2)} via a sleeping-bandit UCB analysis; monotonicity under availability-dependent competition is unclear. Classification: OPEN, precise problem recorded.

6.2 Unknown horizon. Doubling with fresh statistics per epoch preserves all grid results with the same rates (C4 (c), PROVED modulo black boxes) and pathwise monotonicity (each epoch is a separate coupled execution). For MESP, restarting the whole mechanism in doubling epochs gives per-epoch equilibrium gains O(n_k^{2/3} (log n_k)^{1/3}) summing to O(n^{2/3} (log n)^{1/3}) provided agents know the epoch schedule and the per-epoch profile S^*_k is the proposed one; each epoch's bounds are uniform over predictable strategies given the past, so cross-epoch adaptivity is covered. Classification: PROVED IN OUTLINE, routine; recommended as a one-sentence remark only.

6.3 Oblivious (non-i.i.d.) contexts. Lemma lem:cell-law fails (contract Section 11 item 5). A cell-local adversarial rule (per-cell selected-reactive EXP3) competes only with the best fixed agent per cell against the realized within-cell sequence, at cost `sum_C R_K(V_C) <= 3 sqrt(K J_n n log K) + 2 K log K J_n`; comparing to the pointwise honest benchmark needs the Lipschitz bound `b(X_t) <= m_{h_C}(X_t) + 2 L sqrt(D) h_n` pathwise, which holds for honest maps, so robustness `P(n) >= sum_t b(X_t) - 2 L sqrt(D) n h_n - 3 sqrt(K J_n n log K) - 2 K J_n log K` holds against ANY nonanticipating behavior and ANY exogenous context sequence (the honest comparator in each cell delivers at least b(X_t) - 2 L sqrt(D) h_n at every visit, which is what the selected-reactive lemma needs). Rate O(n^{(D+1)/(D+2)} sqrt(log K)) at h_n = n^{-1/(D+2)}. No monotonicity, FATA, or equilibrium. Classification: PROVED IN OUTLINE (the per-cell lemma is the manuscript's Lemma lem:selected-reactive-exp3 with a known cell horizon replaced by doubling, as in C2 step 4); this is a genuinely stronger robustness statement (behavioral agents, arbitrary contexts) and is cheap: about 0.2 page. Recommended as a candidate remark or short theorem if the provers confirm the epoch lemma (shared with C2).

6.4 Bounded or sub-Gaussian rewards. All couplings use `Y = 1{U <= m}`; for general reward families the analogous statements need first-order stochastic dominance in the target, realized by inverse-CDF coupling; the monitor and EXP3 lemmas need only bounded rewards. Not pursued; OPEN, low value.

6.5 Growing K. Scalar: robustness K sqrt(n log n); MESP: K L_n bidding rounds and R_K = O(sqrt(K n log K)), so o(n) needs K = o(n^{1/3} (log n)^{-1/3}); grids: exponential in K through D = Kd. Remark only.

6.6 Lower bound for the private n^{2/3} rate. For MESP as specified: PROVED (Section 7.2) that a unique-top agent gains L_n (M_i - m') - 4 n^{-3} by Stage-1 underbidding, so the mechanism's equilibrium bound is tight in order. For all mechanisms: OPEN; the missing steps are a formal deviation class, an argument that any mechanism with second-capacity revenue must estimate the runner-up from at most o(n) exploration pulls of the runner-up, and the Omega(L^{-1/2}) estimation error of the price; the lead does not expect a clean statement in this cycle.
