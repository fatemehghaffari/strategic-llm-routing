# Scout B3: margin conditions and assumption relaxation for the continuous public equilibrium (17 September 2026)

Status line: IN PROGRESS. Sections are appended as they are finished; a section that is not yet present has not been written. Everything here is scout output for Agent B, not manuscript text. No canonical file was modified.

Conventions: `E` is expectation, `nu` the profile law on `[0,1]^D`, `D = Kd`, `M_*(X) = max_i M_i(x_i)`, `T(X) = {i : M_i(x_i) = M_*(X)}`, `V_i(X) = max_{j != i} M_j(x_j)`, `U_i = {X : M_i(x_i) > V_i(X)}` (agent `i` is the unique top). For a cell `C` with `nu(C) > 0` and a bounded measurable `f`, `E[f | C] = E[f(X) | X in C]`; `bar M_{j,C} = E[M_j(x_j) | C]`. `c_1 := 2 e^{-1/2} < 1.2131` is the explicit constant of Lemma lem:etc-tail (`Delta Pr(hat a >= hat b) <= c_1 q^{-1/2}`). `(x)_+ = max(x, 0)`. Grid cells are half-open dyadic cubes of side `h_n = 2^{-k_n}`; `J_n = h_n^{-D}` is the exact number of cells; `q_n = ceil(n^{2/(D+3)})`. "Nested dyadic grids" means `k_n` is nondecreasing in `n` with `k_n -> infinity` (true for `k_n = ceil(log_2(n)/(D+3))`, which gives `n^{-1/(D+3)}/2 < h_n <= n^{-1/(D+3)}`).

## Executive summary (written first so that an interruption still leaves the conclusion)

1. Claim L5 survives every attack in Section B, and it is in fact too weak. The correct statement needs neither Lipschitz capacities, nor continuity, nor a closed null boundary, nor finitely many components, nor constant top sets: for Static Grid-ETC on nested dyadic grids, for any Borel profile law `nu` on `[0,1]^D` and any Borel capacity maps, all-maximum play is an `S_HDS`-asymptotic equilibrium as soon as `nu(|T(X)| >= 2) = 1`. The tool that replaces continuity and dominated convergence is Levy's upward theorem along the dyadic filtration (cell averages of any bounded measurable function converge `nu`-a.s. to the function). Lipschitz capacities are needed only for the explicit rate.
2. Explicit rate (Theorem C.1, proved in Section C): under `L`-Lipschitz capacities and `nu(|T(X)| >= 2) = 1`, every unilateral `S_HDS` deviation by any agent `i` (top or not, honest or not, mixture or not) gains at most `q_n J_n + c_1 n q_n^{-1/2} + 2 L sqrt(D) n h_n <= (2^{D+1} + 2 e^{-1/2} + 2 L sqrt(D)) n^{(D+2)/(D+3)}`. There is no top/non-top case split and no `K`-dependence beyond `D = Kd`. The exponent is tight for Grid-ETC (Section B, attack 9: the lazy deviation of an agent with `mu_i = 0`, `M_i = 1` gains `q_n J_n (1 - o(1))`).
3. The revenue bound `P(n; S^max) >= E sum_t M_*(X_t) - (K 2^{D+1} + (K-1) c_1 + 2 L sqrt(D)) n^{(D+2)/(D+3)}` needs no top-set condition at all under Lipschitz capacities, and `o(n)` needs nothing but measurability (Theorem C.2).
4. Necessity is a clean characterization (Theorem F.1): agent `i` has a unilateral deviation with linear gain if and only if `nu(W_i) > 0`, where `W_i = U_i` for a strategic agent and `W_i = U_i cap {mu_i(x_i) < M_i(x_i)}` for an honest agent (`U_i` = the set where `i` is the unique top). Knife-edge cases (`nu(U_i) > 0` but `nu(W_i) = 0`, i.e. an honest unique top with no downward slack) remain equilibria.
5. Margin conditions `nu(0 < M_*(X) - M_i(x_i) <= eps) <= C_M eps^alpha` do not enter the deviation-gain bound at all (shading is a top-agent phenomenon); they improve the count of non-top selections at all-maximum play from an unquantified `o(n)` to `O(n^{1 - alpha/(D+3)} (log n)^{alpha/2})` for `alpha < 1` and are dominated by the exploration term `K q_n J_n = Theta(n^{(D+2)/(D+3)})` for `alpha > 1` with the manuscript's fixed parameters (Section E). They cannot replace the FATA boundary condition (Section E.4).
6. Known-horizon Static Grid-UCB (Section D) gives the analogous gain bound `O(n^{(D+1)/(D+2)} (log n)^{1/(D+2)})` conditionally on Claim L1 (own-count self-monotonicity), which is flagged as an unproved hypothesis; the per-cell deficit bound is imported from Lattimore and Szepesvari, Chapter 7.

## A. Inventory: where each assumption of thm:contextual-public is used in the current proof, and what breaks if it is dropped alone

The current proof is appendix_contextual.tex, lines 119 to 142 (file `sections/appendix_contextual.tex`). Its logical skeleton is: (S1) boundary cells (cells meeting `B`) cost at most `n nu(B^{sqrt(D) h_n}) = o(n)`; (S2) in an interior cell where `i` is top, pick another top agent `j`, whose cell mean equals `bar M_C = E[M_*(X) | C]`, and bound the per-visit gain by `p'_C delta_C = O(q_n^{-1/2})` via Lemma lem:etc-tail; (S3) in an interior cell where `i` is non-top, the cell-average gap `bar d_{i,C}` is positive, the commitment probability is at most `min{1, 2 e^{-q_n bar d_{i,C}^2/2}}`, and dominated convergence (using `bar d_{i,C_n(X)} -> d_i(X) > 0`) makes non-top exploitation selections `o(n)`; (S4) exploration savings are at most `q_n J_n`; (S5) conditioning extends to mixtures; (S6) revenue.

Example A.1 (closedness of `B` cannot be replaced by `nu(B) = 0` alone). `K = 3`, `d = 1`, `nu` uniform on the diagonal `{x_1 = x_2 = x_3 = u}` of `[0,1]^3` (so `nu` is not absolutely continuous in `[0,1]^3`, which the manuscript allows). Let `F subset [0,1]` be a fat Cantor set with `|F| = 1/2` (Section B, attack 2). Put `M_1 = 1`, `M_2(u) = 1_F(u)`, `M_3(u) = 1 - 1_F(u)`, all `mu = 0`. Then `T = {1,2}` on `F` and `T = {1,3}` off `F`, so `|T| = 2` everywhere. The set `B_0` where the top set is not locally constant is `partial F = F` (nonempty interior is absent), `nu(B_0) = 1/2 > 0`, so no closed null `B` with the manuscript's properties exists and thm:contextual-public does not apply. The relaxed Theorem C.2 does apply (measurable capacities, `|T| = 2` everywhere): the equilibrium holds with `o(n)` gain. The `eta` term for this instance is computed numerically in Section B (attack 2): it decays like `h_n^{1/2}` rather than `h_n`, so the rate is genuinely slower than the Lipschitz rate, but it still vanishes.

Example A.2 (finitely many components is redundant). Same geometry, `M_1 = 1`, `M_2(u) = 1 - (u sin^2(1/u))` for `u > 0`, `M_2(0) = 1`, `M_3 = 1`. All capacities continuous, `T = {1,3}` except on the countable closed null set `B = {0} cup {1/(k pi)}` where `T = {1,2,3}`; `X \ B` has countably many components (the intervals between consecutive zeros), each with constant top set `{1,3}` of size two. The current proof works verbatim (every cube disjoint from `B` lies in one component); only the word "finitely" is violated.

Example A.3 (constant top set is used and must be replaced by the `eta` term). `K = 3`, diagonal law, `M_1 = 1`, `M_2(u) = 1_{u < 1/3}`, `M_3(u) = 1_{u >= 1/3}` (the boundary is placed at `1/3` because `1/2` is an edge of every dyadic grid and would produce no straddling cell). In the cell `C` containing `1/3`, with left fraction `f in (0,1)`, `bar M_{2,C} = f`, `bar M_{3,C} = 1 - f`, `bar M_{1,C} = 1`. Agent 1 shading to `1 - min(f, 1-f) + 2/sqrt(q_n)` on `C` still beats both rivals with probability at least `1 - 4 e^{-2} > 0.45` (Lemma lem:etc-tail with gap `2/sqrt(q_n)` against each rival) and saves `min(f, 1-f) - 2 q_n^{-1/2}` per exploitation visit in `C`. With a single such cell the gain is `O(n h_n)`, harmless; the point is only that step (S2) as written is false for that cell, so the general proof must carry `eta_{i,C}`.

Minimal counterexample where an assumption is genuinely needed (A5): `K = 2`, `d = 1`, `nu` uniform on the diagonal, `M_1 = 3/4`, `M_2 = 1/4`, `mu_1 = 0`. Agent 1 is the unique top everywhere; the deviation `m'_1 = 1/2` (feasible, horizon independent) wins every fully explored cell with probability at least `1 - 2 e^{-q_n/32}` and saves `1/4` per exploitation visit: gain at least `n/4 - O(q_n J_n) - 2 n e^{-q_n/32}`, linear. Section F gives the general version.

## B. Attack on Claim L5

Target statement (lead's Claim L5): Lipschitz capacities plus `|T(X)| >= 2` for `nu`-a.e. `X` imply that all-maximum play is an `S_HDS`-asymptotic equilibrium under Static Grid-ETC with an explicit gain rate. Every attack below is evaluated against the per-cell inequality that the proof in Section C uses,

`gain_C <= N_C p'_{i,C} delta_{i,C} <= N_C (c_1 q_n^{-1/2} + eta_{i,C})`, `eta_{i,C} := (bar M_{i,C} - max_{j != i} bar M_{j,C})_+`,

so that an attack succeeds only if it produces a cell family with `sum_C nu(C) eta_{i,C}` bounded away from zero, or breaks one of the three ingredients (factorization, self-monotonicity, the tail lemma). Numerical values come from `cellgain.py` (exact binomial computation of the commitment probability with uniform-priority tie breaking, no Monte Carlo) and `fatcantor.py` in the scratch directory named in the brief.

Attack 1 (changing top-pair identity across a boundary, deviator top on both sides). `K = 3`, `d = 1`, `nu` uniform on the diagonal of `[0,1]^3`, `M_1 = 1`, and the boundary placed at `1/3` (a dyadic boundary such as `1/2` is a cell edge and produces no straddling cell). Lipschitz version: `M_2(u) = 1 - L (u - 1/3)_+`, `M_3(u) = 1 - L (1/3 - u)_+`; `T = {1,2}` left, `{1,3}` right. In the unique straddling cell with left fraction `f`, `bar M_{2,C} = 1 - L (1-f)^2 h_n / 2`, `bar M_{3,C} = 1 - L f^2 h_n / 2`, so `eta_{1,C} = (L h_n / 2) min{f^2, (1-f)^2} <= L h_n / 8 < 2 L sqrt(3) h_n`; the cell's contribution is at most `n h_n (L h_n/8 + c_1 q_n^{-1/2})`, and every other cell has `eta = 0`. Discontinuous version (`L = infinity`): `bar M_{2,C} = f`, `bar M_{3,C} = 1 - f`, `eta_{1,C} = min{f, 1-f}`. Exact best per-visit gains of agent 1 in that cell (`mu_1 = 0`): `q = 1024`: `f = 0.5`: 0.4402 at shading 0.4475 (bound `c_1/sqrt(q) + eta = 0.5379`); `f = 0.3`: 0.2548 (bound 0.3379); `f = 0.1`: 0.0755 (bound 0.1379); `q = 64`, `f = 0.5`: 0.3263 (bound 0.6516). The gain is real but confined to one cell of mass `h_n`: total `O(n h_n)`. Outcome: no counterexample; the `eta` term is exactly the price of a changing identity, and Lipschitz capacities make it `O(L h_n)` per straddling cell.

Attack 2 (shared-top set equal to a fat Cantor set: positive mass, empty interior). Let `F` be the Smith-Volterra-Cantor set (remove an open middle interval of length `4^{-k}` from each of the `2^{k-1}` intervals at stage `k`; `|F| = 1/2`, `F` closed, nowhere dense). (a) Lipschitz instance: `M_1 = M_3 = 1`, `M_2(u) = 1 - dist(u, F)`. Then `T = {1,2,3}` on `F`, `{1,3}` off `F`; `|T| >= 2` everywhere; `G_{12} = F` has `partial G_{12} = F` of mass `1/2`. For every agent and every cell `eta = 0` (agent 3 is top on every cell for deviators 1 and 2; for deviator 3, agent 1 is). Theorem C.1 applies with the full rate. The manuscript's theorem does not apply (any closed `B` off which the top set is locally constant must contain `F`, so `nu(B) >= 1/2`). (b) Discontinuous instance (Example A.1): `M_2 = 1_F`, `M_3 = 1 - 1_F`. Then `eta_{1,C} = min{f_C, 1 - f_C}` with `f_C = |F cap C|/|C|`. Exact values of `E[eta_{1,C_k(X)}]` at dyadic levels `k = 2, ..., 12` (stage-14 approximation of `F`, truncation error below `1.2 x 10^{-1} h`, and far smaller for `k <= 9`): 0.3828, 0.2344, 0.2344, 0.1230, 0.1230, 0.0622, 0.0622, 0.0312, 0.0312, 0.0156, 0.0156; the mass of cells with `0 < f_C < 1` is 1, 0.75, 0.75, 0.625, 0.625, 0.5625, 0.5625, 0.5312, 0.5312, 0.5156, 0.5156 and converges to `nu(F) = 1/2`, not to zero. So the "mixed cells" never disappear, yet `E[eta] ~ h^{1/2}` (it equals `h^{1/2}` to three decimals at `k = 12`), because the Lebesgue density theorem drives `f_C` to `0` or `1` for a.e. `X`. Outcome: `o(n)` gain holds (Theorem C.1 without (H5)), with the slower rate `O(n h_n^{1/2}) = O(n^{1 - 1/(2(D+3))})` for this instance. The claim "constant top set on finitely many pieces" is thus not necessary even for discontinuous capacities; the rate is what degrades.

Attack 3 (infinitely many components accumulating). Example A.2 (continuous, `eta = 0` everywhere). A version with genuinely alternating pairs: `M_1 = 1`, `M_2 = 1 - (u sin(1/u))_+`, `M_3 = 1 - (u sin(1/u))_-`, so the top pair alternates between `{1,2}` and `{1,3}` on the intervals between consecutive zeros `u_k = 1/(k pi)`, accumulating at `0`. The capacities are not Lipschitz near `0` (derivative of order `1/u`) but continuous. Cells in `[0, sqrt(h_n)]` have `eta <= sqrt(h_n) + h_n` and total mass `sqrt(h_n)`; a straddling cell around `u_k > sqrt(h_n)` has `eta <= h_n / u_k` (local Lipschitz constant `1/u_k`), and there are at most `1/(pi sqrt(h_n))` such zeros, so `sum_C nu(C) eta_C <= 2 h_n + sum_{k <= 1/(pi sqrt h_n)} h_n (h_n k pi) = O(h_n)`. Outcome: same order as the Lipschitz bound; no counterexample.

Attack 4 (deviator top nowhere but nearly top). `M_1 = 0.95` constant, rivals `M_2 = 1_F`, `M_3 = 1 - 1_F` as in attack 2(b). Agent 1 is top at no point, yet in a mixed cell with `f_C = 0.5` its cell mean `0.95` beats both rivals' cell means `0.5`; exact numbers: `q = 1024`, `f = 0.5`: baseline win probability `p^0 = 1.000`, best per-visit shading gain 0.3903 at shading 0.3990 (`eta = 0.45`); `f = 0.2`: gain 0.1132 (`eta = 0.15`). So the manuscript's non-top argument ("non-top agents have a positive cell gap") is false cell by cell for such instances. The gain is nevertheless controlled by `eta_{1,C}`, whose average vanishes by density (attack 2(b) numbers, since `eta_{1,C} <= min{f_C, 1 - f_C}`). With Lipschitz rivals `eta_{1,C} <= 2 L sqrt(D) h_n` regardless. Outcome: no counterexample, but it confirms that any proof must avoid a top/non-top split; Section C has none.

Attack 5 (shading only inside a thin band). A deviation `m' = M_i - s` on a subset of relative cell mass `w` and `M_i` elsewhere has `delta_{i,C} = w s`. The per-cell inequality is stated for arbitrary `delta_{i,C} in [0,1]` and the sup over `delta` of the exact gain in a symmetric two-top cell is small: `mu_i = 0`, rival at the same mean `M`, best per-visit gain over a grid of 400 shading levels: `M = 1`: 0.178/q, 0.182/q, 0.177/q, 0.099/q for `q = 16, 64, 256, 1024`; `M = 1 - 1/q`: 0.069/q, 0.078/q, 0.079/q, 0 (q = 1024, grid resolution); `M in {0.95, 0.8, 0.5}` and `q >= 64`: exactly 0 (the baseline utility lost on forfeited wins exceeds the effort saved). Outcome: no counterexample; the thin band is just a way to choose `delta` and cannot beat the sup.

Attack 6 (grid-aligned deviations). A map that is constant on each cell chooses `delta_{i,C}` freely per cell; the bound is a sum of per-cell suprema, so alignment can attain but not exceed it. The manuscript's cell-aligned experiment is covered. Outcome: no counterexample.

Attack 7 (random ex ante mixtures). Conditional on the realized map of agent `i` (independent of profiles, seeds, permutations and priorities by the definition of `S_HDS`), the bound of Theorem C.1 holds with constants that do not depend on the map; integrate over the mixing law. Outcome: covered.

Attack 8 (honest deviator with a binding floor). The honest maps `m' >= mu_i` form a subset of the feasible maps, so the upper bound applies. Where `mu_i = M_i` the honest agent has no downward move; this only matters for necessity (Section F). Outcome: covered.

Attack 9 (`a_C = 0`: the lazy deviation, and tightness of the exponent). `K = 2`, `M_1 = M_2 = 1`, `mu_1 = 0`, `mu_2` arbitrary, `nu` with a density bounded below by `rho > 0` on `[0,1]^D`. Baseline utility of agent 1 is exactly `0` (per-pull utility `1 + 0 - 1 = 0`). Deviation `m' = 0`. Exploitation: agent 1's exploration means are `0` against agent 2's `1`, so it is never committed to; exploitation utility is `0` before and after. Exploration: agent 1 is explored exactly `q_n` times in every cell whose visit count reaches `2 q_n`, earning `1` per pull instead of `0`. With `n nu(C) >= rho n h_n^D >= rho n^{3/(D+3)} 2^{-D}` expected visits per cell and only `2 q_n <= 4 n^{2/(D+3)}` needed, Chernoff gives `Pr(V_C < 2 q_n) -> 0` uniformly over cells, so the gain is `q_n J_n (1 - o(1)) = Theta(n^{(D+2)/(D+3)})`. Outcome: the exponent `(D+2)/(D+3)` in Theorem C.1 is attained, and the binding term is exploration, not shading. (The same deviation also removes `q_n J_n` revenue during exploration, the same order as the revenue error term.)

Attack 10 (zero-mass and light cells). Zero-mass cells are never visited (contract, Section 3). A cell with fewer than `K q_n` visits never commits; agent `i`'s pulls there are exploration pulls, at most `q_n`, already counted in `q_n J_n`. A positive-mass cell always contains a point with `|T| >= 2` (the set has full `nu`-measure), which is all Lemma C.3 uses. Outcome: covered.

Attack 11 (truncated exploration blocks). Blocks are fixed uniform permutations drawn independently of everything; truncation depends only on the membership sequence, which the coupling shares. No commitment occurs in a truncated cell. Outcome: covered.

Attack 12 (ties at commitment). The priority permutation is shared by the coupled executions; Lemma C.2 shows `{i committed under m'} subset {i committed under M_i}` including all tie configurations. Outcome: covered.

Attack 13 (`K = 2` versus `K >= 3`; product laws). For `K = 2`, `nu(|T| >= 2) = 1` means `M_1(x_1) = M_2(x_2)` `nu`-a.s. For `K >= 3` the identity of the partner can change (attacks 1 to 4), which is the only new phenomenon, and it is absorbed by `eta`. A structural remark: if `nu` is a product law, two independent random variables `M_i(x_i)` and `M_j(x_j)` coincide with positive probability only at common atoms of their laws, so under a product law the a.e. two-top condition forces `M_*(X)` to take values in a countable set of atoms attained by at least two agents. The contextual content of the condition therefore lives in within-profile dependence (as in the manuscript's experiments, where the top set is `{0,1}` everywhere). This is a modeling observation, not an obstruction.

Attack 14 (shared-top competition with `|T(X)| >= 3`). More rivals at the maximum only lower `p'_{i,C}` and `p_{i,C}`; the bound is unchanged. The baseline utility of a top agent falls to roughly `N_C a_C / |T|`, so a deviation forfeits less baseline, but the bound `gain_C <= N_C p' delta_C` never used the size of the baseline. Outcome: covered.

Attack 15 (the ingredients themselves). Factorization (Lemma C.1) rests on lem:cell-law, which needs i.i.d. profiles and fixed maps (contract, Sections 11 and 12; the deterministic alternating context sequence is the known counterexample). Self-monotonicity (Lemma C.2) is pathwise and needs the reward-independent exploration schedule (phase-dependent strategies break it, as the manuscript notes). The tail lemma needs exactly `q_n` independent observations per agent, which holds because exploitation rewards are ignored. Outcome: no new failure mode.

Verdict on Claim L5: it survives, but the sketch's rival bound `bar M_{j,C} >= bar M_C - 2 L sqrt(D) h_n` (with `bar M_C = E[M_*(X) | C]`) is not the quantity the proof needs; what is needed and what Lemma C.3 proves is `bar M_{j,C} >= bar M_{i,C} - 2 L sqrt(D) h_n` for the deviator's own cell mean (the two coincide only when `i` is top on the whole cell). With that correction the claim is proved in Section C, and Lipschitz continuity is shown to be needed only for the rate.
