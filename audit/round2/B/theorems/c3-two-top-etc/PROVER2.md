## 1. Setting, notation, and exact theorem statements

### 1.1 Setting and notation (fixed for the whole file)

- Context space X = [0,1)^D with D = Kd; the coordinates of a profile X = (x_1, ..., x_K) satisfy x_i in [0,1)^d. Half-open so that the dyadic cubes below partition X exactly. (Remark on [0,1]^D: if nu charges the faces {x : some coordinate equals 1}, replace each level-k interval [(2^k - 1)2^{-k}, 1) by [(2^k - 1)2^{-k}, 1]; the resulting cells still form a Borel partition of [0,1]^D, are still nested across levels, and still have Euclidean diameter at most sqrt(D) 2^{-k}; every argument below goes through verbatim, since only these three properties of the cells are used.)
- nu is an arbitrary Borel probability measure on X. X_1, ..., X_n are i.i.d. nu and exogenous.
- Capacities M_j : [0,1)^d -> [0,1] and intrinsic means mu_j : [0,1)^d -> [0,1] are Borel with mu_j <= M_j pointwise. Throughout, M_j(x_j) and mu_j(x_j) are also regarded as Borel functions of the full profile X. M_*(X) := max_j M_j(x_j); T(X) := {j : M_j(x_j) = M_*(X)}; r_i(X) := max_{j != i} M_j(x_j); U_i := {X : M_i(x_i) > r_i(X)} = {X : T(X) = {i}}; eta_i(X) := (M_i(x_i) - r_i(X))_+, so that {eta_i > 0} = U_i.
- Feasible maps for agent i: Borel m : X -> [0,1] with 0 <= m(X) <= M_i(x_i) for every X; honest-feasible if moreover m(X) >= mu_i(x_i) for every X. S_HDS consists of such maps (chosen knowing n, so they may depend on n and on the grid) and of independent ex ante mixtures: a random variable xi_i, independent of everything else in the model, together with a jointly Borel map (xi, X) -> m^xi(X) such that m^xi is feasible (honest-feasible if i is honest) for every value xi. The all-maximum profile is S^max = (M_1(x_1), ..., M_K(x_K)); S^max_{-i} denotes the rivals' components.
- Per-pull utility of agent i at round t when selected with target m: 1 + mu_i(x_{i,t}) - m in [0,2]; when m in [mu_i(x_{i,t}), M_i(x_{i,t})] it lies in [0,1]. u_i(n; S) = E_S sum_{t <= n} 1{I_t = i}(1 + mu_i(x_{i,t}) - m_{i,t}). P(n; S) = E_S sum_{t <= n} m_{I_t,t}.
- Grid: k_n := ceil(log_2(n)/(D+3)) for n >= 1 (k_1 = 0), h_n := 2^{-k_n}, so n^{-1/(D+3)}/2 < h_n <= n^{-1/(D+3)}. D_k denotes the set of level-k dyadic cells prod_{l=1}^D [a_l 2^{-k}, (a_l+1) 2^{-k}), a_l in {0, ..., 2^k - 1}; |D_k| = 2^{kD}; J_n := |D_{k_n}| = h_n^{-D} <= 2^D n^{D/(D+3)}. Every X in X lies in exactly one cell C_k(X) of D_k, and C_{k+1}(X) subset C_k(X) (nesting). F_k := sigma(D_k) is the finite sigma-algebra generated by the level-k cells; F_k subset F_{k+1}. q_n := ceil(n^{2/(D+3)}) <= 2 n^{2/(D+3)}. c_1 := 2 e^{-1/2} = 1.2130... .
- Cell quantities, for C in D_{k_n} with nu(C) > 0 and any bounded Borel f: E[f | C] := (1/nu(C)) int_C f dnu. bar M_{j,C} := E[M_j | C]; bar m_{j,C} := E[m_j | C] for a map m_j; eta_{i,C} := (bar M_{i,C} - max_{j != i} bar M_{j,C})_+; a_{i,C} := E[1 + mu_i - M_i | C] in [0,1]; for a deviation m' of agent i, delta_C := E[M_i - m' | C] in [0,1]; beta_C := E[M_* | C] - max_j bar M_{j,C} in [0,1]. For a cell with nu(C) = 0 all these are set to 0 by convention (such a cell is visited with probability zero; see Lemma 1(f)), so that every sum over cells below is a finite sum over D_{k_n}.
- Static Grid-ETC (as in the manuscript, appendix A.4, and TASK.md): in each cell C, q_n independent uniform permutations sigma_{C,1}, ..., sigma_{C,q_n} of [K]; the k-th visit to C, for k <= K q_n, selects sigma_{C, b}(k - (b-1)K) with b := ceil(k/K); if the cell receives at least K q_n visits, each agent has exactly q_n exploration observations in C, and hat I_C is an agent with the largest exploration empirical mean, ties resolved toward the agent with the smallest value of an independent uniform priority permutation pi_C; visits k > K q_n select hat I_C; exploitation rewards are ignored. V_C := sum_{t <= n} 1{X_t in C}; N_C := (V_C - K q_n)_+ is the number of exploitation visits. The rule is cell-blind: within a cell, the exact profile is not used.
- Publicity of M_*: it is the informational assumption under which S^max is the natural candidate profile; the algorithm does not use it and no step of the proofs below uses it.

### 1.2 Theorem statements (as they should appear in the paper)

**Theorem T1 (continuous public restricted equilibrium under two tops almost everywhere).** Assume nu(|T(X)| >= 2) = 1 (equivalently nu(U_i) = 0 for every i) and that M_* is public. Under Static Grid-ETC, for every n >= 1, every agent i (strategic or honest), and every unilateral deviation m' in S_HDS of agent i (a deterministic feasible map, or an independent ex ante mixture of such maps),

u_i(n; m', S^max_{-i}) - u_i(n; S^max) <= q_n J_n + c_1 n q_n^{-1/2} + n E_n(i), where E_n(i) := sum_{C in D_{k_n}} nu(C) eta_{i,C},

and E_n(i) -> 0 as n -> infinity. Consequently sup_{m'} [u_i(n; m', S^max_{-i}) - u_i(n; S^max)] = o(n) for every i, so S^max is an S_HDS-asymptotic equilibrium (with a deviation-uniform remainder). The first two terms are at most (2^{D+1} + c_1) n^{(D+2)/(D+3)}.

**Theorem T2 (explicit rate under Lipschitz capacities).** Assume in addition to the hypotheses of T1 that every M_j is L-Lipschitz on [0,1)^d for the Euclidean norm. Then eta_{i,C} <= L sqrt(D) h_n for every i and every cell C in D_{k_n} with nu(C) > 0, hence for every n, i, and deviation m' in S_HDS,

u_i(n; m', S^max_{-i}) - u_i(n; S^max) <= q_n J_n + c_1 n q_n^{-1/2} + L sqrt(D) n h_n <= (2^{D+1} + c_1 + L sqrt(D)) n^{(D+2)/(D+3)}.

(This implies the form with 2 L sqrt(D) in place of L sqrt(D) stated in TASK.md.)

**Theorem T3 (revenue at all-maximum play).** No top-set condition is assumed. For every n >= 1,

P(n; S^max) >= E sum_{t <= n} M_*(X_t) - [K q_n J_n + (K-1) c_1 n q_n^{-1/2} + n B_n], where B_n := sum_{C in D_{k_n}} nu(C) beta_C,

and B_n -> 0 as n -> infinity for Borel capacities; hence P(n; S^max) >= E sum_t M_*(X_t) - o(n). If every M_j is L-Lipschitz, then beta_C <= L sqrt(D) h_n for every positive-mass cell, hence

P(n; S^max) >= E sum_{t <= n} M_*(X_t) - [K q_n J_n + (K-1) c_1 n q_n^{-1/2} + L sqrt(D) n h_n] >= E sum_{t <= n} M_*(X_t) - (K 2^{D+1} + (K-1) c_1 + L sqrt(D)) n^{(D+2)/(D+3)}.

**Theorem T4 (necessity and exact characterization).** For agent i let W_i := U_i if i is strategic and W_i := U_i cap {X : mu_i(x_i) < M_i(x_i)} if i is honest.

(a) (Necessity.) If nu(W_i) > 0, choose g_0 > 0 and a Borel set A subset W_i with nu(A) > 0 such that on A both M_i(x_i) - r_i(X) >= g_0 and s_i(X) >= g_0, where s_i(X) := M_i(x_i) if i is strategic and s_i(X) := M_i(x_i) - mu_i(x_i) if i is honest (such g_0 and A exist; Lemma 6). Then there are deterministic deviations m'_n in S_HDS (honest-feasible if i is honest) and an n_0 depending on the instance such that for all n >= n_0

u_i(n; m'_n, S^max_{-i}) - u_i(n; S^max) >= c n with c := g_0 nu(A)/32.

In particular S^max is not an S_HDS-asymptotic equilibrium.

(b) (Sufficiency, including honest knife-edge unique tops.) If nu(W_i) = 0 for every i, then S^max is an S_HDS-asymptotic equilibrium: for every n, every i, and every deviation m' in S_HDS,

u_i(n; m', S^max_{-i}) - u_i(n; S^max) <= q_n J_n + c_1 n q_n^{-1/2} + n E'_n(i),

where E'_n(i) := sum_C nu(C) eta_{i,C} for strategic i and E'_n(i) := sum_C nu(C) min{eta_{i,C}, sigma_{i,C}} with sigma_{i,C} := E[(M_i - mu_i) 1_{U_i^c} | C] for honest i, and E'_n(i) -> 0. T1 is the special case nu(U_i) = 0 for all i.

Hence, under Static Grid-ETC, S^max is an S_HDS-asymptotic equilibrium if and only if nu(W_i) = 0 for every i.

Remark on observation model: T4(a) uses a deviation that depends on the full profile X (through the sets A and the good cells). This is the default observation model of the manuscript (the selected agent observes the full profile). T1, T2, T3, T4(b) hold verbatim under the own-context-only model because they quantify over a larger class of deviations.

## 2. Lemmas with complete proofs

Throughout, n is fixed, k := k_n, cells are the elements of D_{k_n}, and "cell" means such a cell. The lemmas are stated for an arbitrary profile m = (m_1, ..., m_K) of deterministic feasible maps (mixtures are handled by conditioning in Section 3.6).

### Lemma 1 (canonical construction; cell law; factorization). [This is the manuscript's lem:cell-law, restated with every conditioning explicit, plus the consequences used below.]

Construction. Let (Omega, F, P) carry the following mutually independent families: X_1, ..., X_n i.i.d. nu; U_1, ..., U_n i.i.d. Uniform[0,1]; for every cell C, permutations sigma_{C,1}, ..., sigma_{C,q_n} i.i.d. uniform on the symmetric group of [K] and a uniform permutation pi_C. (Pre-drawing the coins of every cell, whether or not the cell is ever visited, does not change the law of the execution; lazy initialization is a matter of implementation.) Given m, define the execution recursively in t = 1, ..., n: C_t := C_{k_n}(X_t); kappa_t := #{s <= t : X_s in C_t} (visit index of round t within its cell); if kappa_t <= K q_n, then with b := ceil(kappa_t/K), I_t := sigma_{C_t, b}(kappa_t - (b-1)K); if kappa_t > K q_n, then I_t := hat I_{C_t}, where, for a cell with at least K q_n visits, hat I_C is the agent with the largest exploration empirical mean hat m_{j,C} := q_n^{-1} sum_{r=1}^{q_n} W_{j,r} (defined in (d) below), ties resolved toward the smallest pi_C-value; Y_t := 1{U_t <= m_{I_t}(X_t)}.

(a) Model fidelity. The process (X_t, I_t, Y_t)_{t <= n} has the law prescribed by the model when the platform runs Static Grid-ETC against the profile m. Hence u_i(n; m) = E sum_t 1{I_t = i}(1 + mu_i(x_{i,t}) - m_i(X_t)) and P(n; m) = E sum_t m_{I_t}(X_t) may be computed on (Omega, F, P).

Proof. The platform's selection I_t is the algorithm's selection as a function of the observed history (X_s, I_s, Y_s)_{s < t}, of X_t, and of the platform's internal coins (sigma, pi), which are independent of everything else; this is exactly the algorithm's kernel. The target at round t is m_{I_t}(X_t), a function of (X_{1:t}, U_{1:t-1}, sigma, pi). Since U_t is independent of (X_{1:n}, U_{1:t-1}, sigma, pi), P(Y_t = 1 | X_{1:t}, U_{1:t-1}, sigma, pi) = m_{I_t}(X_t). So conditionally on the whole past and the current target, Y_t is Bernoulli with the target as parameter, independent of the past: the model's reward specification. The context X_t is drawn from nu independently of the past. The joint law of (X_t, I_t, Y_t)_{t <= n} is determined by these three conditional kernels, so it coincides with the model's law. QED.

(b) Conditional law given the membership indicators. Fix a cell C with nu(C) > 0. Let E_C := (1{X_t in C})_{t <= n}, V_C := sum_t 1{X_t in C}, and t_{C,1} < ... < t_{C,V_C} the visit rounds. For every e in {0,1}^n with P(E_C = e) > 0, conditionally on {E_C = e} the pairs Z_k := (X_{t_{C,k}}, U_{t_{C,k}}), k = 1, ..., V_C(e), are i.i.d. with law nu(. | C) (x) Uniform[0,1], and are independent of (sigma, pi) and of ((X_t, U_t) : e_t = 0).

Proof. Write C^1 := C and C^0 := X \ C. For Borel A_t subset X and B_t subset [0,1], independence across t gives P(X_t in A_t, U_t in B_t for all t, E_C = e) = prod_{t <= n} nu(A_t cap C^{e_t}) Leb(B_t), and P(E_C = e) = prod_t nu(C^{e_t}) > 0. The quotient is prod_t nu(A_t | C^{e_t}) Leb(B_t), a product law whose factor at a round with e_t = 1 is nu(. | C) (x) Uniform[0,1]. The visit rounds t_{C,k} are deterministic functions of e. (sigma, pi) are independent of (X, U) by construction. QED.

(c) Exploration schedule. For each cell C and agent j, the rounds at which j is explored in C, and their order, are functions of (X_{1:n}, sigma_C) only; they do not depend on the profile m or on U. The r-th exploration pull of j in C occupies cell-visit index kappa_j(r) := (r-1)K + sigma_{C,r}^{-1}(j) in [K q_n], and these indices are pairwise distinct over (j, r). If V_C >= K q_n, agent j has exactly q_n exploration pulls in C; if V_C < K q_n, it has at most q_n (at most one per started block, and at most q_n blocks). In every case the number of exploration rounds in C is min{V_C, K q_n}, and no exploitation visit occurs unless V_C > K q_n. N_C := (V_C - K q_n)_+ is the number of exploitation visits; N_C is a function of X_{1:n} only.

Proof. Immediate from the recursive definition: for kappa_t <= K q_n, I_t depends on (kappa_t, sigma_{C_t}) only, and kappa_t on X_{1:t} only. QED.

(d) I.i.d. exploration rewards. Fix C with nu(C) > 0. On {V_C >= K q_n}, conditionally on (E_C, sigma, pi), the exploration rewards W_{j,r} := 1{U_{t_{C, kappa_j(r)}} <= m_j(X_{t_{C, kappa_j(r)}})}, r = 1, ..., q_n, of agent j are i.i.d. Bernoulli(bar m_{j,C}) with bar m_{j,C} := E[m_j | C]; the family (W_{j,r})_{j in [K], r <= q_n} is (conditionally) independent of (Z_k)_{k > K q_n}; and in fact all the W_{j,r} over distinct (j, r) are mutually independent (this last fact is not needed below).

Proof. Condition on E_C = e with V_C(e) >= K q_n and on (sigma, pi). By (b), (Z_k)_{k <= V_C(e)} are i.i.d. nu(.|C) (x) Uniform and independent of (sigma, pi), so the conditioning on (sigma, pi) does not alter their law. Given sigma_C, the indices kappa_j(r) are fixed, pairwise distinct elements of [K q_n]. Hence W_{j,r} = phi_j(Z_{kappa_j(r)}) with phi_j(x, u) := 1{u <= m_j(x)} are functions of distinct coordinates of an i.i.d. sequence: they are independent, and each has mean E[phi_j(Z_1) | E_C = e] = nu(C)^{-1} int_C int_0^1 1{u <= m_j(x)} du nu(dx) = nu(C)^{-1} int_C m_j dnu = bar m_{j,C}. Independence from (Z_k)_{k > K q_n} is again independence of distinct coordinates. QED.

(e) Commitment probability and factorization. Fix C with nu(C) > 0. On {V_C >= K q_n}, hat I_C = psi((W_{j,r})_{j,r}, pi_C) for a fixed function psi (largest empirical mean, ties toward the smallest pi_C-value). Define p_{j,C}(m) := P(hat I_C = j | V_C >= K q_n) if P(V_C >= K q_n) > 0, and p_{j,C}(m) := 0 otherwise. Then P(hat I_C = j | E_C = e) = p_{j,C}(m) for every e with V_C(e) >= K q_n, and for every bounded Borel g : X -> R,

E[ sum_{k = K q_n + 1}^{V_C} 1{hat I_C = j} g(X_{t_{C,k}}) ] = E[N_C] p_{j,C}(m) E[g | C].     (F)

Proof. For each e with V_C(e) >= K q_n, the conditional law of ((Z_k)_{k <= K q_n}, sigma_C, pi_C) given {E_C = e} is the same product law (by (b)); hat I_C is a fixed function of this vector, so P(hat I_C = j | E_C = e) is one number for all such e, and averaging over these e gives p_{j,C}(m). For (F): condition on E_C = e. If V_C(e) <= K q_n the sum is empty and N_C(e) = 0. Otherwise the sum has N_C(e) = V_C(e) - K q_n terms; for k > K q_n, the term 1{hat I_C = j} g(X_{t_{C,k}}) is the product of a function of ((Z_l)_{l <= K q_n}, sigma_C, pi_C) and a function of Z_k, which are conditionally independent by (b) and (d), with E[g(X_{t_{C,k}}) | E_C = e] = E[g | C]. So the conditional expectation of the sum is N_C(e) p_{j,C}(m) E[g | C]. Take expectation over E_C. QED.

(f) Zero-mass cells. If nu(C) = 0 then P(V_C > 0) <= sum_t P(X_t in C) = n nu(C) = 0: such a cell is a.s. never visited, contributes 0 a.s. to every count, and no conditional mean is needed for it. All cell sums below therefore run over the finitely many positive-mass cells and are well defined; by the convention of Section 1.1 they may equally be written over all of D_{k_n}.

(g) Utility and revenue decomposition. For every profile m and agent i,

u_i(n; m) = sum_{C : nu(C) > 0} { E[ Xpl_{i,C}(m) ] + E[N_C] p_{i,C}(m) E[1 + mu_i - m_i | C] },     (U)

where Xpl_{i,C}(m) := sum over the exploration pulls of i in C of (1 + mu_i(x_{i,t}) - m_i(X_t)) (at most q_n terms, each in [0,2]); and

P(n; m) = sum_{C : nu(C) > 0} { E[ sum over exploration rounds t in C of m_{I_t}(X_t) ] + E[N_C] sum_{j} p_{j,C}(m) bar m_{j,C} }.     (R)

Proof. Split the sum over rounds by cell and, within a cell, into exploration visits (kappa_t <= K q_n) and exploitation visits (kappa_t > K q_n, where I_t = hat I_C); apply (F) with g := 1 + mu_i - m_i (bounded Borel) for the exploitation part of (U), and with g := m_j summed over j for (R); discard zero-mass cells by (f). QED.

### Lemma 2 (two-sample tail; the manuscript's lem:etc-tail with the constant c_1 = 2 e^{-1/2}).

Let hat a be the average of q independent [0,1]-valued random variables with common mean a, and hat b the average of q independent [0,1]-valued random variables with common mean b > a; the two samples live on the same probability space, and no independence between the two samples is required. Put Delta := b - a. Then

P(hat a >= hat b) <= 2 exp(-q Delta^2 / 2),     Delta P(hat a >= hat b) <= c_1 q^{-1/2},     c_1 = 2 e^{-1/2},

and for every Delta_0 in (0, Delta], P(hat a >= hat b) <= 2 exp(-q Delta_0^2 / 2).

Proof. If hat a >= hat b then either hat a - a >= Delta/2 or b - hat b >= Delta/2, for otherwise hat a < a + Delta/2 = b - Delta/2 < hat b. Hoeffding's inequality (Hoeffding 1963, Theorem 2: for independent Y_1, ..., Y_q with values in [0,1] and s > 0, P(sum_k (Y_k - E Y_k) >= q s) <= exp(-2 q s^2), and likewise for the lower tail) with s = Delta/2 bounds each of the two events by exp(-2 q Delta^2/4) = exp(-q Delta^2/2); the union bound gives the first claim. For the second, P(hat a >= hat b) <= min{1, 2 exp(-q Delta^2/2)}, so Delta P(hat a >= hat b) <= f(Delta) with f(x) := 2 x exp(-q x^2/2) on x >= 0; f'(x) = 2 exp(-q x^2/2)(1 - q x^2) vanishes only at x = q^{-1/2}, where f attains its maximum 2 q^{-1/2} e^{-1/2} = c_1 q^{-1/2} (f(0) = 0, f(x) -> 0 as x -> infinity). Thus c_1 = 2 e^{-1/2} is the exact constant of the maximization "x times 2 exp(-q x^2/2)". The last claim holds because x -> exp(-q x^2/2) is nonincreasing on x >= 0. QED.

Application in cells. By Lemma 1(d), conditionally on (E_C, sigma, pi) on {V_C >= K q_n}, agent j's exploration observations in C are q_n i.i.d. Bernoulli(bar m_{j,C}); Lemma 2 therefore applies to any pair of agents in the same cell, with a, b their conditional cell means, and the resulting bound on the conditional probability integrates to the same bound on P(. | V_C >= K q_n).

### Lemma 3 (pathwise commitment coupling; the manuscript's appendix A.4 coupling, including the tie priority).

Fix agent i, a feasible map m' for i, and the rivals' maps m_{-i}. On the space of Lemma 1, run the two executions with profiles m' := (m', m_{-i}) and m^0 := (M_i, m_{-i}) using the same (X_{1:n}, U_{1:n}, sigma, pi); mark quantities of the first execution with a prime and of the second with a superscript 0. Then for every cell C, pointwise on Omega:

(i) the exploration schedules coincide: the same rounds are exploration rounds of C, with the same selected agents (Lemma 1(c)); in particular i's exploration rounds in C are the same rounds in both executions;

(ii) for j != i, hat m'_{j,C} = hat m^0_{j,C} (same rounds, same maps, same U);

(iii) hat m'_{i,C} <= hat m^0_{i,C}, because on each common exploration round t of i, 1{U_t <= m'(X_t)} <= 1{U_t <= M_i(x_{i,t})} by feasibility m'(X_t) <= M_i(x_{i,t}) at the same profile X_t;

(iv) on {V_C >= K q_n}: {hat I'_C = i} subset {hat I^0_C = i}. Consequently p'_{i,C} := p_{i,C}(m') <= p_{i,C}(m^0) =: p^0_{i,C}.

Proof of (iv). Recall hat I_C = i iff hat m_{i,C} >= hat m_{j,C} for all j != i and pi_C(i) < pi_C(j) for every j != i with hat m_{j,C} = hat m_{i,C}. Suppose hat I'_C = i. For j != i: hat m^0_{i,C} >= hat m'_{i,C} >= hat m'_{j,C} = hat m^0_{j,C}, so i is a maximizer in execution 0. If j != i ties with i in execution 0, i.e. hat m^0_{j,C} = hat m^0_{i,C}, then the chain hat m^0_{i,C} >= hat m'_{i,C} >= hat m'_{j,C} = hat m^0_{j,C} = hat m^0_{i,C} forces hat m'_{i,C} = hat m'_{j,C}, so j tied with i in execution 1 as well, and there i had priority: pi_C(i) < pi_C(j). Hence i wins all its ties in execution 0 and hat I^0_C = i. The inclusion holds pointwise on {V_C >= K q_n}; taking P(. | V_C >= K q_n) (when this event has positive probability; otherwise both probabilities are 0 by convention) gives p'_{i,C} <= p^0_{i,C}. QED.

Remark (where the same-visit coupling is legitimate). Step (iii) compares the two maps at the same profile X_t on the same round t. This is possible only because, by Lemma 1(c), exploration rounds are determined by contexts and permutations and never by rewards, so the round at which i's r-th exploration pull in C occurs is the same in both executions. The manuscript's phrase "reward uniforms on common exploration pulls" is realized here by the round-indexed seeds U_t.

### Lemma 4 (dyadic filtration; Levy's upward theorem; the two-top condition).

(i) (F_k)_{k >= 0} is a filtration of Borel sub-sigma-algebras of X = [0,1)^D, and sigma(cup_k F_k) = B(X), the Borel sigma-algebra.

(ii) For every bounded Borel f : X -> R, the function f^{(k)} defined by f^{(k)}(X) := E[f | C_k(X)] if nu(C_k(X)) > 0 and f^{(k)}(X) := 0 otherwise is a version of E_nu[f | F_k], and f^{(k)}(X) -> f(X) for nu-a.e. X as k -> infinity.

(iii) Define M_j^{(k)}, M_*^{(k)}, eta_i^{(k)} := (M_i^{(k)} - max_{j != i} M_j^{(k)})_+ and beta^{(k)} := M_*^{(k)} - max_j M_j^{(k)}. Then eta_i^{(k)}(X) = eta_{i, C_k(X)} and beta^{(k)}(X) = beta_{C_k(X)} for X in positive-mass cells; eta_i^{(k)} -> eta_i = (M_i - r_i)_+ nu-a.s.; beta^{(k)} -> 0 nu-a.s.; and 0 <= eta_i^{(k)}, beta^{(k)} <= 1.

(iv) sum_{C in D_k} nu(C) eta_{i,C} = int eta_i^{(k)} dnu -> int eta_i dnu = int_{U_i} (M_i - r_i) dnu, which is 0 if and only if nu(U_i) = 0; and sum_{C in D_k} nu(C) beta_C = int beta^{(k)} dnu -> 0. The same limits hold along the sequence k = k_n, n -> infinity.

(v) nu(|T(X)| >= 2) = 1 if and only if nu(U_i) = 0 for every i in [K]; under this condition (M_i - r_i)_+ = 0 nu-a.s. for every i.

Proof. (i) Each level-k cell is the disjoint union of the 2^D level-(k+1) cells it contains (nesting of dyadic intervals: [a 2^{-k}, (a+1) 2^{-k}) = [2a 2^{-k-1}, (2a+1) 2^{-k-1}) cup [(2a+1) 2^{-k-1}, (2a+2) 2^{-k-1})), so every element of F_k is a union of level-(k+1) cells and F_k subset F_{k+1}. Cells are Borel, so F_k subset B(X). Conversely let G subset X be relatively open. For x in G pick rho > 0 with {y in X : |y - x| < rho} subset G and k with sqrt(D) 2^{-k} < rho; the cell C_k(x) contains x and has Euclidean diameter at most sqrt(D) 2^{-k} < rho, so C_k(x) subset G. Hence G is the union of the (countably many) dyadic cells of all levels contained in G, and G in sigma(cup_k F_k). Relatively open sets generate B(X). So sigma(cup_k F_k) = B(X). This is the place where nesting of the grids is used: without F_k subset F_{k+1}, (F_k) would not be a filtration and (ii) below would not apply.

(ii) Work on the probability space (X, B(X), nu) with the identity as the random variable. f^{(k)} is F_k-measurable (constant on cells) and for every cell C, int_C f^{(k)} dnu = nu(C) E[f | C] = int_C f dnu if nu(C) > 0, and both sides vanish if nu(C) = 0; since every element of F_k is a finite disjoint union of cells, f^{(k)} is a version of E[f | F_k]. Since f is bounded, f in L^1(nu), and f is B(X) = F_infty-measurable, so E[f | F_infty] = f nu-a.s. By Levy's upward theorem (Durrett, Probability: Theory and Examples, Version 5, Theorem 4.6.8: if F_k increases to F_infty = sigma(cup_k F_k) and X in L^1, then E(X | F_k) -> E(X | F_infty) a.s. and in L^1; verified in the author's PDF, Section 6), E[f | F_k] -> f nu-a.s. Any two versions of E[f | F_k] agree nu-a.s., and a countable union of null sets is null, so f^{(k)}(X) -> f(X) for nu-a.e. X.

(iii) Apply (ii) to the K + 1 bounded Borel functions M_1, ..., M_K, M_*. Off a nu-null set all K + 1 sequences converge, and the maps (u_1, ..., u_K) -> (u_i - max_{j != i} u_j)_+ and (v, u_1, ..., u_K) -> v - max_j u_j are continuous, so eta_i^{(k)} -> (M_i - max_{j != i} M_j)_+ = eta_i and beta^{(k)} -> M_* - max_j M_j = 0 nu-a.s. The identifications with eta_{i,C} and beta_C on positive-mass cells are the definitions in Section 1.1; the bounds follow from 0 <= M_j^{(k)} <= 1 and max_j M_j^{(k)} <= M_*^{(k)} (conditional expectation is monotone).

(iv) eta_i^{(k)} equals the constant eta_{i,C} on each positive-mass cell C and cells of mass zero are nu-null, so int eta_i^{(k)} dnu = sum_{C : nu(C) > 0} nu(C) eta_{i,C}, which by the convention of Section 1.1 is the sum over D_k. Bounded convergence (dominating constant 1, nu a probability measure) and (iii) give the limits. eta_i >= 0 and {eta_i > 0} = U_i, so int eta_i dnu = 0 iff nu(U_i) = 0. Since k_n is nondecreasing with k_n >= log_2(n)/(D+3) -> infinity, the sequences indexed by k_n converge to the same limits (they are subsequences with repetitions of convergent sequences).

(v) T(X) is never empty, and |T(X)| = 1 iff T(X) = {i} for some i iff X in U_i; the U_i are pairwise disjoint. Hence {|T| = 1} = cup_i U_i (disjoint) and nu(|T| >= 2) = 1 iff nu(U_i) = 0 for all i. Under this condition, for nu-a.e. X: if i in T(X) there is j != i in T(X), so r_i(X) >= M_j(x_j) = M_*(X) = M_i(x_i) and (M_i - r_i)_+(X) = 0; if i not in T(X), M_i(x_i) < M_*(X) = r_i(X) and again (M_i - r_i)_+(X) = 0. QED.

### Lemma 5 (Lipschitz cell bounds).

Assume each M_j is L-Lipschitz on [0,1)^d for the Euclidean norm. Let C be a level-k cell with nu(C) > 0. Then:

(a) for every j and every X in C, M_j(x_j) <= bar M_{j,C} + L sqrt(D) 2^{-k};

(b) beta_C <= L sqrt(D) 2^{-k};

(c) if nu(U_i) = 0, then eta_{i,C} <= L sqrt(D) 2^{-k} (this uses only the Lipschitz property of M_j for j != i).

Proof. For X, X' in C, |x_j - x'_j| <= |X - X'| <= sqrt(D) 2^{-k} (all D coordinates differ by less than 2^{-k}), so M_j(x_j) <= M_j(x'_j) + L sqrt(D) 2^{-k}; integrating in X' with respect to nu(. | C) gives (a). Taking the maximum over j in (a): M_*(X) <= max_j bar M_{j,C} + L sqrt(D) 2^{-k} for all X in C; integrating in X with respect to nu(. | C) gives E[M_* | C] <= max_j bar M_{j,C} + L sqrt(D) 2^{-k}, which is (b). For (c): by Lemma 4(v), nu(U_i) = 0 means M_i(x_i) <= r_i(X) for nu-a.e. X, and by (a) applied to j != i, r_i(X) <= max_{j != i} bar M_{j,C} + L sqrt(D) 2^{-k} for all X in C; hence M_i(x_i) <= max_{j != i} bar M_{j,C} + L sqrt(D) 2^{-k} for nu-a.e. X in C, and integrating with respect to nu(. | C) gives bar M_{i,C} <= max_{j != i} bar M_{j,C} + L sqrt(D) 2^{-k}, i.e. eta_{i,C} <= L sqrt(D) 2^{-k}. QED.

### Lemma 6 (a set of positive mass with uniform gap and slack).

If nu(W_i) > 0, there exist g_0 > 0 and a Borel set A subset W_i with nu(A) > 0 such that M_i(x_i) - r_i(X) >= g_0 and s_i(X) >= g_0 for every X in A (s_i as in T4).

Proof. For m >= 1 let A_m := {X : M_i(x_i) - r_i(X) >= 1/m, s_i(X) >= 1/m}; A_m is Borel (M_j, mu_i Borel) and increasing in m. Its union is {M_i - r_i > 0} cap {s_i > 0}. If i is strategic, s_i = M_i and on U_i one has M_i(x_i) > r_i(X) >= 0, so {s_i > 0} contains U_i and the union is U_i = W_i. If i is honest, {s_i > 0} = {mu_i < M_i} and the union is U_i cap {mu_i < M_i} = W_i. By continuity from below nu(A_m) -> nu(W_i) > 0, so some m has nu(A_m) > 0; take g_0 := 1/m and A := A_m. QED.

### Lemma 7 (exploration accounting).

Let i be fixed, m' a feasible map for i, and compare the executions of Lemma 3 (profiles (m', S^max_{-i}) and S^max). Pointwise on Omega,

0 <= sum_C [ Xpl'_{i,C} - Xpl^0_{i,C} ] <= q_n J_n,

where the sum is over the cells actually visited. Consequently the exploration part of the utility change is at most q_n J_n and at least 0.

Proof. By Lemma 3(i), i's exploration rounds in C are the same rounds in both executions, so Xpl'_{i,C} - Xpl^0_{i,C} = sum over those rounds t of [(1 + mu_i(x_{i,t}) - m'(X_t)) - (1 + mu_i(x_{i,t}) - M_i(x_{i,t}))] = sum over those rounds of (M_i(x_{i,t}) - m'(X_t)). Each summand lies in [0, 1]: it is nonnegative by feasibility and at most M_i(x_{i,t}) <= 1. (The cruder statement "per-pull utility lies in [0, 2]" would only give a difference in [-2, 2]; the pathwise coincidence of exploration rounds is what gives the one-sided bound 1.) By Lemma 1(c) agent i has at most q_n exploration pulls in each cell, including cells whose exploration is truncated (V_C < K q_n) and cells never fully explored, and at most J_n cells exist. Hence the total is in [0, q_n J_n]. QED.

## 3. Proofs of T1 to T4

### 3.1 The per-cell inequality (Proposition P)

Fix agent i, a deterministic feasible map m' for i, and let the rivals play S^max_{-i}. Write m^1 := (m', S^max_{-i}) and m^0 := S^max. Fix a cell C with nu(C) > 0 and set

p'_C := p_{i,C}(m^1), p_C := p_{i,C}(m^0) (Lemma 1(e)), a_C := E[1 + mu_i - M_i | C], delta_C := E[M_i - m' | C], bar m'_C := E[m' | C] = bar M_{i,C} - delta_C,

so that E[1 + mu_i - m' | C] = a_C + delta_C. By (U) of Lemma 1(g), the exploitation part of agent i's utility in C is E[N_C] p'_C (a_C + delta_C) under m^1 and E[N_C] p_C a_C under m^0; define the exploitation gain in C,

G_C := E[N_C] [ p'_C (a_C + delta_C) - p_C a_C ].

Proposition P. For every positive-mass cell C,

G_C <= E[N_C] p'_C delta_C <= E[N_C] min{ delta_C, c_1 q_n^{-1/2} + eta_{i,C} } <= n nu(C) ( c_1 q_n^{-1/2} + eta_{i,C} ).

Proof. Step 1 (a_C >= 0 and the coupling). Pointwise, 1 + mu_i(x_i) - M_i(x_i) >= 0 because M_i <= 1 <= 1 + mu_i, so a_C >= 0. By Lemma 3(iv), p'_C <= p_C. Hence p'_C a_C - p_C a_C = -(p_C - p'_C) a_C <= 0 and G_C <= E[N_C] p'_C delta_C. (If P(V_C >= K q_n) = 0, then N_C = 0 a.s., G_C = 0, and there is nothing to prove; assume P(V_C >= K q_n) > 0 below.)

Step 2 (the trivial bound). p'_C <= 1 and delta_C >= 0 (feasibility m' <= M_i) give p'_C delta_C <= delta_C.

Step 3 (the tail bound; two cases). Let j^* attain max_{j != i} bar M_{j,C} (under S^max_{-i}, rival j's cell mean is bar M_{j,C}), and define the deviator's cell gap to the best rival,

Delta' := bar M_{j^*,C} - bar m'_C = delta_C - ( bar M_{i,C} - max_{j != i} bar M_{j,C} ).

Case Delta' > 0. On {V_C >= K q_n}, the winner has the largest empirical mean, so {hat I'_C = i} subset {hat m'_{i,C} >= hat m_{j^*,C}}. Conditionally on (E_C, sigma, pi), by Lemma 1(d) applied to the profile m^1, hat m'_{i,C} is the average of q_n i.i.d. Bernoulli(bar m'_C) observations and hat m_{j^*,C} the average of q_n i.i.d. Bernoulli(bar M_{j^*,C}) observations (on the same space; independence between the two samples is not needed). Lemma 2 with a := bar m'_C, b := bar M_{j^*,C}, Delta = Delta' gives P(hat I'_C = i | E_C, sigma, pi) <= 2 exp(-q_n Delta'^2/2) and Delta' P(hat I'_C = i | E_C, sigma, pi) <= c_1 q_n^{-1/2} on {V_C >= K q_n}; integrating over (E_C, sigma, pi) on {V_C >= K q_n} yields p'_C Delta' <= c_1 q_n^{-1/2}. Therefore

p'_C delta_C = p'_C Delta' + p'_C ( bar M_{i,C} - max_{j != i} bar M_{j,C} ) <= c_1 q_n^{-1/2} + eta_{i,C},

where the last step uses p'_C in [0,1] and x <= x_+ = eta_{i,C} for x := bar M_{i,C} - max_{j != i} bar M_{j,C}.

Case Delta' <= 0. Then delta_C <= bar M_{i,C} - max_{j != i} bar M_{j,C}, and since delta_C >= 0 this right-hand side is nonnegative and equals eta_{i,C}. Hence p'_C delta_C <= delta_C <= eta_{i,C} <= c_1 q_n^{-1/2} + eta_{i,C}.

Step 4. Combine Steps 2 and 3 for the minimum; finally E[N_C] <= E[V_C] = n nu(C). QED.

Remark. Proposition P is the precise form of the manuscript's display "p'_C (a_C + delta_C) - p_C^0 a_C <= p'_C delta_C = O(q_n^{-1/2})": the O(q_n^{-1/2}) is valid only up to the cell-level unique-top margin eta_{i,C}, which vanishes in the manuscript's interior cells (where i's cell mean equals bar M_C = another top agent's cell mean) and which is what the two-top almost everywhere condition controls in the limit here.

### 3.2 Proof of Theorem T1

Fix n >= 1, agent i, and a deterministic feasible deviation m' (for an honest i, the honest-feasible maps form a subset, so the bound below covers honest agents; mixtures are treated in Section 3.6). By Lemma 1(g), applied to the two profiles m^1 = (m', S^max_{-i}) and m^0 = S^max, and since E[N_C] is the same under both profiles (N_C is a function of X_{1:n} only, Lemma 1(c)),

u_i(n; m^1) - u_i(n; m^0) = E[ sum_C ( Xpl'_{i,C} - Xpl^0_{i,C} ) ] + sum_{C : nu(C) > 0} G_C.

Lemma 7 bounds the first term by q_n J_n (this covers truncated cells and cells with fewer than K q_n visits, which have no exploitation visits and whose only contribution is exploration). Proposition P bounds the second term by

sum_{C : nu(C) > 0} n nu(C) ( c_1 q_n^{-1/2} + eta_{i,C} ) = c_1 n q_n^{-1/2} sum_{C : nu(C) > 0} nu(C) + n sum_{C} nu(C) eta_{i,C} = c_1 n q_n^{-1/2} + n E_n(i),

because the positive-mass cells of D_{k_n} carry total mass nu(X) = 1 and zero-mass cells contribute 0 to E_n(i) by convention. This proves the displayed inequality for every n, every i, and every deterministic deviation, with a right-hand side that does not depend on m'.

Convergence of E_n(i). By Lemma 4(v), nu(|T(X)| >= 2) = 1 implies nu(U_i) = 0 for every i, i.e. eta_i = (M_i - r_i)_+ = 0 nu-a.s. By Lemma 4(iv), E_n(i) = int eta_i^{(k_n)} dnu -> int eta_i dnu = 0. (The chain is: nesting gives a filtration; the dyadic cells generate B([0,1)^D); Levy's upward theorem gives eta_i^{(k)} -> eta_i nu-a.s.; bounded convergence gives the integrals; k_n -> infinity.)

Rates of the explicit terms. J_n = 2^{k_n D} with k_n < log_2(n)/(D+3) + 1 gives J_n < 2^D n^{D/(D+3)}; q_n <= n^{2/(D+3)} + 1 <= 2 n^{2/(D+3)} because n^{2/(D+3)} >= 1; hence q_n J_n <= 2^{D+1} n^{(D+2)/(D+3)}. Also q_n >= n^{2/(D+3)} gives c_1 n q_n^{-1/2} <= c_1 n^{(D+2)/(D+3)}. Thus

u_i(n; m', S^max_{-i}) - u_i(n; S^max) <= (2^{D+1} + c_1) n^{(D+2)/(D+3)} + n E_n(i) = o(n),

uniformly over deviations; in particular Definition 1 (restricted asymptotic equilibrium) holds for the class S_HDS. QED (T1, deterministic deviations; mixtures in 3.6).

### 3.3 Proof of Theorem T2

Under the hypotheses of T1, nu(U_i) = 0 (Lemma 4(v)), so Lemma 5(c) with k = k_n gives eta_{i,C} <= L sqrt(D) h_n for every positive-mass cell C and every i; therefore n E_n(i) <= L sqrt(D) n h_n sum_C nu(C) = L sqrt(D) n h_n <= L sqrt(D) n^{(D+2)/(D+3)} because h_n <= n^{-1/(D+3)}. Insert into T1's bound and use the rates computed in 3.2:

u_i(n; m', S^max_{-i}) - u_i(n; S^max) <= q_n J_n + c_1 n q_n^{-1/2} + L sqrt(D) n h_n <= (2^{D+1} + c_1 + L sqrt(D)) n^{(D+2)/(D+3)},

for every n >= 1, every i, and every deviation in S_HDS (mixtures by 3.6). The constant depends only on D, L (and c_1 is absolute); the exploration term does not depend on K because only the deviator's own exploration pulls enter (Lemma 7). Since L sqrt(D) <= 2 L sqrt(D), the form stated in TASK.md follows. QED.

### 3.4 Proof of Theorem T3

Let Def_n := E sum_{t <= n} [ M_*(X_t) - M_{I_t}(x_{I_t,t}) ] = E sum_t M_*(X_t) - P(n; S^max) (under S^max every selected agent delivers its capacity). Each summand lies in [0,1].

Exploration rounds. By Lemma 1(c) each cell has at most min{V_C, K q_n} exploration rounds and there are at most J_n cells, so the exploration rounds contribute at most K q_n J_n to Def_n (also at most n).

Exploitation rounds. Fix a positive-mass cell C and apply (F) of Lemma 1(e) with g := M_* - M_j (bounded Borel) and the profile S^max:

E[ sum_{k > K q_n} 1{hat I_C = j} ( M_*(X_{t_{C,k}}) - M_j(x_{j,t_{C,k}}) ) ] = E[N_C] p_{j,C} ( E[M_* | C] - bar M_{j,C} ) = E[N_C] p_{j,C} ( beta_C + Delta_{j,C} ),

where bar M^*_C := max_j bar M_{j,C}, Delta_{j,C} := bar M^*_C - bar M_{j,C} >= 0, and beta_C = E[M_* | C] - bar M^*_C >= 0. Summing over j, and using sum_j p_{j,C} = 1 (on {V_C >= K q_n} some agent is committed; if P(V_C >= K q_n) = 0 then N_C = 0 a.s. and the cell contributes nothing), the exploitation deficit of C is

E[N_C] ( beta_C + sum_j p_{j,C} Delta_{j,C} ).

Let j^* attain bar M^*_C. For j with Delta_{j,C} > 0, {hat I_C = j} subset {hat m_{j,C} >= hat m_{j^*,C}} on {V_C >= K q_n}; by Lemma 1(d) (profile S^max) and Lemma 2 with a := bar M_{j,C}, b := bar M_{j^*,C}, Delta = Delta_{j,C}, conditionally on (E_C, sigma, pi) and hence unconditionally on {V_C >= K q_n}, p_{j,C} Delta_{j,C} <= c_1 q_n^{-1/2}. Agents with Delta_{j,C} = 0 contribute 0, and j^* is one of them, so at most K - 1 agents contribute: sum_j p_{j,C} Delta_{j,C} <= (K-1) c_1 q_n^{-1/2}. Summing over cells with E[N_C] <= n nu(C),

Def_n <= K q_n J_n + (K-1) c_1 n q_n^{-1/2} + n sum_C nu(C) beta_C = K q_n J_n + (K-1) c_1 n q_n^{-1/2} + n B_n,

which is the first display of T3. By Lemma 4(iv), B_n = int beta^{(k_n)} dnu -> 0 for Borel capacities (no top-set condition is used anywhere in this proof), so Def_n = o(n), using K q_n J_n <= K 2^{D+1} n^{(D+2)/(D+3)} and (K-1) c_1 n q_n^{-1/2} <= (K-1) c_1 n^{(D+2)/(D+3)}. If every M_j is L-Lipschitz, Lemma 5(b) gives beta_C <= L sqrt(D) h_n, hence n B_n <= L sqrt(D) n h_n <= L sqrt(D) n^{(D+2)/(D+3)}, and

P(n; S^max) >= E sum_t M_*(X_t) - [ K q_n J_n + (K-1) c_1 n q_n^{-1/2} + L sqrt(D) n h_n ] >= E sum_t M_*(X_t) - (K 2^{D+1} + (K-1) c_1 + L sqrt(D)) n^{(D+2)/(D+3)}.

The constants depend only on K, D, L. QED.

### 3.5 Proof of Theorem T4

**(a) Necessity.** Assume nu(W_i) > 0 and fix g_0 > 0 and A subset W_i as in Lemma 6: nu(A) > 0 and, on A, M_i(x_i) - r_i(X) >= g_0 and s_i(X) >= g_0. Put epsilon := g_0/2.

Good cells. For a level k, call a cell C in D_k with nu(C) > 0 good if

(G1) nu(A | C) >= 1/2, and (G2) gamma_C := bar M_{i,C} - max_{j != i} bar M_{j,C} >= 3 g_0/4;

let Good_k be the union of the good level-k cells (a Borel set, a finite union of cells).

The deviation. m'_n(X) := M_i(x_i) - epsilon 1_A(X) 1_{Good_{k_n}}(X). This is a Borel map of the full profile, chosen before play knowing n (it depends on n through k_n, i.e. it is grid-aligned, which S_HDS permits: maps may depend on n). Feasibility: off A cap Good_{k_n}, m'_n = M_i. On A, s_i >= g_0 > epsilon; if i is strategic, s_i = M_i and m'_n = M_i - g_0/2 >= g_0/2 > 0; if i is honest, s_i = M_i - mu_i and m'_n = M_i - g_0/2 >= mu_i + g_0/2 > mu_i. So m'_n is feasible, and honest-feasible when i is honest; m'_n in S_HDS.

Lower bound on the gain. Apply the decomposition of 3.2 to m^1 = (m'_n, S^max_{-i}) and m^0 = S^max: gain = (exploration change) + sum_{C : nu(C) > 0} G_C. By Lemma 7 the exploration change is >= 0, so gain >= sum_C G_C.

Cells that are not good. On such a cell m'_n = M_i identically, so on every exploration round of i in C both executions produce the same reward (Lemma 3(i), same X_t and U_t); hence hat I'_C = hat I^0_C pointwise, p'_C = p_C, and delta_C = E[M_i - m'_n | C] = 0; thus G_C = 0.

Good cells. Here delta_C = epsilon nu(A | C) in [epsilon/2, epsilon] = [g_0/4, g_0/2] by (G1), and bar m'_C = bar M_{i,C} - delta_C. For each rival j != i, by (G2),

bar m'_C - bar M_{j,C} >= gamma_C - epsilon >= 3 g_0/4 - g_0/2 = g_0/4 =: Delta_0 > 0.

On {V_C >= K q_n}, if hat m'_{i,C} > hat m_{j,C} for every j != i then i is the strict maximizer and wins irrespective of pi_C; hence {hat I'_C != i} subset cup_{j != i} {hat m_{j,C} >= hat m'_{i,C}}. Conditionally on (E_C, sigma, pi), by Lemma 1(d) and Lemma 2 with a := bar M_{j,C}, b := bar m'_C (gap at least Delta_0), each event in the union has probability at most 2 exp(-q_n Delta_0^2/2) = 2 exp(-q_n g_0^2/32); a union bound and integration over {V_C >= K q_n} give

1 - p'_C <= 2 (K-1) exp(-q_n g_0^2/32) =: rho_n.

By Lemma 3(iv) and p_C <= 1, 0 <= p_C - p'_C <= 1 - p'_C <= rho_n; also a_C in [0,1] (because mu_i <= M_i <= 1 pointwise). Therefore, per exploitation visit,

p'_C (a_C + delta_C) - p_C a_C = p'_C delta_C - (p_C - p'_C) a_C >= (1 - rho_n) g_0/4 - rho_n =: lambda_n.

Consequently, whenever lambda_n >= 0,

gain >= lambda_n sum_{C good} E[N_C] >= lambda_n sum_{C good} ( E[V_C] - K q_n ) = lambda_n ( n nu(Good_{k_n}) - K q_n #{good cells} ) >= lambda_n ( n nu(Good_{k_n}) - K q_n J_n ),

using N_C >= V_C - K q_n and E[V_C] = n nu(C).

Mass of the good cells. Apply Lemma 4(ii) to the bounded Borel functions 1_A (A is Borel because M_j and mu_i are Borel) and M_1, ..., M_K: for nu-a.e. X, nu(A | C_k(X)) = 1_A^{(k)}(X) -> 1_A(X) and gamma_{C_k(X)} = M_i^{(k)}(X) - max_{j != i} M_j^{(k)}(X) -> M_i(x_i) - r_i(X). For nu-a.e. X in A the limits are 1 > 1/2 and >= g_0 > 3 g_0/4, so there is k_0(X) such that C_k(X) is good for every k >= k_0(X); that is, 1_{Good_k}(X) -> 1 for nu-a.e. X in A. Bounded convergence gives nu(Good_k cap A) -> nu(A), so there is k_1 with nu(Good_k) >= nu(Good_k cap A) >= nu(A)/2 for all k >= k_1.

Choice of n_0 and the constant. Let n_0 be such that for all n >= n_0: (1) k_n >= k_1 (possible since k_n -> infinity); (2) rho_n <= g_0/(8 + 2 g_0), which holds as soon as q_n >= (32/g_0^2) log( 2(K-1)(8 + 2 g_0)/g_0 ), hence for n >= [ (32/g_0^2) log( 2(K-1)(8 + 2 g_0)/g_0 ) ]^{(D+3)/2}, and which gives lambda_n >= g_0/8 (indeed lambda_n - g_0/8 = g_0/8 - rho_n (1 + g_0/4) >= 0); (3) K q_n J_n <= n nu(A)/4, which holds for n >= ( 2^{D+3} K / nu(A) )^{D+3} because K q_n J_n <= K 2^{D+1} n^{(D+2)/(D+3)}. Then for all n >= n_0,

gain >= (g_0/8) ( n nu(A)/2 - n nu(A)/4 ) = ( g_0 nu(A) / 32 ) n = c n, c := g_0 nu(A)/32 > 0.

Thus agent i gains linearly, and S^max is not an S_HDS-asymptotic equilibrium. (Threshold (1) is not explicit: it is the level from which the good cells carry at least half of the mass of A, which exists by almost sure convergence but has no rate for general nu.) QED (a).

**(b) Sufficiency, including honest knife-edge unique tops.** Assume nu(W_i) = 0 for every i. Fix i and a deterministic deviation m' (honest-feasible if i is honest; mixtures by 3.6). As in 3.2, gain <= q_n J_n + sum_C G_C, and Proposition P gives G_C <= E[N_C] min{delta_C, c_1 q_n^{-1/2} + eta_{i,C}}.

Strategic i: W_i = U_i has nu-mass 0, so E_n(i) -> 0 by Lemma 4(iv), and the T1 bound with E'_n(i) = E_n(i) applies verbatim.

Honest i: nu(U_i cap {mu_i < M_i}) = 0, so for nu-a.e. X in U_i, mu_i(x_i) = M_i(x_i), and honesty (m' >= mu_i everywhere) together with feasibility (m' <= M_i) force m'(X) = M_i(x_i) for nu-a.e. X in U_i. Hence, nu-a.e., 0 <= M_i - m' = (M_i - m') 1_{U_i^c} <= (M_i - mu_i) 1_{U_i^c}, and integrating over nu(. | C): delta_C <= sigma_{i,C} := E[(M_i - mu_i) 1_{U_i^c} | C]. Since min{s, c + e} <= c + min{s, e} for c >= 0, Proposition P gives G_C <= n nu(C) [ c_1 q_n^{-1/2} + min{sigma_{i,C}, eta_{i,C}} ], and summing,

gain <= q_n J_n + c_1 n q_n^{-1/2} + n E'_n(i), E'_n(i) := sum_C nu(C) min{sigma_{i,C}, eta_{i,C}} = int min{ sigma_i^{(k_n)}, eta_i^{(k_n)} } dnu,

where sigma_i^{(k)} := E[(M_i - mu_i) 1_{U_i^c} | F_k] (the set U_i is Borel, so the integrand is bounded Borel). By Lemma 4(ii),(iii), nu-a.s., sigma_i^{(k)} -> (M_i - mu_i) 1_{U_i^c} and eta_i^{(k)} -> (M_i - r_i) 1_{U_i}; at every X one of the two indicators vanishes, so min{sigma_i^{(k)}, eta_i^{(k)}} -> 0 nu-a.s.; the minimum lies in [0,1]; bounded convergence gives E'_n(i) -> 0 along k_n -> infinity. Hence the gain is o(n) uniformly over honest-feasible deviations. Together with the strategic case, S^max is an S_HDS-asymptotic equilibrium. T1 is the special case in which nu(U_i) = 0 for all i (then nu(W_i) = 0 for all i regardless of honesty).

Characterization. (a) shows that nu(W_i) > 0 for some i rules out equilibrium; (b) shows that nu(W_i) = 0 for all i implies equilibrium. QED (T4).

### 3.6 Independent ex ante mixtures

Let agent i's deviation be a mixture: a random variable xi, independent of (X_{1:n}, U_{1:n}, sigma, pi), together with a jointly Borel map (xi, X) -> m^xi(X) such that every m^x is feasible (honest-feasible if i is honest). Enlarge the space of Lemma 1 by xi. The execution against the random map is, pathwise, the execution of Lemma 1 against the map m^xi, and it is jointly measurable in (xi, omega). Conditionally on xi = x, by independence, the law of the execution is that of Lemma 1 with the deterministic map m^x; hence E[ utility of i | xi ] = u_i(n; m^xi, S^max_{-i}) a.s., a bounded measurable function of xi (Fubini's theorem), and

u_i(n; mixture, S^max_{-i}) = E[ u_i(n; m^xi, S^max_{-i}) ].

The upper bounds of T1, T2, and T4(b) hold for every realized deterministic map with a right-hand side that does not depend on the map (it involves only n, D, K, L, nu, and the capacities), so they hold after taking the expectation over xi. This is exactly the manuscript's convention "uniform after conditioning on realized ex ante maps and hence also for their independent mixtures". T3 involves no deviation, and T4(a) exhibits a deterministic deviation, which is an element of S_HDS. This completes the proofs of T1 to T4 for the full class S_HDS.

### 3.7 Remark: relation to the manuscript's thm:contextual-public and an explicit rate under its hypotheses

The manuscript's hypotheses (a closed nu-null B such that X \ B has finitely many connected components, on each of which the top set is constant and has at least two agents whenever the component has positive mass) imply nu(|T(X)| >= 2) = 1: the exceptional set is contained in B together with the zero-mass components. Hence T1 and T3 contain the equilibrium and revenue statements of thm:contextual-public, and T1 does so for all Borel capacities (continuity is not needed) and without any component structure. Under the manuscript's hypotheses one also gets an explicit rate from Proposition P: a cell C is convex hence connected, so a cell disjoint from B lies in one component; there the top set T is constant with |T| >= 2, and for every i one finds j' in T \ {i} with M_{j'}(x_{j'}) = M_*(X) >= M_i(x_i) on C, so max_{j != i} bar M_{j,C} >= bar M_{j',C} >= bar M_{i,C} and eta_{i,C} = 0. A cell meeting B is contained in the closed sqrt(D) h_n-neighborhood B^{sqrt(D) h_n}, and eta_{i,C} <= 1. Therefore E_n(i) <= nu(B^{sqrt(D) h_n}), and T1 yields, for every n, i, and deviation,

u_i(n; m', S^max_{-i}) - u_i(n; S^max) <= q_n J_n + c_1 n q_n^{-1/2} + n nu(B^{sqrt(D) h_n}),

where nu(B^{sqrt(D) h_n}) -> nu(B) = 0 by continuity from above (B closed, so the intersection of its closed eps-neighborhoods is B). This replaces the manuscript's dominated-convergence step for non-top agents by an explicit boundary term and requires no continuity of the capacities.

## 4. Where every assumption is used

1. Profiles i.i.d. nu, exogenous, independent of reward seeds and platform coins: Lemma 1 (construction; (b) conditional i.i.d. law given membership; (d) i.i.d. exploration rewards; (e) factorization (F)); E[V_C] = n nu(C) in Proposition P, T3, and T4(a); every integral against nu in Lemma 4. Without the i.i.d. (at least within-cell exchangeable, schedule-independent) structure, Lemma 1(d) fails (contract Section 11, item 5).
2. Maps fixed before play (S_HDS, no adaptation to phases, counts, or rewards): Lemma 1(d) (bar m_{j,C} is the integral of one fixed map, and the same map is used at exploration and exploitation, so the exploitation cell mean a_C + delta_C is tied to the exploration law through delta_C); Lemma 3 (the compared executions use the same map on every round); Proposition P (the tail bound on p'_C controls the exploitation term because the same delta_C appears in both). A phase-dependent strategy breaks this link (the manuscript's closing remark on bait-and-switch).
3. Borel measurability of M_j, mu_j, m': all conditional means exist; Lemma 4 (conditional expectations); Borel measurability of U_i, W_i, A, Good_k in T4.
4. Feasibility 0 <= m' <= M_i pointwise: Lemma 3(iii) (score domination), delta_C >= 0 (Proposition P, Step 2 and Case Delta' <= 0), Lemma 7 (exploration change in [0, q_n J_n], lower bound 0 used in T4(a)).
5. Honesty (m' >= mu_i pointwise): used only in T4: definition of W_i, honest feasibility of m'_n in T4(a) (slack g_0), and delta_C <= sigma_{i,C} in T4(b).
6. Two-top almost everywhere, nu(|T| >= 2) = 1 (equivalently nu(U_i) = 0 for all i, Lemma 4(v)): T1 uses it only to conclude E_n(i) -> 0 (Lemma 4(iv),(v)); T2 uses it in Lemma 5(c). T3 does not use it. T4 replaces it by nu(W_i) = 0.
7. Lipschitz capacities: T2 (Lemma 5(c), only rivals' capacities are needed); T3 second part (Lemma 5(b)). Nowhere else; intrinsic means are never assumed Lipschitz in this task.
8. Nested dyadic grid with k_n = ceil(log_2(n)/(D+3)): nesting makes (F_k) a filtration and gives sigma(cup_k F_k) = B(X) (Lemma 4(i)); Levy's upward theorem needs the filtration (Lemma 4(ii)); used in the convergence statements of T1 (E_n(i) -> 0), T3 (B_n -> 0), T4(a) (mass of good cells) and T4(b) (E'_n(i) -> 0). Points a referee may press, and my assessment.
1. T1's remainder n E_n(i) has no rate for general Borel capacities and general nu; this is intrinsic (E_n(i) is the integral of a conditional-expectation defect, which can go to zero arbitrarily slowly). T2 gives the rate under Lipschitz capacities, and Section 3.7 gives an explicit boundary rate under the manuscript's component hypotheses.
2. T4(a)'s threshold n_0 is not explicit in one of its three conditions (the level from which the good cells carry half of nu(A)); the constant c = g_0 nu(A)/32 is explicit. If A contains a nonempty open set, or more generally a whole dyadic cell of some level, that condition becomes explicit (from that level on, the cells inside it are good once (G2) holds, which can be checked directly); I did not pursue this.
3. T4(a)'s deviation is grid-aligned and uses nu and the rivals' capacities (to identify the good cells). The contract explicitly admits grid-aligned maps in S_HDS, and Definition 1 quantifies over all maps in the class, so this is a valid witness of non-equilibrium; but the reader should not read it as a behaviorally natural deviation. A simpler deviation, "shade by epsilon on all of A", can lose linearly in cells that contain a small portion of A and a tie region of positive mass, which is why the grid-aligned witness was used.
4. T4(a) uses the default observation model (the selected agent sees the full profile). Under own-context-only observation the sets U_i and A are not functions of x_i in general and the statement would need a different witness; T1, T2, T3, T4(b) are unaffected.
5. Lemma 2 is applied conditionally on (E_C, sigma, pi); the required independence within each sample is exactly Lemma 1(d). No independence across agents is used anywhere (though it holds).
6. The manuscript's proof of thm:contextual-public asserts p'_C delta_C = O(q_n^{-1/2}) in interior cells; Proposition P shows that in general the correct bound is c_1 q_n^{-1/2} + eta_{i,C}, and that eta_{i,C} = 0 in interior cells under the manuscript's hypotheses (Section 3.7). So the manuscript's argument is repaired, not contradicted, and its dominated-convergence step for non-top agents is subsumed.
7. Nothing in the proofs uses the publicity of M_*. If the paper wants to keep "M_* public" in the statement, it should be described as the informational premise for the profile, not as a hypothesis of the proof.
8. I did not find any step that I could not close. If the referee comparison finds a discrepancy with the independent proof, the most delicate steps are Lemma 1(e) (the conditional law given membership indicators is the same product law for every indicator sequence with at least K q_n visits) and Lemma 3(iv) (tie handling in the coupling).
