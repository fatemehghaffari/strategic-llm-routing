## 1. Setting, algorithm, and exact theorem statements

### 1.1 Setting (as it should appear in the paper)

Profiles. `X = [0,1]^D`, `D = Kd`, profile `X = (x_1,...,x_K)` with `x_i in [0,1]^d`. Profiles `X_t`, `t = 1,...,n`, are i.i.d. with a Borel law `nu` on `X`, exogenous and independent of all reward seeds, of the platform's randomization, and of the agents' ex ante randomizations. Capacities `M_i : [0,1]^d -> [0,1]` and intrinsic means `mu_i : [0,1]^d -> [0,1]` are Borel with `mu_i <= M_i` pointwise. `M_*(X) := max_i M_i(x_i)`, `T(X) := {i : M_i(x_i) = M_*(X)}`, and for each `i`
`V_i(X) := max_{j != i} M_j(x_j)`, `gap_i(X) := M_i(x_i) - V_i(X)`, `U_i := {X : gap_i(X) > 0}` (agent `i` is the unique top at `X`).
Then `{X : |T(X)| = 1} = union_i U_i` (disjoint union), so `nu(|T(X)| >= 2) = 1` if and only if `nu(U_i) = 0` for every `i`.

Strategies. `S_HDS`: agent `i` chooses, before play and knowing `n`, a Borel map `m_{i,n} : X -> [0,1]` with `0 <= m_{i,n}(X) <= M_i(x_i)` for every `X` (honest agents: `mu_i(x_i) <= m_{i,n}(X)`), and uses it at every selection; independent ex ante randomization over such maps is allowed (the realized map is independent of the profiles, the reward seeds, the platform's coins, and the other agents' maps, and the utility under a mixture is the mixture of the utilities). Maps may depend on `n` and hence on the grid. `S^max` is the profile `m_{i,n} = M_i` for every `i`. Utilities: `u_i(n;S) = E_S[sum_{t<=n} 1{I_t = i}(1 + mu_i(x_{i,t}) - m_{i,t})]`, `P(n;S) = E_S[sum_{t<=n} m_{I_t,t}]`. Per-pull utility lies in `[0,2]`; at capacity it lies in `[0,1]` because `mu_i <= M_i <= 1`.

Nested dyadic grid. For `k >= 0` and `a in {0,...,2^k - 1}` put `I_{k,a} := [a 2^{-k}, (a+1) 2^{-k})` if `a < 2^k - 1` and `I_{k,2^k-1} := [1 - 2^{-k}, 1]`. The level-`k` cells are the `2^{kD}` products `prod_{l=1}^D I_{k,a_l}`. They partition `[0,1]^D`, each is a Borel set of Euclidean diameter at most `sqrt(D) 2^{-k}`, and every level-`k` cell is the disjoint union of `2^D` level-`(k+1)` cells (nesting). On `[0,1)^D` these are exactly the standard half-open dyadic cubes; the only change relative to the task's `[0,1)^D` is that the last cell in each coordinate is closed at `1`, which keeps the partition, nesting, and diameter properties and covers the manuscript's space `[0,1]^D` without a null-set assumption. `C_k(X)` denotes the level-`k` cell containing `X`. `F_k := sigma(level-k cells)`, the finite sigma-algebra generated by the level-`k` partition; `F_k subset F_{k+1}` by nesting.

For the horizon `n >= 1`: `k_n := ceil(log_2(n)/(D+3))`, `h_n := 2^{-k_n}`, `J_n := 2^{k_n D} = h_n^{-D}`, `q_n := ceil(n^{2/(D+3)})`. Then `n^{-1/(D+3)}/2 < h_n <= n^{-1/(D+3)}`, `J_n < 2^D n^{D/(D+3)}`, `n^{2/(D+3)} <= q_n <= 2 n^{2/(D+3)}`, and `k_n -> infinity`.

Static Grid-ETC (level `k_n`). Before play the platform draws, for every cell `C`, independent uniform permutations `pi_{C,1},...,pi_{C,q_n}` of `[K]` and an independent uniform priority permutation `sigma_C` of `[K]` (lazy initialization has the same law). At round `t` the platform locates `C = C_{k_n}(X_t)`; if this is the `k`-th visit to `C` and `k <= K q_n`, it selects agent `pi_{C,b}(r)` where `b = ceil(k/K)` and `r = k - K(b-1)` (block `b`, position `r`); if `k > K q_n`, it selects the committed agent `hat I_C`, defined after the `K q_n`-th visit as the agent with the largest exploration empirical mean (each over exactly `q_n` observations), ties resolved toward the smallest `sigma_C`-rank. Exploitation rewards are ignored. The exact within-cell position is never used.

Cell quantities. For a cell `C` with `nu(C) > 0` and a map `m`: `bar m_C := E[m | C]`; `bar M_{j,C} := E[M_j(x_j) | C]`; `bar M_C := E[M_* | C]`; for agent `i`,
`eta_{i,C} := (bar M_{i,C} - max_{j != i} bar M_{j,C})_+`, `theta_C := bar M_C - max_j bar M_{j,C} >= 0`.
Zero-mass cells are never visited (Lemma 2.1(a)); all sums over cells below run over positive-mass cells, and the convention `nu(C) eta_{i,C} := 0` when `nu(C) = 0` makes them well defined. `c_1 := 2 e^{-1/2} = 1.2130...`.

### 1.2 Theorem statements

Theorem T1 (equilibrium under two-top almost everywhere; measurable capacities). Let `nu` be any Borel probability law on `[0,1]^D` and let the capacities and intrinsic means be Borel. Assume `nu(|T(X)| >= 2) = 1` and `M_*` public. Then under Static Grid-ETC on the level-`k_n` dyadic grid, for every agent `i` (honest or strategic), every `n >= 1`, and every unilateral deviation `m'_{i,n} in S_HDS` (a deterministic feasible map, or an independent ex ante mixture of such maps),
`u_i(n; m'_{i,n}, S^max_{-i}) - u_i(n; S^max) <= q_n J_n + c_1 n q_n^{-1/2} + n sum_C nu(C) eta_{i,C}`, (T1.1)
where the sum runs over the level-`k_n` cells, and `sum_C nu(C) eta_{i,C} -> 0` as `n -> infinity`. Consequently the right-hand side of (T1.1) is `o(n)` uniformly over deviations, and `S^max` is an `S_HDS`-asymptotic equilibrium.

Theorem T1' (exact characterization; per-agent version). Drop the assumption `nu(|T| >= 2) = 1`. For agent `i` let `s_i(X) := M_i(x_i) - mu_i(x_i)` if `i` is honest and `s_i(X) := M_i(x_i)` if `i` is strategic (the maximal feasible shading at `X`), and `W_i := U_i cap {s_i > 0}`. If `nu(W_i) = 0`, then for every `n` and every deviation `m'_{i,n} in S_HDS`,
`u_i(n; m'_{i,n}, S^max_{-i}) - u_i(n; S^max) <= q_n J_n + c_1 n q_n^{-1/2} + n sum_C nu(C) kappa_{i,C}`, `kappa_{i,C} := min{eta_{i,C}, E[s_i 1_{U_i^c} | C]}`,
and `sum_C nu(C) kappa_{i,C} -> 0`. Together with Theorem T4 this gives: `S^max` is an `S_HDS`-asymptotic equilibrium if and only if `nu(W_i) = 0` for every `i`. In particular an honest unique top without downward slack (`nu(U_i) > 0` but `nu(W_i) = 0`) is a knife-edge case that remains an equilibrium.

Theorem T2 (explicit rate under Lipschitz capacities). Assume in addition to Theorem T1 that every `M_i` is `L`-Lipschitz with respect to the Euclidean norm on `[0,1]^d`. Then `eta_{i,C} <= 2 L sqrt(D) h_n` for every positive-mass level-`k_n` cell and every `i`, hence for every `n >= 1`, every `i`, and every deviation in `S_HDS`,
`u_i(n; m'_{i,n}, S^max_{-i}) - u_i(n; S^max) <= q_n J_n + c_1 n q_n^{-1/2} + 2 L sqrt(D) n h_n <= (2^{D+1} + c_1 + 2 L sqrt(D)) n^{(D+2)/(D+3)}`.
The constant depends only on `D` and `L` (there is no top/non-top case split and no dependence on `K` beyond `D = Kd`).

Theorem T3 (revenue at all-maximum play; no top-set condition). Under Static Grid-ETC, for every `n >= 1`:
(a) if every `M_i` is `L`-Lipschitz, `P(n; S^max) >= E sum_{t<=n} M_*(X_t) - [K q_n J_n + (K-1) c_1 n q_n^{-1/2} + 2 L sqrt(D) n h_n] >= E sum_{t<=n} M_*(X_t) - (K 2^{D+1} + (K-1) c_1 + 2 L sqrt(D)) n^{(D+2)/(D+3)}`;
(b) if the capacities are merely Borel, `P(n; S^max) >= E sum_{t<=n} M_*(X_t) - [K q_n J_n + (K-1) c_1 n q_n^{-1/2} + n sum_C nu(C) theta_C]` and `sum_C nu(C) theta_C -> 0`, so the deficit is `o(n)`.

Theorem T4 (necessity). Let `W_i` be as in Theorem T1'. If `nu(W_i) > 0`, pick `g_0 > 0` with `alpha := nu(A) > 0` for `A := {X : gap_i(X) >= g_0, s_i(X) >= g_0}` (such `g_0` exists because `W_i = union_{m >= 1} {gap_i >= 1/m, s_i >= 1/m}`). Then there exist `n_0` (depending on the instance) and a unilateral deviation of agent `i` in `S_HDS` (feasible, and honest if `i` is honest) such that for all `n >= n_0`
`u_i(n; m'_{i,n}, S^max_{-i}) - u_i(n; S^max) >= (g_0 alpha / 16) n`.
The deviation can be taken grid-aligned (shade by `g_0/2` on `A` inside a set of "good" level-`k_n` cells), or, at the price of one more standard fact (inner regularity of Borel probability measures on a metric space), horizon-independent (shade by `g_0/2` on a closed subset of `A` of positive mass; then the constant is `g_0 alpha/32`). Hence `S^max` is not an `S_HDS`-asymptotic equilibrium whenever `nu(W_i) > 0` for some `i`, and in particular not when a strategic agent is the unique top on a set of positive `nu`-mass.

Remark (relation to the manuscript's thm:contextual-public). Theorem T1 needs none of: continuity of capacities, a closed `nu`-null separator `B`, finitely many components, or a constant top set per component. Its hypothesis `nu(|T| >= 2) = 1` is implied by the manuscript's hypotheses (on each positive-mass component the top set has size at least two and `nu(B) = 0`), so T1 strictly generalizes thm:contextual-public; T2 adds the explicit rate; T1' and T4 give the sharp characterization.

## 2. Lemmas with complete proofs

### 2.0 Probability space and realization of the model

Fix the horizon `n`, the grid level `k_n`, and (after conditioning on any ex ante randomization) the realized Borel maps `m_1,...,m_K`. Let `(Omega, F, P)` carry the following mutually independent families:
(R1) `X_1,...,X_n` i.i.d. `nu`;
(R2) `U_1,...,U_n` i.i.d. Uniform`[0,1]` (one reward seed per round);
(R3) for every level-`k_n` cell `C`: `pi_{C,1},...,pi_{C,q_n}` i.i.d. uniform on the symmetric group of `[K]`, and `sigma_C` uniform on the symmetric group, all independent across cells;
(R4) the agents' ex ante randomizations, if any (used only through conditioning).
Execution. `C_t := C_{k_n}(X_t)`; `kappa_t := #{s <= t : C_s = C_t}` (visit index of round `t` in its cell); if `kappa_t <= K q_n`, `I_t := pi_{C_t,b}(r)` with `b = ceil(kappa_t/K)`, `r = kappa_t - K(b-1)`; if `kappa_t > K q_n`, `I_t := hat I_{C_t}`. Target `m_{I_t,t} := m_{I_t}(X_t)`; reward `Y_t := 1{U_t <= m_{I_t}(X_t)}`. For a cell `C` and agent `j`, `hat m_{j,C} := q_n^{-1} sum_{t : C_t = C, kappa_t <= K q_n, I_t = j} Y_t` (agent `j` occupies exactly one position of each block, so the sum has exactly `q_n` terms once the cell has had `K q_n` visits), and `hat I_C := argmin{sigma_C(j) : j in argmax_l hat m_{l,C}}`.
This construction realizes the model: `(X_s, I_s, Y_s)_{s < t}`, `X_t`, `I_t`, and the target are functions of `X_1,...,X_t`, `U_1,...,U_{t-1}`, (R3), so `U_t` is independent of them and `P(Y_t = 1 | past, X_t, I_t) = m_{I_t}(X_t)`; the profiles are i.i.d. `nu` and independent of everything else. The utilities `u_i(n; .)` and `P(n; .)` are functionals of the joint law of `(X_t, I_t, m_{I_t,t})_{t <= n}`, which is determined by these conditional specifications (chain rule), so any construction with the same conditional specifications gives the same utilities. The manuscript indexes reward uniforms by the agent's local pull index; the round-indexed construction above has the same law and is the one used for the couplings below (contract, Section 14, item 1: the indexing is stated explicitly).

### Lemma 2.1 (cell law; the manuscript's lem:cell-law made explicit)

Fix a level-`k_n` cell `C`. Let `B := (1{X_t in C})_{t <= n}` (membership sequence), `V_C := sum_t 1{X_t in C}`, `tau_C(k)` the round of the `k`-th visit to `C` (`k <= V_C`), `X_C^{(k)} := X_{tau_C(k)}`, `U_C^{(k)} := U_{tau_C(k)}`, and `Z_j^{(k)} := 1{U_C^{(k)} <= m_j(X_C^{(k)})}` (the potential reward of agent `j` on the `k`-th visit).
(a) If `nu(C) = 0` then `P(V_C = 0) = 1`; zero-mass cells never appear in any execution and need no conditional mean.
(b) If `nu(C) > 0`: conditional on `B`, the pairs `(X_C^{(k)}, U_C^{(k)})_{k <= V_C}` are i.i.d., with `X_C^{(k)} ~ nu(. | C)` and `U_C^{(k)}` uniform and independent of `X_C^{(k)}`; and this family is independent of (R3), of (R4), and of `(X_t, U_t)` at the rounds with `X_t notin C`.
(c) Conditional on `B`, for each fixed `j`, `(Z_j^{(k)})_{k <= V_C}` are i.i.d. Bernoulli(`bar m_{j,C}`), `bar m_{j,C} := E[m_j | C]`; the vectors `(Z_1^{(k)},...,Z_K^{(k)})` are independent across `k` (coordinates within a vector may be dependent).
(d) Let `A_k := pi_{C, ceil(k/K)}(k - K(ceil(k/K) - 1))` be the agent scheduled at exploration visit `k <= K q_n`, and `E_j := {k <= K q_n : A_k = j}`; then `|E_j| = q_n`, `E_j` is a function of (R3) only, and on `{V_C >= K q_n}`, conditional on `B` and (R3), `hat m_{j,C} = q_n^{-1} sum_{k in E_j} Z_j^{(k)}` is the mean of `q_n` i.i.d. Bernoulli(`bar m_{j,C}`) variables, for every `j`. The commitment `hat I_C` is a function of `(Z^{(k)})_{k <= K q_n}` and (R3); hence, conditional on `B`, it is independent of `(X_C^{(k)})_{k > K q_n}`, and `p_{j,C} := P(hat I_C = j | B)` on `{V_C >= K q_n}` does not depend on the value of `B`.
(e) (Factorization.) For every bounded Borel `w : X -> R` and every `j`,
`E[ sum_{k = K q_n + 1}^{V_C} 1{hat I_C = j} w(X_C^{(k)}) ] = N_C p_{j,C} E[w | C]`, `N_C := E[(V_C - K q_n)_+]`, with `N_C <= E V_C = n nu(C)`.
(f) (Exploration.) The exploration visits at which `j` is selected are `{tau_C(k) : k in E_j, k <= V_C}`, at most `q_n` of them, and this set is a function of `B` and (R3) only.

Proof. (a) `P(V_C >= 1) <= n nu(C) = 0`.
(b) If `nu(C) = 1` then `B = (1,...,1)` a.s. and the claim is the i.i.d. hypothesis. Let `0 < nu(C) < 1`, `C^1 := C`, `C^0 := X \ C`. For `b in {0,1}^n` and Borel `A_t subset X`, `E_t subset [0,1]`, independence across rounds gives `P(X_t in A_t, U_t in E_t for all t, B = b) = prod_t nu(A_t cap C^{b_t}) Leb(E_t)`, and `P(B = b) = prod_t nu(C^{b_t}) > 0`. Dividing, conditional on `B = b` the pairs `(X_t, U_t)` are independent across `t`, with `X_t ~ nu(. | C)` for the rounds with `b_t = 1` and `U_t` uniform and independent of `X_t`. Relabeling the rounds with `b_t = 1` in increasing order gives the claim for `(X_C^{(k)}, U_C^{(k)})`. (R3) and (R4) are independent of `(X, U)` and hence of `((X, U), B)`.
(c) For `U` uniform and independent of `X ~ nu(. | C)`, Fubini gives `P(U <= m_j(X)) = E[m_j(X)] = bar m_{j,C}`. Independence across `k` follows from (b) because `Z^{(k)}` is a function of `(X_C^{(k)}, U_C^{(k)})`.
(d) Each permutation places `j` in exactly one position, so `|E_j| = q_n`. Conditional on `B` and (R3), the `Z_j^{(k)}`, `k in E_j`, are i.i.d. Bernoulli(`bar m_{j,C}`) by (c) and by the independence of (R3) from `(X, U)`. The observed exploration reward at visit `k` is `Y_{tau_C(k)} = Z_{A_k}^{(k)}`, so `hat m_{j,C}` is as displayed. `hat I_C` is a deterministic function of `(Z^{(k)})_{k <= K q_n}` and `sigma_C`, which by (b) and (c) are conditionally independent of `(X_C^{(k)})_{k > K q_n}` given `B`; and its conditional law given `B` on `{V_C >= K q_n}` is the image of a fixed law (that of `q_n K` i.i.d. Bernoulli vectors and (R3)), hence does not depend on `B`.
(e) Condition on `B`. For each `k` with `K q_n < k <= V_C`, (d) gives `E[1{hat I_C = j} w(X_C^{(k)}) | B] = p_{j,C} E[w | C]`. Summing the `(V_C - K q_n)_+` terms and integrating over `B` gives the display. `N_C <= E V_C = n nu(C)` because `V_C ~ Binomial(n, nu(C))`.
(f) Immediate from the definition of the schedule. QED.

Where i.i.d. profiles are used: (b) is exactly the place; nothing below uses more than (b) to (f).

### Lemma 2.2 (dyadic filtration and Levy's upward theorem)

Work on the probability space `([0,1]^D, Borel, nu)` with `X` the identity map; `F_k := sigma(level-k cells)`.
(a) `F_k subset F_{k+1}` for all `k` (this is where nesting of the dyadic grids is used).
(b) `F_infty := sigma(union_k F_k)` equals the Borel sigma-algebra of `[0,1]^D`.
(c) For bounded Borel `f`, the function `f_k(X) := sum_{C level k, nu(C) > 0} 1_C(X) E[f | C]` (and `f_k := 0` on null cells) is a version of `E_nu[f | F_k]`.
(d) `f_k(X) -> f(X)` for `nu`-a.e. `X`.
(e) Let `f_1,...,f_m` be bounded Borel and `Phi : R^m -> R` continuous. Then `Phi((f_1)_k(X),...,(f_m)_k(X)) -> Phi(f_1(X),...,f_m(X))` `nu`-a.s., and if `Phi` is bounded on the bounded range of these vectors, `int Phi((f_1)_k,...,(f_m)_k) dnu -> int Phi(f_1,...,f_m) dnu`.

Proof. (a) Each level-`k` cell is the disjoint union of the `2^D` level-`(k+1)` cells obtained by halving each coordinate interval (for the right-closed last interval `[1 - 2^{-k}, 1]` the halves are `[1 - 2^{-k}, 1 - 2^{-k-1})` and `[1 - 2^{-k-1}, 1]`, again of the prescribed form). Hence every `F_k`-set is a union of level-`(k+1)` cells.
(b) Every cell is a product of intervals, hence Borel, so `F_infty subset Borel`. Conversely let `G` be relatively open in `[0,1]^D`, `G = G' cap [0,1]^D` with `G'` open in `R^D`. For `X in G` choose `r > 0` with the open ball `B(X, r) subset G'`. Every point of `C_k(X)` is at Euclidean distance at most `sqrt(D) 2^{-k}` from `X` (each coordinate differs by less than or equal to `2^{-k}`), so for `k` with `sqrt(D) 2^{-k} < r` we get `C_k(X) subset B(X, r) cap [0,1]^D subset G`. Thus `G` is a union of dyadic cells; there are countably many dyadic cells altogether, so `G` is a countable union of cells and `G in F_infty`. The relatively open sets generate the Borel sigma-algebra, so `Borel subset F_infty`.
(c) `f_k` is `F_k`-measurable (constant on cells). For `G in F_k`, `G` is a finite disjoint union of level-`k` cells, and `int_G f_k dnu = sum_{C subset G, nu(C) > 0} nu(C) E[f | C] = sum_{C subset G} int_C f dnu = int_G f dnu` (null cells contribute zero to both sides). This is the defining property of `E_nu[f | F_k]`.
(d) `f in L^1(nu)` since bounded. By Levy's upward theorem (Durrett, Probability: Theory and Examples, 5th edition, Theorem 4.6.8: if `F_k` increases to `F_infty = sigma(union_k F_k)` then `E(f | F_k) -> E(f | F_infty)` a.s. and in `L^1`; equivalently Williams, Probability with Martingales, Chapter 14, Levy's Upward Theorem), `f_k -> E_nu[f | F_infty]` a.s. By (b), `f` is `F_infty`-measurable, so `E_nu[f | F_infty] = f` a.s.
(e) Apply (d) to each `f_l` and intersect the `m` full-measure events; continuity of `Phi` gives the a.s. convergence; bounded convergence (dominated convergence with a constant dominating function, valid since `nu` is a probability measure) gives the convergence of integrals. QED.

Corollary 2.2' (the three vanishing sums). Write `f_j(X) := M_j(x_j)`, a bounded Borel function on `[0,1]^D` (composition of the Borel `M_j` with the continuous coordinate projection); likewise `M_*`, `gap_i`, `s_i 1_{U_i^c}` are bounded Borel (`U_i = {gap_i > 0}` is Borel). For a level-`k` cell `C` with `nu(C) > 0`, `bar M_{j,C} = (f_j)_k` on `C`. Let the sums run over level-`k` cells, null cells contributing zero.
(i) If `nu(U_i) = 0` then `sum_C nu(C) eta_{i,C} = int eta_{i,C_k(X)} nu(dX) -> 0` as `k -> infinity`.
(ii) Always, `sum_C nu(C) theta_C -> 0`.
(iii) If `nu(W_i) = 0` then `sum_C nu(C) kappa_{i,C} -> 0`, where `kappa_{i,C} = min{eta_{i,C}, E[s_i 1_{U_i^c} | C]}`.
(iv) Since `k_n -> infinity`, each of these sums evaluated on the level-`k_n` grid tends to zero as `n -> infinity`.
Proof. (i) Take `Phi(y) := (y_i - max_{j != i} y_j)_+`, continuous and `[0,1]`-valued on `[0,1]^K`. By Lemma 2.2(e), `eta_{i,C_k(X)} = Phi((f_1)_k(X),...,(f_K)_k(X)) -> Phi(M_1(x_1),...,M_K(x_K)) = (gap_i(X))_+` `nu`-a.s. The limit vanishes exactly off `U_i`, hence `nu`-a.s. when `nu(U_i) = 0`; bounded convergence gives `int eta_{i,C_k(X)} nu(dX) -> 0`, and this integral equals `sum_C nu(C) eta_{i,C}` because `eta_{i,C_k(X)}` is constant on cells. Under `nu(|T| >= 2) = 1` this applies to every `i`: on `{|T(X)| >= 2}` there is `j != i` with `M_j(x_j) = M_*(X) >= M_i(x_i)`, so `gap_i(X) <= 0` and `(gap_i(X))_+ = 0`; that is, `nu(U_i) = 0` for every `i`.
(ii) `Phi(y_0, y_1,...,y_K) := y_0 - max_j y_j` applied to `(M_*, f_1,...,f_K)`: the limit is `M_*(X) - max_j M_j(x_j) = 0` for every `X`. `theta_C in [0,1]` because `M_* >= M_j` pointwise.
(iii) `min{eta_{i,C_k(X)}, (s_i 1_{U_i^c})_k(X)} -> min{(gap_i(X))_+, s_i(X) 1_{U_i^c}(X)}` `nu`-a.s. by Lemma 2.2(e) with the continuous `Phi(y, z) := min{(y_i - max_{j != i} y_j)_+, z}`. For `X in U_i` the second entry is `0`; for `X notin U_i` the first is `0`. So the limit is identically zero, without any assumption; bounded convergence finishes. (The hypothesis `nu(W_i) = 0` is used in Theorem T1' to justify `delta_C <= E[s_i 1_{U_i^c} | C]`, not here.)
(iv) `k_n = ceil(log_2(n)/(D+3)) >= log_2(n)/(D+3) -> infinity`. QED.

### Lemma 2.3 (ETC tail bound; the manuscript's lem:etc-tail with the constant `c_1 = 2 e^{-1/2}`)

Let `hat a` and `hat b` be empirical means of `q` i.i.d. `[0,1]`-valued observations each, with means `a < b` (the two samples need not be independent of each other), `Delta := b - a`. Then
`P(hat a >= hat b) <= 2 e^{-q Delta^2 / 2}` and `Delta P(hat a >= hat b) <= c_1 q^{-1/2}`, `c_1 := 2 e^{-1/2} = 1.2130...`.
Proof. On `{hat a >= hat b}`, if `hat a - a < Delta/2` and `b - hat b < Delta/2` then `hat a < a + Delta/2 = b - Delta/2 < hat b`, a contradiction; hence `{hat a >= hat b} subset {hat a - a >= Delta/2} cup {b - hat b >= Delta/2}`. Hoeffding's inequality (Hoeffding 1963, Theorem 2: for independent `[0,1]`-valued `Z_1,...,Z_q` with mean `a`, `P(q^{-1} sum Z_l - a >= s) <= e^{-2 q s^2}`, and the same for the lower tail) with `s = Delta/2` bounds each event by `e^{-2 q Delta^2 / 4} = e^{-q Delta^2 / 2}`; the union bound gives the first claim. For the second, `Delta P(hat a >= hat b) <= min{Delta, 2 Delta e^{-q Delta^2/2}} <= sup_{x >= 0} 2 x e^{-q x^2/2}`. The function `g(x) := x e^{-q x^2/2}` has `g'(x) = e^{-q x^2/2}(1 - q x^2)`, positive on `(0, q^{-1/2})` and negative beyond, so `sup g = g(q^{-1/2}) = q^{-1/2} e^{-1/2}`, and `sup 2 g = 2 e^{-1/2} q^{-1/2} = c_1 q^{-1/2}`. QED.
(Numerical confirmation: `sup_x sqrt(q) 2 x e^{-q x^2/2} = 1.21306...` at `x sqrt(q) = 1` for `q in {1, 7, 64, 1000}`; script `checks.py` in the scratch directory.)

Consequence (K agents). If `hat m_1,...,hat m_K` are empirical means of `q` i.i.d. Bernoulli samples with means `bar m_1,...,bar m_K` (samples for different agents may be dependent), `j^*` attains `max_l bar m_l`, and `hat I` is any agent with `hat m_{hat I} = max_l hat m_l` (any tie rule), then `E[bar m_{j^*} - bar m_{hat I}] <= (K-1) c_1 q^{-1/2}`. Proof: `E[...] = sum_{j : bar m_j < bar m_{j^*}} (bar m_{j^*} - bar m_j) P(hat I = j)`, and `{hat I = j} subset {hat m_j >= hat m_{j^*}}`, so each term is at most `c_1 q^{-1/2}` by the lemma; there are at most `K - 1` such `j`.

### Lemma 2.4 (pathwise commitment coupling; the appendix A.4 coupling, with the tie priority)

Fix agent `i`, the other agents' maps, and two feasible maps `m' <= m''` pointwise for agent `i` (below, `m'' = M_i` and `m'` the deviation). Run the two executions on the same space of Section 2.0 (same (R1) to (R4)); primed quantities refer to `m'`. Then, for every cell `C`:
(a) the membership sequence `B`, the visit rounds `tau_C(k)`, the exploration schedule `A_k`, and every exploration selection `I_t` (`kappa_t <= K q_n`) coincide in the two executions;
(b) `hat m'_{i,C} <= hat m''_{i,C}` and `hat m'_{j,C} = hat m''_{j,C}` for `j != i`;
(c) `{hat I'_C = i} subset {hat I''_C = i}` pathwise (including every tie configuration); consequently `p'_{i,C} <= p''_{i,C}`;
(d) if `m' = m''` `nu`-a.e. on `C`, then with probability one the two executions select the same agent at every visit to `C`.
Proof. (a) Membership and visit indices are functions of `(X_t)` alone; exploration selections are functions of the visit index and (R3). (b) On each exploration visit `k in E_i`, `Z'^{(k)}_i = 1{U <= m'(X)} <= 1{U <= m''(X)} = Z''^{(k)}_i` because `m'(X) <= m''(X)`; the other agents' potential rewards are unchanged, and by (a) each agent's exploration sample is drawn at the same visits. (c) Suppose `hat I'_C = i`: then `hat m'_i >= hat m'_j = hat m''_j` for all `j != i`, and `sigma_C(i) < sigma_C(j)` for every `j != i` with `hat m''_j = hat m'_i`. Under `m''`: `hat m''_i >= hat m'_i >= hat m''_j` for all `j != i`. If `hat m''_i > hat m'_i`, then `i` is the unique maximizer and `hat I''_C = i`. If `hat m''_i = hat m'_i`, the set of maximizers is the same as under `m'` and `i` has the smallest priority rank among them, so again `hat I''_C = i`. Taking conditional probabilities given `B` (the same in both executions) gives `p'_{i,C} <= p''_{i,C}`. (d) By Lemma 2.1(b) each `X_C^{(k)}` has law `nu(. | C)`, so a.s. `m'(X_C^{(k)}) = m''(X_C^{(k)})` for all `k`, hence all potential rewards, both empirical means, and both commitments coincide. QED.

### Lemma 2.5 (per-cell inequality)

Fix agent `i` (honest or strategic), a deterministic feasible deviation `m'` (`0 <= m' <= M_i`, and `m' >= mu_i` if `i` is honest), and a level-`k_n` cell `C` with `nu(C) > 0`. Define
`a_C := E[1 + mu_i(x_i) - M_i(x_i) | C] in [0,1]`, `delta_C := E[M_i(x_i) - m'(X) | C] in [0,1]`,
`Util_i(C) := sum_{t <= n : C_t = C, I_t = i} (1 + mu_i(x_{i,t}) - m_{i,t})` (agent `i`'s realized utility collected in `C`).
Let `E'` denote expectation under `(m', S^max_{-i})` and `E` under `S^max`. Then
`E'[Util_i(C)] - E[Util_i(C)] <= q_n + N_C p'_{i,C} delta_C <= q_n + N_C min{ delta_C, c_1 q_n^{-1/2} + eta_{i,C} }`.
Proof. Split `Util_i(C)` into exploration visits (`kappa_t <= K q_n`) and exploitation visits (`kappa_t > K q_n`).
Exploration. By Lemma 2.4(a) the exploration visits at which `i` is selected are the same in both executions, and by Lemma 2.1(f) there are at most `q_n` of them. At such a visit the per-pull utility changes from `1 + mu_i - M_i` to `1 + mu_i - m'`, a change of `M_i(x_i) - m'(X) in [0, 1]` (it is at most `M_i <= 1`). Hence the exploration part of the difference lies in `[0, q_n]`; in particular it is at most `q_n`. This holds whether or not the cell reaches `K q_n` visits (truncated last block included: fewer than `q_n` selections of `i`, and no commitment).
Exploitation. By Lemma 2.1(e) with `w = 1 + mu_i - M_i` (baseline) and `w' = 1 + mu_i - m'` (deviation; `E[w' | C] = a_C + delta_C`): the exploitation parts equal `N_C p_{i,C} a_C` and `N_C p'_{i,C} (a_C + delta_C)`, where `p_{i,C}`, `p'_{i,C}` are the commitment probabilities of Lemma 2.1(d) under the two profiles. Their difference is `N_C [ (p'_{i,C} - p_{i,C}) a_C + p'_{i,C} delta_C ] <= N_C p'_{i,C} delta_C`, since `p'_{i,C} <= p_{i,C}` (Lemma 2.4(c)) and `a_C >= 0` (because `M_i <= 1` and `mu_i >= 0`; also `a_C <= 1` because `mu_i <= M_i`).
Bound on `p'_{i,C} delta_C`. Trivially `p'_{i,C} delta_C <= delta_C`. For the second bound let `j^*` attain `max_{j != i} bar M_{j,C}` and put `Delta' := bar M_{j^*,C} - bar m'_{i,C}` where `bar m'_{i,C} = E[m' | C] = bar M_{i,C} - delta_C`. Then `Delta' = delta_C - (bar M_{i,C} - bar M_{j^*,C}) >= delta_C - eta_{i,C}`.
Case `Delta' > 0`. On `{V_C >= K q_n}`, `{hat I'_C = i} subset {hat m'_{i,C} >= hat m_{j^*,C}}`, and conditional on `B` and (R3), `hat m'_{i,C}` and `hat m_{j^*,C}` are empirical means of `q_n` i.i.d. Bernoulli samples with means `bar m'_{i,C} < bar M_{j^*,C}` (Lemma 2.1(d); the deviator's exploration observations are i.i.d. Bernoulli(`bar m'_{i,C}`) because `m'` is a fixed map, which is exactly where the fixed ex ante map is used). Lemma 2.3 gives `P(hat I'_C = i | B, (R3)) Delta' <= c_1 q_n^{-1/2}`; integrating, `p'_{i,C} Delta' <= c_1 q_n^{-1/2}`. Therefore `p'_{i,C} delta_C <= p'_{i,C} (Delta' + eta_{i,C}) <= c_1 q_n^{-1/2} + eta_{i,C}`.
Case `Delta' <= 0`. Then `delta_C <= eta_{i,C}`, so `p'_{i,C} delta_C <= delta_C <= eta_{i,C} <= c_1 q_n^{-1/2} + eta_{i,C}`.
Adding the exploration and exploitation parts proves the lemma. QED.
(Numerical confirmation of `p'_{i,C} delta_C <= c_1 q^{-1/2} + eta_{i,C}` and of `p' <= p` by exact binomial computation with uniform-priority ties, 300 random configurations with `K in {2,3}`, `q in {4,16,64,256}`, including exact ties and gaps of order `q^{-1/2}`: largest value of `p' delta - (c_1 q^{-1/2} + eta)` observed was `-0.0699`; script `checks.py`.)

### Lemma 2.6 (Lipschitz cell bounds)

Assume every `M_j` is `L`-Lipschitz for the Euclidean norm on `[0,1]^d`. Let `C` be a level-`k` cell (side `h = 2^{-k}`) with `nu(C) > 0`. For `X, X_0 in C` and every `l`, `|x_l - x_{0,l}| <= |X - X_0| <= sqrt(D) h`.
(a) If `nu(U_i) = 0` (in particular under `nu(|T| >= 2) = 1`), then `eta_{i,C} <= 2 L sqrt(D) h`.
(b) Without any top-set condition, `theta_C = bar M_C - max_j bar M_{j,C} <= 2 L sqrt(D) h`.
Proof. (a) `nu(C setminus U_i) = nu(C) > 0`, so there is `X_0 in C` with `gap_i(X_0) <= 0`, i.e. some `j != i` with `M_j(x_{0,j}) >= M_i(x_{0,i})`. For every `X in C`: `M_j(x_j) >= M_j(x_{0,j}) - L sqrt(D) h >= M_i(x_{0,i}) - L sqrt(D) h >= M_i(x_i) - 2 L sqrt(D) h`. Averaging over `nu(. | C)`: `bar M_{j,C} >= bar M_{i,C} - 2 L sqrt(D) h`, hence `eta_{i,C} <= 2 L sqrt(D) h`. (b) Pick any `X_0 in C` and `j^* in T(X_0)`. For `X in C` and every `l`: `M_l(x_l) <= M_l(x_{0,l}) + L sqrt(D) h <= M_{j^*}(x_{0,j^*}) + L sqrt(D) h <= M_{j^*}(x_{j^*}) + 2 L sqrt(D) h`. Taking the maximum over `l`, `M_*(X) <= M_{j^*}(x_{j^*}) + 2 L sqrt(D) h` on `C`; averaging gives `bar M_C <= bar M_{j^*,C} + 2 L sqrt(D) h <= max_j bar M_{j,C} + 2 L sqrt(D) h`. QED.
(The sharper constant `2 L sqrt(d) h` holds since `|x_l - x_{0,l}| <= sqrt(d) h`; the task's constant `2 L sqrt(D) h` is kept.)

### Lemma 2.7 (parameter arithmetic)

For `n >= 1`: `n^{-1/(D+3)}/2 < h_n <= n^{-1/(D+3)}`; `J_n = h_n^{-D} < 2^D n^{D/(D+3)}`; `n^{2/(D+3)} <= q_n <= 2 n^{2/(D+3)}`; hence `q_n J_n <= 2^{D+1} n^{(D+2)/(D+3)}`, `n q_n^{-1/2} <= n^{(D+2)/(D+3)}`, `n h_n <= n^{(D+2)/(D+3)}`.
Proof. `k_n = ceil(log_2(n)/(D+3))` satisfies `log_2(n)/(D+3) <= k_n < log_2(n)/(D+3) + 1`, so `n^{1/(D+3)} <= 2^{k_n} < 2 n^{1/(D+3)}`, giving the bounds on `h_n = 2^{-k_n}` and `J_n = 2^{k_n D}`. `q_n = ceil(n^{2/(D+3)}) <= n^{2/(D+3)} + 1 <= 2 n^{2/(D+3)}` because `n^{2/(D+3)} >= 1`. The three products follow by multiplication. QED. (Checked numerically for `D in {1,2,3,6}` and `n in {1, 2, 10, 10^3, 10^6, 10^9}`; `checks.py`.)

## 3. Proofs of the theorems

Throughout, the total utility of agent `i` decomposes over cells: `sum_{t <= n} 1{I_t = i}(1 + mu_i(x_{i,t}) - m_{i,t}) = sum_C Util_i(C)`, where the sum runs over the level-`k_n` cells; zero-mass cells have `Util_i(C) = 0` a.s. (Lemma 2.1(a)), so all sums are effectively over the finitely many positive-mass cells (at most `J_n`, and also at most `n` visited cells).

### 3.1 Proof of Theorem T1

Step 1 (deterministic deviation). Fix `i`, `n >= 1`, and a deterministic feasible `m' = m'_{i,n}`. By Lemma 2.5, summing over positive-mass cells,
`u_i(n; m', S^max_{-i}) - u_i(n; S^max) = sum_C ( E'[Util_i(C)] - E[Util_i(C)] ) <= sum_C q_n + sum_C N_C ( c_1 q_n^{-1/2} + eta_{i,C} )`.
The first sum is at most `q_n J_n` (at most `J_n` cells; each positive-mass cell contributes at most `q_n`, cells never visited contribute `0`). For the second, `sum_C N_C <= sum_C E V_C = E sum_C V_C = n`, so `sum_C N_C c_1 q_n^{-1/2} <= c_1 n q_n^{-1/2}`; and `N_C <= n nu(C)` (Lemma 2.1(e)) gives `sum_C N_C eta_{i,C} <= n sum_C nu(C) eta_{i,C}`. This is (T1.1).
Step 2 (independent ex ante mixtures). Let agent `i` draw its map from a law `rho` on a measurable space of feasible maps, independently of (R1) to (R3) and of the other agents' (fixed) maps. By definition of independent ex ante randomization, the play under the mixture is, conditional on the realized map `m'`, the play under `(m', S^max_{-i})`, and `u_i(n; rho, S^max_{-i}) = int u_i(n; m', S^max_{-i}) rho(dm')`. Step 1 applies to every `m'` with a right-hand side that does not depend on `m'`; integrating against `rho` gives (T1.1) for the mixture. (The manuscript's baseline `S^max_{-i}` is deterministic; if the other agents also mix, condition on their realized maps as well and note that the right-hand side does not depend on them either, because only `M_j`, not `m_j`, enters `eta_{i,C}`: under `S^max_{-i}` the rivals' realized maps are `M_j` in any case.)
Step 3 (the sum vanishes). Under `nu(|T(X)| >= 2) = 1`, Corollary 2.2'(i) and (iv) give `sum_C nu(C) eta_{i,C} -> 0` along the level-`k_n` grids (this is where the filtration `F_k`, Levy's upward theorem, the identification `F_infty = Borel`, and bounded convergence are used, and where the two-top condition enters through `(gap_i)_+ = 0` `nu`-a.s.).
Step 4 (conclusion). By Lemma 2.7, `q_n J_n + c_1 n q_n^{-1/2} <= (2^{D+1} + c_1) n^{(D+2)/(D+3)} = o(n)`, and `n sum_C nu(C) eta_{i,C} = o(n)` by Step 3. The right-hand side of (T1.1) does not depend on the deviation, so `sup_{m' in S_HDS} [u_i(n; m', S^max_{-i}) - u_i(n; S^max)] = o(n)` for every `i`, which is the `S_HDS`-asymptotic equilibrium property of Definition def:restricted-equilibrium (with a deviation-uniform remainder). Feasibility of `S^max` for every agent (honest agents included, since `M_i >= mu_i`) uses only that each agent knows its own capacity map; publicity of `M_*` is the informational assumption under which the profile and the benchmark are meaningful and is not used in any inequality. QED.

### 3.2 Proof of Theorem T1'

Fix `i` with `nu(W_i) = 0` and a deterministic feasible deviation `m'`. Let `f_i := M_i - s_i` be agent `i`'s feasible floor (`mu_i` if honest, `0` if strategic), so `f_i <= m' <= M_i` and `M_i - m' <= s_i` pointwise. On `U_i setminus W_i` we have `s_i = 0`; on `W_i`, a `nu`-null set, nothing is needed; hence `M_i - m' <= s_i 1_{U_i^c}` `nu`-a.s., and therefore `delta_C = E[M_i - m' | C] <= E[s_i 1_{U_i^c} | C]` for every positive-mass cell. Lemma 2.5 gives `E'[Util_i(C)] - E[Util_i(C)] <= q_n + N_C min{delta_C, c_1 q_n^{-1/2} + eta_{i,C}} <= q_n + N_C ( c_1 q_n^{-1/2} + min{eta_{i,C}, E[s_i 1_{U_i^c} | C]} ) = q_n + N_C (c_1 q_n^{-1/2} + kappa_{i,C})`. Summing exactly as in Step 1 of 3.1 gives the displayed bound; mixtures are handled as in Step 2; `sum_C nu(C) kappa_{i,C} -> 0` by Corollary 2.2'(iii) and (iv). For the characterization: if `nu(W_j) = 0` for every `j`, every agent's deviation gain is `o(n)` uniformly, so `S^max` is an `S_HDS`-asymptotic equilibrium; if `nu(W_j) > 0` for some `j`, Theorem T4 exhibits a deviation of `j` in `S_HDS` with gain at least `c n` for all large `n`, so `S^max` is not an `S_HDS`-asymptotic equilibrium. The knife-edge statement is the case `nu(U_i) > 0 = nu(W_i)` for an honest `i` (possible only if `mu_i = M_i` `nu`-a.e. on `U_i`). QED.

### 3.3 Proof of Theorem T2

Under `nu(|T| >= 2) = 1`, `nu(U_i) = 0` for every `i` (Corollary 2.2'(i)), so Lemma 2.6(a) gives `eta_{i,C} <= 2 L sqrt(D) h_n` for every positive-mass level-`k_n` cell and every `i`. Inserting this into (T1.1) (valid for every `n`, every `i`, every deviation, mixtures included) and using `sum_C nu(C) = 1`:
`gain <= q_n J_n + c_1 n q_n^{-1/2} + 2 L sqrt(D) n h_n`.
By Lemma 2.7 each term is bounded by the corresponding multiple of `n^{(D+2)/(D+3)}`: `q_n J_n <= 2^{D+1} n^{(D+2)/(D+3)}`, `c_1 n q_n^{-1/2} <= c_1 n^{(D+2)/(D+3)}`, `2 L sqrt(D) n h_n <= 2 L sqrt(D) n^{(D+2)/(D+3)}`. The constant `2^{D+1} + c_1 + 2 L sqrt(D)` depends only on `D` and `L`; the argument makes no top/non-top or honest/strategic case split. QED.

### 3.4 Proof of Theorem T3

Under `S^max` every agent `j` plays `M_j`, so `P(n; S^max) = E sum_t M_{I_t}(x_{I_t,t})` and the deficit is `Def_n := E sum_{t <= n} [M_*(X_t) - M_{I_t}(x_{I_t,t})]`, a sum of terms in `[0,1]`. Decompose over cells and phases.
Exploration. Each positive-mass cell has at most `K q_n` exploration visits, each with deficit at most `1`; at most `J_n` cells; total at most `K q_n J_n` (pathwise).
Exploitation in a positive-mass cell `C`. By Lemma 2.1(e) applied to `w_j := M_* - M_j` for each `j` and summed over `j`,
`E sum_{k = K q_n + 1}^{V_C} [M_*(X_C^{(k)}) - M_{hat I_C}(x_{hat I_C}^{(k)})] = N_C sum_j p_{j,C} (bar M_C - bar M_{j,C}) = N_C [ theta_C + sum_j p_{j,C} (max_l bar M_{l,C} - bar M_{j,C}) ]`,
using `sum_j p_{j,C} = 1` on `{V_C >= K q_n}`. The last sum is `E[max_l bar M_{l,C} - bar M_{hat I_C, C}]`; by Lemma 2.1(d) the `K` empirical means are means of `q_n` i.i.d. Bernoulli(`bar M_{j,C}`) samples and `hat I_C` maximizes them, so the consequence of Lemma 2.3 gives at most `(K-1) c_1 q_n^{-1/2}`. Hence the exploitation deficit in `C` is at most `N_C [theta_C + (K-1) c_1 q_n^{-1/2}]`.
Summation. With `sum_C N_C <= n` and `N_C <= n nu(C)`,
`Def_n <= K q_n J_n + (K-1) c_1 n q_n^{-1/2} + n sum_C nu(C) theta_C`.
(a) Lipschitz capacities: Lemma 2.6(b) gives `theta_C <= 2 L sqrt(D) h_n`, so `Def_n <= K q_n J_n + (K-1) c_1 n q_n^{-1/2} + 2 L sqrt(D) n h_n <= (K 2^{D+1} + (K-1) c_1 + 2 L sqrt(D)) n^{(D+2)/(D+3)}` by Lemma 2.7. No top-set condition was used.
(b) Borel capacities: `sum_C nu(C) theta_C -> 0` by Corollary 2.2'(ii) and (iv), so `Def_n = o(n)`. QED.

### 3.5 Proof of Theorem T4

Fix `i` with `nu(W_i) > 0`, and `g_0`, `A`, `alpha = nu(A) > 0` as in the statement (`A = {gap_i >= g_0} cap {s_i >= g_0}` is Borel since `gap_i` and `s_i` are Borel).

Step 0 (feasible shading on `A`). Put `m^A(X) := M_i(x_i) - g_0/2` for `X in A`. Since `s_i >= g_0` on `A`, `m^A = M_i - g_0/2 >= M_i - s_i/2 = f_i + s_i/2 >= f_i`, where `f_i` is the feasible floor (`mu_i` if honest, `0` if strategic). So any map equal to `m^A` on a Borel subset of `A` and to `M_i` elsewhere is feasible (and honest if `i` is honest) and Borel; being allowed to depend on `n`, it lies in `S_HDS`.

Step 1 (good cells). For a level `k` and a Borel set `A' subset A`, call a level-`k` cell `C` good (for `A'`) if `nu(C) > 0`, `nu(A' | C) >= 3/4`, and `bar M_{i,C} - max_{j != i} bar M_{j,C} >= 3 g_0/4`; write `G_k(A')` for the set of good cells and `phi_k(X) := 1{C_k(X) in G_k(A')}`.
Claim: `phi_k(X) -> 1` for `nu`-a.e. `X in A'`. Indeed by Lemma 2.2(d) applied to `1_{A'}` and by Lemma 2.2(e) applied to `(f_1,...,f_K)` with `Phi(y) = y_i - max_{j != i} y_j`, for `nu`-a.e. `X in A'` we have `E[1_{A'} | C_k(X)] -> 1` and `bar M_{i,C_k(X)} - max_{j != i} bar M_{j,C_k(X)} -> gap_i(X) >= g_0 > 3 g_0/4`, so both defining inequalities hold for all large `k`. By bounded convergence, `nu(union G_k(A')) >= int_{A'} phi_k dnu -> nu(A')`, hence there is `k_0` with `nu(union G_k(A')) >= nu(A')/2` for all `k >= k_0`.

Step 2 (gain in a good cell under a deviation that equals `m^A` on `A' cap C`). Let `m'` be feasible with `m' = m^A` on `A' cap C` and `m' = M_i` on `C setminus A'`. Then `delta_C = E[M_i - m' | C] = (g_0/2) nu(A' | C) >= 3 g_0/8`, and the deviator's cell mean is `bar m'_{i,C} = bar M_{i,C} - delta_C >= bar M_{i,C} - g_0/2`, so for every `j != i`, `bar m'_{i,C} - bar M_{j,C} >= 3 g_0/4 - g_0/2 = g_0/4 > 0`. If `hat m'_{i,C} > hat m_{j,C}` for every `j != i` then `i` is committed (no tie to resolve), so by Lemma 2.1(d) and Lemma 2.3 (union bound over the `K-1` rivals, gap at least `g_0/4`), `p'_{i,C} >= 1 - eps_n`, `eps_n := 2 (K-1) e^{-q_n g_0^2 / 32}`. By the exploitation factorization of Lemma 2.5's proof, the exploitation gain in `C` is `N_C [ p'_{i,C}(a_C + delta_C) - p_{i,C} a_C ] >= N_C [ p'_{i,C} delta_C - (1 - p'_{i,C}) a_C ]` (using `p_{i,C} <= 1`, `a_C >= 0`) `>= N_C [ (1 - eps_n)(3 g_0/8) - eps_n ] >= N_C [ 3 g_0/8 - 2 eps_n ]` (using `a_C <= 1` and `3 g_0/8 <= 1`). The exploration gain in `C` is nonnegative (each of the at most `q_n` exploration pulls of `i` changes its utility by `M_i - m' >= 0`). Hence, whenever `eps_n <= g_0/16`, the total gain in a good cell is at least `N_C g_0/4`.

Step 3 (grid-aligned deviation; the main statement). Take `A' := A` and define `m'_n(X) := m^A(X)` if `X in A` and `C_{k_n}(X) in G_{k_n}(A)`, and `m'_n(X) := M_i(x_i)` otherwise. This is feasible by Step 0 and Borel (finitely many Borel cells). In a cell not in `G_{k_n}(A)`, `m'_n = M_i` on the whole cell, so by Lemma 2.4(d) (with equal maps on `C`) the two executions coincide on that cell almost surely and the gain there is `0`. In a good cell Step 2 applies. Therefore, for `n` with `eps_n <= g_0/16`,
`gain(n) >= (g_0/4) sum_{C in G_{k_n}(A)} N_C >= (g_0/4) [ n nu(union G_{k_n}(A)) - K q_n J_n ]`,
using `N_C = E(V_C - K q_n)_+ >= E V_C - K q_n = n nu(C) - K q_n` and `|G_{k_n}(A)| <= J_n`. By Step 1 and `k_n -> infinity`, `nu(union G_{k_n}(A)) >= alpha/2` for all `n` with `k_n >= k_0`. By Lemma 2.7, `K q_n J_n <= K 2^{D+1} n^{(D+2)/(D+3)} <= alpha n/4` as soon as `n^{1/(D+3)} >= K 2^{D+3}/alpha`. For such `n`, `gain(n) >= (g_0/4)(alpha n/2 - alpha n/4) = g_0 alpha n/16`. Thus with
`n_0 := min{ n : k_m >= k_0, 2(K-1) e^{-q_m g_0^2/32} <= g_0/16, and m^{1/(D+3)} >= K 2^{D+3}/alpha for all m >= n }`
(finite because `k_n -> infinity` and `q_n -> infinity`), the gain is at least `(g_0 alpha/16) n` for all `n >= n_0`. The constant `c = g_0 alpha/16` is explicit in terms of `(g_0, alpha)`; `n_0` depends on the instance through `k_0`, which comes from an almost sure convergence without a rate (unavoidable for merely Borel data).

Step 4 (horizon-independent deviation; variant). By inner regularity of Borel probability measures on the metric space `[0,1]^D` (Billingsley, Convergence of Probability Measures, 2nd edition, Theorem 1.1: for every Borel `A` and `eps > 0` there is a closed `F subset A` with `nu(A setminus F) < eps`), choose a closed `A' subset A` with `alpha' := nu(A') >= alpha/2`. Define the horizon-independent map `m'(X) := m^A(X)` on `A'`, `m'(X) := M_i(x_i)` off `A'`; feasible by Step 0. Classify the level-`k_n` positive-mass cells into good (`G_{k_n}(A')`), null (`nu(A' cap C) = 0`), and bad (the rest). Null cells: `m' = M_i` `nu(. | C)`-a.e. on `C`, so by Lemma 2.4(d) the gain is `0`. Good cells: gain at least `N_C g_0/4` by Step 2 (for `eps_n <= g_0/16`). Bad cells: the exploitation gain is `N_C[(p' - p) a_C + p' delta_C] >= -N_C (p - p') a_C >= -N_C >= -n nu(C)`, and the exploration gain is nonnegative; so the loss is at most `n nu(union of bad cells)`. Let `psi_k(X) := 1{C_k(X) is bad at level k}`. For `nu`-a.e. `X in A'`, `C_k(X)` is eventually good (Step 1), so `psi_k(X) -> 0`. For `X notin A'`, `r := dist(X, A') > 0` because `A'` is closed, and for `sqrt(D) 2^{-k} < r` the cell `C_k(X)` does not meet `A'`, so it is null and `psi_k(X) = 0`. Hence `psi_k -> 0` `nu`-a.e. and, by bounded convergence, `nu(union of bad level-k cells) = int psi_k dnu -> 0`. Combining, for all large `n`,
`gain(n) >= (g_0/4)[ n alpha'/2 - K q_n J_n ] - n o(1) >= (g_0 alpha/16) n - o(n) >= (g_0 alpha/32) n`.
So even a horizon-independent, grid-unaware feasible map gains linearly. QED.

Remark (why the horizon-independent variant needs care). Shading on an arbitrary Borel `A` of positive mass, rather than on a closed subset, can lose linearly in cells where `i` is tied at baseline and `A` has small but positive conditional mass (the deviator's cell mean drops below the tied rival's by more than `q_n^{-1/2}` while its baseline utility there is positive); closedness of `A'` is what makes the mass of such contaminated cells vanish.

## 4. Where each assumption is used

1. Profiles i.i.d. `nu` and independent of seeds, platform coins, and ex ante randomizations: Lemma 2.1(b) only (conditional i.i.d. `nu(. | C)` structure and independence of past cell data from future cell profiles); everything else uses Lemma 2.1(b) to (f). Also `E V_C = n nu(C)` (Binomial) in Lemma 2.1(e). A non-i.i.d. exogenous sequence can break Lemma 2.1(b) (contract, Section 11, item 5).
2. Fixed ex ante maps (no adaptation to rewards, counts, or phases): Lemma 2.1(c) and (d) (the deviator's exploration observations are i.i.d. Bernoulli(`bar m'_{i,C}`), which is what Lemma 2.3 needs in Lemma 2.5); Lemma 2.4 (a fixed map makes the pointwise comparison `1{U <= m'(X)} <= 1{U <= M_i(x_i)}` available on the same visit); the factorization in Lemma 2.1(e) (the per-pull utility during exploitation has a fixed conditional cell mean). Mixtures: handled by conditioning on the realized map, Step 2 of 3.1, using that the realized map is independent of (R1) to (R3).
3. Borel measurability of `nu`, `M_j`, `mu_j`, and of the deviation: all integrals `E[. | C]`; Lemma 2.2 (the functions `f_j(X) = M_j(x_j)`, `M_*`, `gap_i`, `s_i 1_{U_i^c}`, `1_A` must be Borel for `E[. | F_k]` and for `F_infty`-measurability); the sets `U_i`, `W_i`, `A` Borel in T1', T4.
4. `nu(|T(X)| >= 2) = 1`: only through `nu(U_i) = 0` for each `i` (Corollary 2.2'(i): the a.s. limit `(gap_i)_+` vanishes; Lemma 2.6(a): existence of a point of `C` outside `U_i`). Not used in T3. Weakened to `nu(W_i) = 0` per agent in T1'.
5. Two-top rival existence in each positive-mass cell (the analog of the manuscript's "another top agent `j`"): replaced by the correction term `eta_{i,C}`; Lemma 2.5 never assumes a rival with cell mean `bar M_C`.
6. `L`-Lipschitz capacities: Lemma 2.6 only (hence T2 and T3(a)). Intrinsic means need no regularity anywhere in T1 to T4. Continuity of capacities is never used.
7. Nested dyadic grid: Lemma 2.2(a) (`F_k` is a filtration, needed by Levy's upward theorem); the diameter bound `sqrt(D) 2^{-k}` in Lemma 2.2(b), Lemma 2.6, and T4 Step 4; the exact cell count `J_n = 2^{k_n D}` and `n^{-1/(D+3)}/2 < h_n <= n^{-1/(D+3)}` in Lemma 2.7. The choice `k_n = ceil(log_2(n)/(D+3))` is used for `k_n -> infinity` (Corollary 2.2'(iv), T4 Step 3) and the constants in Lemma 2.7. Nesting across different horizons is used only in the sense that all horizons draw their grid from the same dyadic filtration.
8. Half-open cells with the last interval closed at `1`: partition of `[0,1]^D`, nesting, diameter bound (Section 1.1, Lemma 2.2(a),(b)). On `[0,1)^D` these are the standard dyadic cubes; no null-set assumption on the faces at `1` is needed.
9. Static Grid-ETC structure: exactly `q_n` exploration observations per agent per cell and exploitation rewards ignored (Lemma 2.1(d), Lemma 2.3); cell-blind decisions (Lemma 2.1(d): commitment is a function of cell data and coins only); exploration schedule independent of rewards (Lemma 2.4(a)); a tie rule given by a fixed permutation drawn independently of the data (Lemma 2.4(c)). Uniformity of the permutations and of the priority is not needed for T1 to T4 (it is needed for the manuscript's FATA, not here); what is needed is one pull per agent per block and data-independence.
10. `0 <= mu_i <= M_i <= 1`: `a_C in [0,1]` (Lemma 2.5, T4 Step 2), per-pull utility change `M_i - m' in [0,1]` on exploration pulls (Lemma 2.5), deficits in `[0,1]` (T3).
11. `M_*` public: informational assumption making `S^max` a profile each agent can play and the benchmark meaningful; used in no inequality.
12. `K >= 2`: existence of a rival index `j != i` in `eta_{i,C}` and Lemma 2.6; the number of non-best agents `K - 1` in T3.
13. Inner regularity of Borel probability measures on a metric space: T4 Step 4 (horizon-independent variant) only.
14. Levy's upward theorem: Lemma 2.2(d), hence Corollary 2.2' (T1 Step 3, T1', T3(b)) and T4 Step 1.
15. Hoeffding's inequality: Lemma 2.3 only.

## 5. Self-audit

Classification: T1 COMPLETE; T1' (extension, exact characterization) COMPLETE; T2 COMPLETE; T3 COMPLETE (both parts); T4 COMPLETE (grid-aligned deviation with explicit constant `g_0 alpha/16`; horizon-independent variant with constant `g_0 alpha/32`, resting additionally on Billingsley Theorem 1.1). No target statement was found to be false.

What I checked and how. (i) Every lemma and theorem above is proved in this file from the model (Section 2.0), the two textbook theorems (Levy upward, Hoeffding), and, for the T4 variant, inner regularity; the manuscript's lem:cell-law, lem:etc-tail, and the A.4 coupling are reproved here as Lemmas 2.1, 2.3, 2.4 rather than imported. (ii) The constant `c_1 = 2 e^{-1/2}` was confirmed analytically (Lemma 2.3) and numerically. (iii) The per-cell inequality `p' delta_C <= c_1 q^{-1/2} + eta_{i,C}` and the coupling `p' <= p` were checked by exact binomial computation with uniform-priority ties over 300 random configurations including ties and `q^{-1/2}`-scale gaps (no violation; worst slack `0.0699`). (iv) Lemma 2.7's constants were checked numerically for several `D` and `n`. (v) The scout's Sections A and B and the ledger's per-cell check were used as a map of the argument; every step used was re-derived, and one point was sharpened: the exploitation difference is bounded by `N_C p' delta_C` and then by `min{delta_C, c_1 q^{-1/2} + eta}`, whose second member yields T1' and the exact characterization.

Points a referee may press, with my assessment.
(a) Mixtures. The statement "utility under an independent ex ante mixture is the mixture of the utilities" is taken as the definition of ex ante randomization (contract, Section 5); it presupposes a measurable structure on the space of maps making the play jointly measurable. I did not construct such a structure; for the paper, the cleanest wording is to define mixtures over a measurable family of maps, as the contract does. This is a modeling convention, not a gap in the inequality.
(b) T4's threshold `n_0` is not explicit: it depends on the level `k_0` after which the good-cell mass is at least `alpha/2`, which comes from an almost sure convergence without a rate. This is unavoidable under Borel data. Under `L`-Lipschitz capacities and an `A` with nonempty interior one can make `n_0` explicit, but T4 as stated does not claim this.
(c) Seed indexing. The manuscript's coupling indexes reward uniforms by the agent's local pull index; I use one uniform per round. Both realize the model, and the utilities depend only on the law. The coupling of Lemma 2.4 is stated for the round-indexed construction; since exploration selections coincide pathwise in the two executions (Lemma 2.4(a)), the same argument works with cell-visit-indexed or local-pull-indexed seeds during exploration. I did not rely on the manuscript's wording.
(d) Space `[0,1]^D` versus `[0,1)^D`. I used the closed-at-`1` last interval to cover the manuscript's `[0,1]^D` exactly; the task's `[0,1)^D` is the special case where those faces are excluded. Nothing else changes.
(e) The half-open cell diameter: for two points of a cell, `|X - X_0| <= sqrt(D) 2^{-k}` (each coordinate differs by at most `2^{-k}`); I never need strict inequality.
(f) In T3 the number of exploration rounds is bounded pathwise by `K q_n` per positive-mass cell; the bound `K q_n J_n` is loose when few cells are visited (one could use `K q_n min{J_n, n}`) but the rate is unaffected.
(g) Requirement 2's clause "state precisely why `(M_i - max_{j != i} M_j)_+ = 0` `nu`-a.s.": Corollary 2.2'(i), last sentences; it is a pointwise identity on `{|T| >= 2}`.
(h) Citation numbering. Williams' Theorem 14.2 was verified through the publisher's preview table of contents entry "14.2. Levy's 'Upward' Theorem" (Williams numbers results by section, so the theorem carries the label 14.2), not by reading the theorem page itself; Durrett's Theorem 4.6.8 was verified by reading the statement in the author-hosted 5th-edition PDF; Billingsley's Theorem 1.1 was verified by reading the statement (2nd edition, p. 7); Hoeffding 1963's bibliographic data were verified through Crossref (the Taylor and Francis and JSTOR pages refused automated access), and the theorem number "Theorem 2" is the standard label for the bounded-variables inequality in that paper, not re-read by me today. If the paper cites Hoeffding by theorem number, someone with access should confirm it; citing the paper without a theorem number is safe.
(i) Nothing in T1 to T4 uses the manuscript's finite-component, closed-null-boundary, constant-top-set, or continuity hypotheses; thm:contextual-public follows from T1 because its hypotheses imply `nu(|T| >= 2) = 1` (the top set has size at least two on every positive-mass component of `X setminus B` and `nu(B) = 0`). The manuscript's step "the rival's mean is `bar M_C`" is not needed and is false in cells where the top identity changes (scout Example A.3); the `eta_{i,C}` term is the repair.
(j) I did not attempt to remove the `q_n J_n` exploration term; the scout's Attack 9 (lazy deviation of an agent with `a_C = 0`) indicates it is attained up to `1 - o(1)` under a density bounded below, so the exponent `(D+2)/(D+3)` in T2 is tight for this algorithm. I did not re-verify that attack and make no claim about it.

Nothing is left open in the four target theorems as stated in Section 1.
