## 1. Executive summary (verdict first)

VERDICT: no counterexample to the target statements T1, T2, T3 was found. T4's statement survives, but two of the proof routes prescribed for it are broken, one by an explicit instance with exact numbers. Details:

1. (P1, proof of T4 "if" direction; explicit counterexample to the lead's argument, not to the theorem.) The ledger's "if" direction ("elementary: shade by half the gap on W_i") is FALSE as a proof. Section 8 (Attack F1) gives an instance with nu(W_1) = 1/64 > 0 (K = 2, d = 1, diagonal law, capacities 1/2 and 1/2 + g 1_A with g = 1/4) on which the deviation m' = M_1 - g/2 on all of W_1 = A has expected gain at most -0.058 n (a linear LOSS) on every horizon range n in (2^{5(k_m - 1)}, 2^{5 k_m}], k_m in {8, 26, 62, 134, ...}. Mechanism: in cells where A has relative mass f_C of order q_n^{-1/2}/g (near-tie cells), shading lowers the commitment probability by a constant (from about 0.92 to 0.76 at s = sqrt(q_n) g f_C = 1) while the effort saved per visit is only g f_C/2 -> 0; the baseline utility forfeited (about 0.08 per exploitation visit) is a constant. Exact binomial computations in `cellgain_exact.out` and `naive_multiscale.out`; an exact Grid-ETC paired simulation at n = 10^5 reproduces the sign (Section 9). T4 remains TRUE: the deviation must be restricted to a subset of W_i on which the cell density is uniformly close to one, either (i) horizon dependent and grid aligned (shade on A_g intersected with the cells C having nu(A_g | C) >= 1 - eps), or (ii) horizon independent via an Egorov subset E of A_g on which nu(A_g | C_k(X)) -> 1 uniformly (this uses nested grids). Both give gain >= (g nu(A_g)/8) n for all large n; the complete argument is in Section 8. Requirement 9's suggestion "cells inside a positive-mass open set" is also insufficient by itself when nu charges the boundary of the open set (same mechanism, Section 8, Remark).

2. (P1, statement of T4, second sentence.) "Conversely T1 shows nu(W_i) = 0 for all i suffices" does not follow from T1 as stated. T1 assumes nu(|T(X)| >= 2) = 1, i.e. nu(U_i) = 0 for every i, which is strictly stronger than nu(W_i) = 0 for every i (an honest agent with nu(U_i) > 0 but mu_i = M_i on U_i has nu(W_i) = 0). For such a knife-edge honest agent the T1 bound is true but useless: eta_{i,C_k(X)} -> (M_i - V_i)_+(X) > 0 on U_i, so n sum_C nu(C) eta_{i,C} is of order n. The equilibrium conclusion is nevertheless TRUE, by the refined per-cell bound p'_C delta_C <= c_1 q_n^{-1/2} + min{eta_{i,C}, s_{i,C}} with s_{i,C} := E[M_i - mu_i | C] for an honest deviator (s_{i,C} := bar M_{i,C} <= 1 for a strategic one), because min{eta, s}(C_k(X)) -> min{(M_i - V_i)_+, M_i - mu_i}(X) = 0 nu-a.s. exactly when nu(W_i) = 0. Section 7 has the argument. Repair: state T1 with min{eta_{i,C}, s_{i,C}} (which only strengthens it), or state the "iff" of T4 with that refined bound instead of "T1 shows".

3. (Simplification, not a defect.) Nested dyadic grids and Levy's upward theorem are NOT needed for sum_C nu(C) eta_{i,C} -> 0 in T1 or for the o(n) revenue in T3. For ANY sequence of finite Borel partitions P_n of [0,1]^D with mesh -> 0 and any finite Borel nu, E[f | P_n] -> f in L^1(nu) for every bounded Borel f (continuous functions are dense in L^1(nu); for continuous g the cell averages converge uniformly by the modulus of continuity; the conditional expectation is an L^1 contraction). Since eta_{i,C_n(X)} = (E[M_i | P_n] - max_{j != i} E[M_j | P_n])_+(X) and both max and (.)_+ are 1-Lipschitz, E[eta_{i,C_n(X)}] -> E[(M_i - V_i)_+] = 0. The manuscript's "dyadic width within a constant factor of n^{-1/(D+3)}" therefore suffices as it stands; the attempt in (c) to break convergence with non-nested grids fails for a structural reason. Nesting IS used for one thing only: the horizon-independent necessity deviation of item 1 (Egorov along a single filtration). Recorded in Section 4.

## 2. Attack (a): the factorization step

Claim under attack: for a cell C with nu(C) > 0, the deviator's expected exploitation utility in C equals N_C p'_C E[1 + mu_i - m'_{i,n} | C] with N_C := E[(V_C - K q_n)_+] and p'_C := Pr(i is committed | V_C >= K q_n).

Analysis. Let (E_t)_{t <= n}, E_t = 1{X_t in C}, be the membership sequence. Because the X_t are i.i.d. and independent of all seeds, permutations and priorities, conditional on (E_t) the ordered profiles X^{(1)}, X^{(2)}, ... of the visits to C are i.i.d. nu(. | C) (thinning of an i.i.d. sequence by an independent selection) and independent of all seeds, permutations and priorities. The commitment event W_i is a function of (X^{(1)}, ..., X^{(K q_n)}), the reward uniforms of those visits, the permutations and the priority; every exploitation visit k > K q_n has profile X^{(k)} independent of that data. Hence, on {V_C >= K q_n}, E[1{W_i} g(X^{(k)}) | (E_t)] = Pr(W_i | (E_t)) E[g | C] = p'_C E[g | C], where p'_C does not depend on the particular membership sequence because the exploration data have the same law given any membership sequence with V_C >= K q_n. Summing over k in (K q_n, V_C] and taking the expectation over (E_t) gives N_C p'_C E[g | C]. The dependence between V_C and W_i suggested by the brief does not exist: V_C is a function of the membership sequence, and conditional on that sequence W_i has the constant probability p'_C. Exactly the same holds under S^max with the same N_C, because the membership sequence is strategy independent.

Instances tried: (i) nu with an atom at a two-top point inside a cell (the conditional law nu(. | C) has an atom; the i.i.d. thinning argument is unchanged); (ii) nu singular (the diagonal law used throughout, nu concentrated on a line in [0,1)^2); (iii) nu concentrated on a finite set (then Grid-ETC is a finite-context ETC and the same identity holds); (iv) heavy-tailed cell visit counts: V_C is Binomial(n, nu(C)), never heavy tailed, and the identity holds for every law of V_C anyway since it conditions on (E_t). None of these breaks the identity. The simulations of Section 9 (uniform diagonal law and an atomic mixture law with unequal cell masses) reproduce the factorization predictions within Monte Carlo error.

Outcome: does not break the target. The only genuine requirement is the one already in the contract: i.i.d. profiles independent of the seeds (Section 11, item 5) and fixed ex ante maps (Section 12).

## 3. Attack (b): the coupling p'_C <= p_C

Coupling: same profiles, same permutations, same priority, same reward uniforms per (cell visit, agent). Feasibility gives 1{U <= m'(X)} <= 1{U <= M_i(x_i)} at every exploration visit of i, so i's exploration empirical mean is pointwise no larger under m', the other agents' means are identical, and the commitment rule (argmax with a fixed priority) gives {i committed under m'} subset of {i committed under M_i}: if hat m'_i >= hat M_j for all j with ties resolved for i, then hat M_i >= hat m'_i >= hat M_j with the same or fewer ties, resolved the same way. Instances tried: (i) m' = M_i on a subset and lower elsewhere (still pointwise dominated, so nothing changes); (ii) exact ties at commitment (covered by the shared priority; the numerical check `cellgain_exact.py` implements fair tie breaking and never shows p' > p); (iii) the truncated last block (no commitment in either execution; the exploration pulls of i are the same visits, so the utility difference there is the exploration term); (iv) K = 2, M_1 = M_2 everywhere, mu_1 = 0: p = 1/2 exactly, and with shading s the deviator wins only when its q_n exploration rewards are all ones and the priority favours it, p' = (1 - s)^{q_n}/2, gain N_C s (1 - s)^{q_n}/2 <= N_C/(2 e q_n), far below c_1 N_C q_n^{-1/2}.

Outcome: does not break the target.

Constant check for lem:etc-tail. Hoeffding: Pr(hat a - a >= Delta/2) <= exp(-2 q (Delta/2)^2) = exp(-q Delta^2/2), likewise for b - hat b, union bound gives 2 exp(-q Delta^2/2). The function x -> 2 x exp(-q x^2/2) is maximised at x = q^{-1/2} with value 2 e^{-1/2} q^{-1/2}, so c_1 = 2 e^{-1/2} = 1.21306...; numerically confirmed (`cellgain_exact.out`, first line: 1.2130613 at q = 1000 on a grid of 2 x 10^5 points).

## 4. Attack (c): the eta bound and non-nested grids

(c1) Attempt to make sum_C nu(C) eta_{i,C} stay away from zero with nu(|T| >= 2) = 1. Structural obstruction (this is the argument of item 3 of the summary, written out): let P_n be any sequence of finite Borel partitions of [0,1]^D with mesh(P_n) -> 0 (dyadic or not, nested or not; the manuscript's "half-open cubes of side h_n within a constant factor of n^{-1/(D+3)}" qualify) and let f be bounded Borel. Fix eps > 0 and choose g continuous on [0,1]^D with ||f - g||_{L^1(nu)} <= eps (continuous functions are dense in L^1 of a finite Borel measure on a compact metric space; Rudin, Real and Complex Analysis, Theorem 3.14, and Lusin's theorem 2.24). Then ||E[f | P_n] - f||_1 <= ||E[f - g | P_n]||_1 + ||E[g | P_n] - g||_1 + ||g - f||_1 <= 2 eps + omega_g(mesh(P_n)) where omega_g is the modulus of continuity of g, because on each cell C the average of g differs from g(x) by at most omega_g(diam C). Hence E[f | P_n] -> f in L^1(nu). Apply this to f = M_j for each j (finitely many): then max_{j != i} E[M_j | P_n] -> V_i in L^1 (|max a_j - max b_j| <= sum |a_j - b_j|), and eta_{i,C_n(X)} = (E[M_i | P_n] - max_{j != i} E[M_j | P_n])_+(X) -> (M_i - V_i)_+(X) in L^1. Under nu(|T| >= 2) = 1, (M_i - V_i)_+ = 0 nu-a.s. (if i in T(X) some other j in T(X) has M_j(x_j) = M_i(x_i); if i is not in T(X) then M_i(x_i) < M_*(X) = V_i(X)), so E[eta_{i,C_n(X)}] = sum_C nu(C) eta_{i,C} -> 0. No sequence of grids with mesh to zero can defeat this, so the sought counterexample cannot exist. (Zero-mass cells contribute nothing to the sum, which is an integral.)

(c2) Non-nested grids. Since (c1) needs no nesting, the manuscript need not adopt nesting for T1 or T3. I nevertheless checked the classical obstruction: for general Radon measures in dimension D >= 2 the a.e. differentiation along uncentred cubes can fail, so an a.s. (rather than L^1) statement along an arbitrary non-nested grid sequence would need care; the T1 bound only needs the integral, so this is moot.

(c3) [0,1)^D versus [0,1]^D. The half-open dyadic cubes of all levels generate the Borel sigma-algebra of [0,1)^D (every relatively open set is a countable union of dyadic cubes contained in it). Points with a coordinate equal to 1 belong to no half-open cube; the code's clipped floor(x/h) puts them in the last cube, which makes the last cubes closed on that face. With this convention the level-k partitions of [0,1]^D are still nested and still generate the Borel sigma-algebra, and (c1) applies verbatim. If nu charges the face {x_j = 1} nothing changes in any bound. Outcome: no break; the task's [0,1)^D convention is harmless but the manuscript's [0,1]^D with clipping is equally fine.

(c4) Where nesting IS used: only for the horizon-independent necessity deviation (Section 8, route (ii)), which needs a.s. convergence along one filtration to apply Egorov. The horizon-dependent route (i) does not need it.

Outcome: does not break T1; identifies requirement 1 of TASK.md as unnecessary for T1 to T3.

## 5. Attack (d): the Lipschitz bound eta_{i,C} <= 2 L sqrt(D) h_n

Proof being attacked: a positive-mass cell C contains a point X_0 with |T(X_0)| >= 2 (nu(C cap {|T| >= 2}) = nu(C) > 0, so such points exist inside the half-open cell, not merely in its closure; this disposes of the "two-top points only on the closure" attempt). Take j in T(X_0), j != i. For x in C, M_j(x_j) >= M_j(x_{0,j}) - L |x_j - x_{0,j}| = M_*(X_0) - L |x_j - x_{0,j}| >= M_i(x_{0,i}) - L |x_j - x_{0,j}| >= M_i(x_i) - L(|x_i - x_{0,i}| + |x_j - x_{0,j}|) >= M_i(x_i) - 2 L sqrt(d) h_n. Averaging over nu(. | C) gives bar M_{j,C} >= bar M_{i,C} - 2 L sqrt(d) h_n, hence eta_{i,C} <= 2 L sqrt(d) h_n <= 2 L sqrt(D) h_n. (The sharper sqrt(d) is available because each M_j depends on its own block x_j only.)

Instances tried: (i) three-way near-ties with K >= 3: only one rival j is used, so nothing changes; (ii) capacities depending on a coordinate shared with other agents: excluded by the model (M_i is a function of x_i alone); if the model allowed M_i(X) the same argument works with sqrt(D) in place of sqrt(d); (iii) i not top anywhere in C but cell-best (scout attack 4): the bound uses M_i(x_{0,i}) <= M_*(X_0), valid whether or not i is top; (iv) cells whose two-top points all lie on a lower-dimensional set of positive nu-mass (diagonal law): they are still points of C.

Outcome: does not break T2. T2's constant: q_n <= n^{2/(D+3)} + 1 <= 2 n^{2/(D+3)}, 2^{k_n} < 2 n^{1/(D+3)} so J_n < 2^D n^{D/(D+3)}, hence q_n J_n < 2^{D+1} n^{(D+2)/(D+3)}; c_1 n q_n^{-1/2} <= c_1 n^{(D+2)/(D+3)}; 2 L sqrt(D) n h_n <= 2 L sqrt(D) n^{(D+2)/(D+3)}. The displayed constant 2^{D+1} + c_1 + 2 L sqrt(D) is correct.

## 6. Attack (e): T3 revenue without a top-set condition

Per exploitation visit in a positive-mass cell C the expected benchmark loss is bar M_C - E[bar M_{hat I, C}] = (bar M_C - max_j bar M_{j,C}) + sum_{j not best} (max_k bar M_{k,C} - bar M_{j,C}) Pr(hat I = j). The second term is at most (K - 1) c_1 q_n^{-1/2} by lem:etc-tail applied to each non-best j against a best agent (winning requires beating it). For the first term take ANY point X_0 in C (no top-set condition, no positive mass needed for the point) and j in T(X_0): M_j(x_j) >= M_*(X_0) - L sqrt(d) h_n >= M_*(x) - L(sqrt(d) + sqrt(D)) h_n for all x in C since M_* is L-Lipschitz in X as a maximum of L-Lipschitz functions, so bar M_C - max_j bar M_{j,C} <= 2 L sqrt(D) h_n. Exploration visits number at most K q_n J_n pathwise with loss at most 1 each. Summing, P(n; S^max) >= E sum_t M_*(X_t) - [K q_n J_n + (K - 1) c_1 n q_n^{-1/2} + 2 L sqrt(D) n h_n]. Without Lipschitz continuity, E[M_* | P_n] -> M_* and max_j E[M_j | P_n] -> max_j M_j = M_* in L^1 by Section 4 (c1), so the first term integrates to o(1) and the loss is o(n).

Instances tried: a unique top everywhere (K = 2, M_1 = 3/4, M_2 = 1/4): at all-maximum play the platform loses only exploration plus 2 e^{-q_n/8} per exploitation visit, well inside the bound; the discontinuous snapshot instance of Section 9 (L = infinity), where the exact factorization predicts a shortfall of 869 out of a benchmark of 60937.5 at n = 10^5, i.e. 0.87 percent, while c_1 n q_n^{-1/2} alone is 12070; the fat-Cantor instances of the scout (loss controlled by the same two terms).

Outcome: does not break T3.

## 7. Attack (f) part 1 and attack (h): honest slack, small n, trivial deviations

(h1) Every n. Exploration: agent i's exploration pulls are the same visits under both profiles; per pull the utility difference is M_i(x_i) - m'(X) in [0, 1] (m' >= 0, M_i <= 1), at most q_n pulls per cell and at most J_n cells, so at most q_n J_n for every n, including n with q_n J_n > n (then the bound exceeds n and is trivial since the whole deviating utility is at most 2n... more precisely the exploitation term is nonpositive when no cell commits). Exploitation: the per-cell inequality gain_C <= N_C (c_1 q_n^{-1/2} + eta_{i,C}) is proved for every n, with N_C = 0 when no cell reaches K q_n visits. No small-n failure.
(h2) m' = M_i: gain 0, bound nonnegative. Trivial.
(h3) Honest deviators with binding floors: honest maps are a subset of feasible maps, so the upper bound holds; where mu_i = M_i the honest agent cannot move, so only necessity is affected (Section 8).

(f1) Honest slack and the knife-edge case. This is item 2 of the summary. Let i be honest with nu(U_i) > 0 and mu_i = M_i nu-a.e. on U_i (so nu(W_i) = 0). Then any honest deviation has m' = M_i on U_i, and delta_C = E[(M_i - m') 1{U_i^c} | C] <= s_{i,C} := E[M_i - mu_i | C]. From the per-cell inequality, p'_C delta_C <= min{delta_C, c_1 q_n^{-1/2} + eta_{i,C}} <= c_1 q_n^{-1/2} + min{s_{i,C}, eta_{i,C}}. By Section 4 (c1), min{s, eta}(C_n(X)) -> min{M_i - mu_i, (M_i - V_i)_+}(X) in L^1(nu), and the limit vanishes nu-a.s. iff nu({M_i > mu_i} cap U_i) = nu(W_i) = 0. Hence the refined bound gives gain <= q_n J_n + c_1 n q_n^{-1/2} + n sum_C nu(C) min{s_{i,C}, eta_{i,C}} = o(n) exactly when nu(W_i) = 0, for strategic (s = bar M_{i,C}, W_i = U_i) and honest agents alike. The unrefined T1 bound does not give this: with eta alone, sum_C nu(C) eta_{i,C} -> E[(M_i - V_i)_+] > 0 when nu(U_i) > 0. So the sentence "Conversely T1 shows nu(W_i) = 0 for all i suffices" in T4 is not supported by T1 as stated; the refined bound repairs it at no cost.

Outcome: T1 to T3 not broken; T4's sufficiency sentence needs the refined bound (P1 on the statement's logic, with a one-line repair).
